- Metal后端Mac开发指南.md — macOS Metal 后端的编译验证、调试、优化指南，含 Windows→Mac 搬代码步骤与预判错误查表。

- document-to-renderdata-flow.md — 文档模型（Document/Scene）如何转换为渲染数据（render data）进入 GPU renderer 的完整流程。

- viewport-refresh-flow.md — 视口刷新流程，从文档变化传递到渲染层再显示到屏幕的当前有效链路与收口方向。
- 操作-通知-渲染关系图.md — 记录 Workbench3D.cpp 各项 3D 操作中，场景通知、树重建、Render 更新三者的触发关系，含 structureRevision 推进判定。
- 新渲染架构.md — 渲染 DLL 只管"怎么画"、应用层定义"画什么"的新架构设计，含统一渲染管线、跨 DLL 零 STL 暴露等原则。
- 渲染数据结构重构方案.md — 消除顶点格式/图元枚举/渲染批次重复定义、统一到单一来源（Utility/Ut/VertexFormat.hpp 等）的重构方案。
- 渲染管线.md — 当前渲染层将 2D/3D 统一到 Renderx/RenderX 的核心管线，只保留当前可用设计与未来收口目标。
- 百万级矢量剔除-空间索引设计.md — 对 DrawList 每帧剔除从 O(N) 线性遍历升级为空间索引驱动的 O(可见) 查询的 CPU 空间索引设计。
- 虚线.md — 选中轮廓"流水虚线"高亮的渲染原理（弧长驱动、流动动画）与可配置参数。
- 虚线事件剥离-空间索引设计.md — 同「百万级矢量剔除-空间索引设计」的副标题版本，定位 CPU 空间索引 O(可见) 查询。
- 视图渲染现状记录.md — 2D/3D 视图渲染实现的关键发现记录，确认核心渲染已全部使用 RenderX DLL，不再用 Qt QPainter。

## 06-算法专题

- 3D切片与激光减材加工.md — 3D 模式下对三维图形分层切片→每片生成刀路→输出给激光设备做减材加工的完整流程设计，Engraving 模块唯一契约文档。
- 3D撤销与B-Rep同步优化.md — 3D 撤销栈 UAF、B-Rep 变换同步、数据持久化与保存点、崩溃健壮性的 P0-P3 优先级修复记录，已完成并通过编译与冒烟验证。
- 三角剖分算法.md — CAD 系统多边形三角剖分算法（PolygonTriangulator）的原理、实现细节与使用方式，色块填充的核心步骤。
- 偏移算法.md — 2D 路径偏移（Offset/Geo2DOffset）的核心实现，基于 Clipper2 库做多边形膨胀/收缩，支持内缩外扩与 JoinType 拐角处理。
- 填充算法.md — 填充算法体系总览，含线填充（EntityFiller / EntityFill）与色块填充（Color Fill）两大类的完整实现。
- 套料算法.md — Nesting 模块 v2 套料算法，将任意形状 2D 零件紧凑排到板材上最大化利用率，含算法原理、分层结构与 C ABI 契约。
- 线填充算法.md — 激光雕刻最常用的线填充（Hatch Fill / Fill2D）算法，把所有选中图元轮廓合成统一边集合按角度反向旋转逐行扫描。
- 色块填充算法.md — 色块填充（Color Fill / FillColor2D）算法，与线填充并列，将闭合轮廓三角剖分生成 SyFillRegion 实心色块。
- 阵列算法.md — CAD 阵列（ArrayAlgorithm）算法的核心实现、参数配置、调用流程与优化分析。
