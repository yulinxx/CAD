## 3. 各文档作用

### 3.1 当前架构总览

描述系统当前分层、模块职责和整体关系，是最上层的架构入口。

### 3.2 模块边界定义

描述模块之间的依赖边界、通信规则和禁止关系。

### 3.3 命令与状态流

描述命令系统、状态同步、Undo、交互过程和事件流转。

### 3.4 渲染与视口边界

描述 UI、Viewport、RenderCore、后端之间的职责分工。

### 3.5 开发说明

描述项目统一开发规范、日志与注释约定、DLL 编写注意事项和提交前自检要求。

### 3.6 菜单架构定义

描述菜单的内容、分类、命令映射和设计原则。

### 3.7 左侧工具栏架构定义

描述左侧工具栏的绘图入口、工具切换和高频操作定位。

### 3.8 右侧工具栏架构定义

描述右侧工具栏的属性编辑、工艺参数和对象管理职责。

### 3.9 顶部工具栏架构定义

描述顶部工具栏的视图控制、全局快捷入口和加工快捷功能。

### 3.10 属性面板架构定义

描述属性面板的职责、UI/算法/数据三层解耦、双击编辑与撤销集成、按图元类型展示属性。

### 3.11 状态栏架构定义

描述状态栏的上下文反馈、命令提示和系统状态显示。

### 3.12 场景树架构定义

描述 2D"场景"页场景树的职责、UI/算法/数据三层解耦、QTreeView 懒加载百万级优化、多选与右键批量操作（显示/隐藏/锁定/删除）。

### 3.13 UI定制变更设计方案

历史设计文档。当前实现以 `UI定制.md` 为准，描述运行时客户 ID 解析、配置驱动 UI、面板工厂、授权闸门等机制。

### 3.14 序列化架构定义

位置：[`../01-当前架构/序列化架构定义.md`](../01-当前架构/序列化架构定义.md)（权威）

描述存盘/打开/导入/导出的分层架构：`SySerializer` 原生格式（.sy/.syx）、
导入侧的中立 IR（`IrPublisher` / `IrProjector` / `IrTransform`）与跨 DLL 内存契约、
转换层 `Eg::FioEntityConverter`（位于 Engine3D）、图层/颜色/群组/位图四条通道、
2D 与 3D 同构的导入链路、五阶段导入流程。

格式级细节（各格式实体覆盖、第三方依赖库、外部工具、跨平台状态、分期计划）
见模块自带文档 [`FileIO/README.md`](../../FileIO/README.md)。
