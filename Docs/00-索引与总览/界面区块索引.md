## 3. 可见文字中英文对照原则

所有界面文案和文档中的按钮、菜单项、状态项，建议使用“中文 + 英文”形式记录，便于多语言翻译和界面统一。

例如：

- 新建 New
- 打开 Open
- 保存 Save
- 退出 Exit
- 撤销 Undo
- 重做 Redo
- 选择 Select
- 绘图 Draw
- 编辑 Edit
- 视图 View
- 帮助 Help
