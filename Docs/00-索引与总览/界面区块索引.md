# 界面区块索引

## 1. 目的

本文档用于对应用主界面的几个核心区块做索引，方便查找对应架构文档。

---

## 2. 界面区块与文档对应关系

| 界面区块 | 英文 | 对应文档 |
|---|---|---|
| 菜单 | Menu | `菜单架构定义.md` |
| 左侧工具栏 | Left Toolbar | `左侧工具栏架构定义.md` |
| 右侧工具栏 | Right Toolbar | `右侧工具栏架构定义.md` |
| 顶部工具栏 | Top Toolbar | `顶部工具栏架构定义.md` |
| 状态栏 | Status Bar | `状态栏架构定义.md` |

---

## 3. 可见文字中英文对照原则

所有界面文案和文档中的按钮、菜单项、状态项，建议使用“中文 + 英文”形式记录，便于多语言翻译和界面统一。

例如：

- 新建 New
- 打开 Open
- 保存 Save
- 退出 Exit
- 撤销 Undo
- 重做 Redo
- 选择 Select
- 绘图 Draw
- 编辑 Edit
- 视图 View
- 帮助 Help

## 5. 使用建议

当你在做某个界面区块的变更时，先查本索引，再进入对应文档，可以避免遗漏相关职责边界。
