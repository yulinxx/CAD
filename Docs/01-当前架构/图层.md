# 图层系统设计与使用指南

## 概述

本文档描述了 CAD 系统中图层系统的完整设计，包括图层类型（矢量/位图）、填充支持、视觉区分、持久化以及常用 API 参考。

---

## 核心概念

| 类型 | 枚举值 | 说明 | 视觉特征 |
|------|--------|------|----------|
| 矢量图层 | `Eg::LayerType::VECTOR` | 包含线、圆、多边形等矢量图元 | 实线边框（图层色）+ 白色背景 |
| 位图图层 | `Eg::LayerType::BITMAP` | 包含导入的位图图像 | 虚线边框（图层色）+ 浅灰背景 + 相机图标 |
| 矢量+填充图层 | `Eg::LayerType::VECTOR` + `fill=true` | 矢量图层启用填充 | 实线边框（图层色）+ 填充色背景 |

## 架构设计

### 1. 图层类型枚举

**文件位置**: `Engine/Common/Include/Engine/Layer/SyLayer.h`

```cpp
namespace Eg
{
    enum class LayerType : int8_t
    {
        VECTOR = 0,  // 矢量图层（默认，包含线、圆、多边形等矢量图元）
        BITMAP = 1   // 位图图层（包含导入的位图图像）
    };
}
```

### 2. SyLayer 扩展

在 `SyLayer` 类中添加了 `LayerType` 支持：

```cpp
class SyLayer
{
public:

    void setLayerType(LayerType type);
    LayerType getLayerType() const;

private:
    LayerType eLayerType{ LayerType::VECTOR };  // 图层类型
};
```

### 3. LayerManager 扩展

**文件位置**: `Engine/2D/Include/Engine2D/Interaction/LayerManager.h`

新增方法：
- `setLayerType(int nLayerId, Eg::LayerType type)` - 设置图层类型
- `layerType(int nLayerId) const` - 查询图层类型
- `findOrCreateLayerByType(Eg::LayerType type, const std::string& name)` - 查找或创建指定类型的图层

### 4. LayerInfo 结构扩展

## 右侧工具栏视觉设计

### 色块显示规则

| 图层类型 | 边框样式 | 背景色 | 图标 |
|---------|---------|--------|------|
| 矢量图层 | 2px 实线（图层色） | 白色 | 无 |
| 矢量+填充图层 | 2px 实线（图层色） | 填充色 | 无 |
| 位图图层 | 2px 虚线（图层色） | 浅灰色 (#F0F0F0) | 16x16 相机图标 |

### 视觉示例

```
矢量图层 (红色):        矢量+填充 (红色/绿色填充):    位图图层 (蓝色):
┌─────────┐            ┌─────────┐                  ┌─────────┐
│         │            │░░░░░░░░░│                  │  📷     │
│  白色   │            │░填充色░░│                  │  蓝色   │
│         │            │░░░░░░░░░│                  │         │
└─────────┘            └─────────┘                  └─────────┘
  红色边框                红色边框                      蓝色虚线边框
```

### 选中高亮行为

- **选中态**：保持图层原色，边框加粗为 3px 实线
- **悬停态**：边框变为 2px 实线（图层色）
- **锁定态**：2px 虚线（主题锁定色）
- **隐藏态**：透明度降低（alpha=110）

## 持久化支持

### 数据库 Schema

```sql
CREATE TABLE IF NOT EXISTS layers (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    document_id     TEXT    NOT NULL,
    layer_id        INTEGER NOT NULL,
    name            TEXT    NOT NULL DEFAULT '',
    color           TEXT    DEFAULT '#000000',
    visible         INTEGER DEFAULT 1,
    locked          INTEGER DEFAULT 0,
    fill            INTEGER DEFAULT 0,
    fill_color      TEXT    DEFAULT '',
    layer_type      INTEGER DEFAULT 0,  -- 0=矢量，1=位图
    order_index     INTEGER DEFAULT 0,
    updated_at      TEXT    DEFAULT (datetime('now'))
);
```

### 数据迁移

`DatabaseBootstrapper::ensureLayerColumns()` 会自动为现有数据库添加 `layer_type` 列（默认值 0）。

## 位图导入集成

### ImageImporter 扩展

新增重载方法，支持自动分配到位图图层：

```cpp
static bool importFromFile(const QString& filePath, 
    Eg::SceneManager* sceneManager,
    LayerManager* layerManager,  // 新增参数
    const QPointF& anchorWorld, 
    QWidget* parent = nullptr);
```

### 导入实现关键点（修复克隆 Bug）

```cpp
// 1. 保存原始 ID
const Eg::EntityId originalId = imgEntity->id;

// 2. 克隆并保留 ID
auto snap = std::unique_ptr<Eg::SyEntity>(imgEntity->clone());
snap->id = originalId;
sceneManager->insertEntityPreserveId(std::move(snap));

// 3. 查找场景中的实际实体
Eg::SyEntity* added = sceneManager->findSyEntityById(originalId);

// 4. 分配到位图图层
if (layerManager && added)
{
    int bitmapLayerId = layerManager->findOrCreateLayerByType(Eg::LayerType::BITMAP);
    if (bitmapLayerId >= 0)
    {
        layerManager->assignEntityToLayer(added, bitmapLayerId);
        layerManager->setCurrentLayer(bitmapLayerId);
    }
}
```

**关键点**：`SceneManager::addEntity()` 会克隆实体并分配新 ID，必须使用 `insertEntityPreserveId()` 保留 ID，再通过 ID 查找场景中的实际实体进行图层分配。

### BitmapInputTool 更新

自动使用新的导入方法，将位图分配到位图图层：

```cpp
bool BitmapInputTool::runDialog()
{
    if (!ImageImporter::importFromFile(filePath, m_sceneManager, 
        m_layerManager, anchorWorld, parent))
    {
        return false;
    }
    return true;
}
```

## 注意事项

1. **默认类型**：新创建的图层默认为 `VECTOR` 类型
2. **自动分配**：通过 `ImageImporter` 导入的位图会自动分配到位图图层
3. **类型可变**：图层类型创建后可以修改（`setLayerType`），但会影响视觉显示
4. **数据库兼容**：旧文档中的图层会自动获得 `layer_type = 0`（矢量）
5. **克隆 Bug 修复**：所有创建 SyImage 的路径都必须使用 `insertEntityPreserveId()` 模式

## 故障排除

### 问题：位图没有分配到正确的图层

**解决方案**：检查是否调用了带 `LayerManager` 参数的 `importFromFile` 方法，且使用了 `insertEntityPreserveId` 模式。

### 问题：右侧工具栏没有显示正确的样式

**解决方案**：检查 `RightToolBar::refreshColorsFromLayers()` 是否被正确调用，以及 `LayerDisplayInfo` 中的 `layerType`、`isFillLayer`、`fillColor` 是否正确填充。

### 问题：数据库缺少 `layer_type` 列

**解决方案**：`DatabaseBootstrapper::ensureLayerColumns()` 会自动添加该列。

### 问题：选中高亮遮挡了图层颜色

**解决方案**：检查 `generateSwatchStyleSheet()` 中 `isCurrent` 分支是否使用 `baseColor.name()` 而非 `theme.borderCurrent`。

## 性能考虑

- 图层类型信息在 `LayerInfo` 中存储，查询效率为 O(1)
- 右侧工具栏刷新时批量获取图层信息，避免多次查询
- 样式表生成在 UI 线程完成，不影响 Engine 性能
