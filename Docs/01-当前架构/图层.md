# 图层系统设计与使用指南

## 概述

本文描述当前图层系统的真实实现方式，聚焦图层类型、位图图层、持久化和常用接口。

---

## 1. 当前图层模型

图层系统当前支持两类图层：

| 类型 | 枚举值 | 用途 |
|------|--------|------|
| 矢量图层 | `Eg::LayerType::VECTOR` | 线、圆、多边形等常规图元 |
| 位图图层 | `Eg::LayerType::BITMAP` | 导入图片、位图对象 |

`SyLayer` 已支持图层类型字段，`LayerManager` 负责维护当前图层集合与分配规则。

---

## 2. 当前接口

`Engine/2D/Include/Engine2D/Interaction/LayerManager.h` 里当前可用的核心接口包括：

- `setLayerType(int nLayerId, Eg::LayerType type)`
- `layerType(int nLayerId) const`
- `findOrCreateLayerByType(Eg::LayerType type, const std::string& name = {})`
- `assignEntityToLayer(...)`
- `setCurrentLayer(...)`

`LayerInfo` 当前保存的信息包括：

- `name`
- `color`
- `lineWidth`
- `lineStyle`
- `visible`
- `locked`
- `fill`
- `fillColor`
- `layerType`
- `hardwareProfileId`

---

## 3. 当前视觉规则

当前右侧工具栏对图层的展示遵循以下规则：

| 图层类型 | 边框样式 | 背景 |
|---------|---------|------|
| 矢量图层 | 实线 | 白色 |
| 矢量 + 填充 | 实线 | 填充色 |
| 位图图层 | 虚线 | 浅灰色 |

选中、悬停、锁定、隐藏状态会进一步影响边框粗细和透明度。

---

## 4. 当前持久化

图层信息会写入数据库层，当前 schema 中包含：

- `layer_id`
- `name`
- `color`
- `visible`
- `locked`
- `fill`
- `fill_color`
- `layer_type`
- `order_index`
- `updated_at`

数据库初始化会补齐 `layer_type` 字段，确保旧数据能够以默认矢量图层继续工作。

---

## 5. 位图导入规则

位图导入当前会优先走位图图层：

1. 导入位图实体
2. 通过 `insertEntityPreserveId()` 保留实体 ID
3. 在场景中查到实际实体
4. 通过 `findOrCreateLayerByType(Eg::LayerType::BITMAP)` 找到或创建位图图层
5. 调用 `assignEntityToLayer()` 分配实体
6. 设为当前图层

这保证了位图对象在图层语义上和矢量图元分离。

---

## 6. 维护原则

- 图层类型应由 `LayerManager` 统一管理
- 位图图层应继续保持独立语义
- 图层视觉规则应尽量集中在 UI 层生成
- 持久化字段新增时应同步数据库初始化逻辑
