# 属性面板架构定义

## 1. 文档目标

本文档描述 2D 工作台"属性"页（属性面板 / Properties Panel）的职责、功能、分层架构与实现方式。属性面板用于查看并编辑当前选中图元（含多选）的属性，例如名称、基点、几何参数、控制点、节点坐标等。

> 状态说明：本文对应已落地实现（2026-08-15）。涉及"撤销集成""按索引编辑节点""图元名可编辑""基点按类型命名"均已实现。

---

## 2. 在整体框架中的位置

```text
选择图元（视口 / 操作）
    → 绑定层(Workbench2D::refreshPropertiesPanel)
    → 算法层(EntityPropertyEditSession2D) 按 id 解析实体 → 生成数据(PropertyModel)
    → UI 层(PropertiesPanelWidget) 渲染
    → 用户双击编辑 → IPropertyEditTarget → 算法层 → SceneEditService 快照入撤销栈
    → 重建模型 → 面板刷新
```

属性面板属于 `UI` 层。它**不保存业务真相**，**不直接修改图元内存**，只通过 `PropertyModel`（数据）与 `IPropertyEditTarget`（编辑接口）与算法层交互。

---

## 3. 职责

1. 查看当前选中对象（单个或多选）的属性。
2. 通过双击值列，内联编辑可编辑属性。
3. 修改结果统一经算法层提交并集成撤销/重做。
4. 不同图元类型动态展示不同字段（几何、控制点、节点等）。
5. 面板可被替换/移除（配置驱动 UI 下可能不存在），不影响数据与算法。

---

## 4. 分层架构（UI / 算法 / 数据 解耦）

属性面板按三层严格解耦，任一层可独立替换。

### 4.1 数据层（UICommon，纯数据）

| 文件 | 说明 |
|---|---|
| `UI/Dlg/PropertyItem.h` | 单条属性：category / name / value / tooltip / editable / editType / editData |
| `UI/Dlg/PropertyModel.h` | 属性面板数据模型：typeName、hasSelection、items（有序，按 category 分组） |

数据层不依赖任何 UI 控件，是算法层与 UI 层的唯一数据契约。

### 4.2 算法层（UI2D，无 widget）

| 文件 | 说明 |
|---|---|
| `UI2D/Service/EntityPropertyModel2D.{h,cpp}` | 只读模型生成：`build(entities) → PropertyModel` |
| `UI2D/Service/EntityPropertyEditSession2D.{h,cpp}` | 编辑会话：持有图元 id，按需解析实体、应用修改、集成撤销；实现 `IPropertyEditTarget` |
| `UI/Dlg/IPropertyProvider.h` | 属性提取/编辑接口：collectProperties / setPropertyValue / pointAt / setPointAt |
| `UI/Dlg/Entity2DPropertyProvider.{h,cpp}` | 单图元属性提供者（含名称、按类型命名基点、几何/控制点） |
| `UI/Dlg/MultiEntity2DPropertyProvider.{h,cpp}` | 多选图元汇总属性提供者 |

算法层复用 `IPropertyProvider` 体系从 `Eg::SyEntity` 提取与修改属性，**不感知任何 widget**。

### 4.3 编辑接口（UICommon，解耦边界）

| 文件 | 说明 |
|---|---|
| `UI/Dlg/IPropertyEditTarget.h` | `editValue / editPointAt / pointAt`。UI 只依赖此接口提交编辑，不感知引擎/撤销 |

### 4.4 UI 层（Main，可替换/移除）

| 文件 | 说明 |
|---|---|
| `Main/Src/UI/Widgets/UiPropertiesPanel.{cpp,h}` | 渲染 `PropertyModel` 树；双击内联编辑；`sigPropertyEdited` 信号 |

UI 面板仅消费 `PropertyModel`（数据）与 `IPropertyEditTarget`（接口）。面板不存在或被替换都不影响数据与算法。

### 4.5 绑定层（组合根）

| 文件 | 说明 |
|---|---|
| `Main/Src/UI/Workbench/UiWorkbench.cpp` | `Workbench2D::refreshPropertiesPanel()`：解析选中图元 id → 创建会话 → `setEditTarget` + `setPropertyModel` |

绑定层是唯一同时知道"面板是否存在"的地方，先探测 `propertiesDock()`（可为空）再绑定，保证 UI 可定制性。

## 5. 编辑功能

### 5.1 交互方式

双击属性行的**值列**触发内联编辑；字段名列（第 0 列）只读，防止误改属性名。仅 `editable == true` 且存在编辑目标的行可编辑。

### 5.2 编辑类型（按 `PropertyItem.editType`）

| editType | 编辑器 |
|---|---|
| Text / Number / Integer | `QLineEdit`（数字/整数带校验） |
| Point2d | X/Y 数值框 |
| PointList | 索引下拉 + X/Y 数值框（切换索引实时加载该节点坐标） |
| ComboBox | `QComboBox` |
| CheckBox | 是/否下拉 |
| Color | 颜色按钮（弹出选色对话框） |

### 5.3 提交与撤销

提交时，UI 调用 `IPropertyEditTarget::editValue / editPointAt`；算法层 `EntityPropertyEditSession2D` 内部：
1. 按 id 从场景解析当前实体；
2. `SceneEditService::captureSnapshots` 捕获修改前快照；
3. 调用 `IPropertyProvider` 的 setter 修改实体；
4. 捕获修改后快照，`pushExecutedChange` 入撤销栈；
5. 成功后经 `sigPropertyEdited` → 绑定层重建模型刷新面板（派生字段如周长/面积同步更新）。

### 5.4 引擎撤销语义与指针安全

引擎撤销会把场景中的图元对象**整体替换为快照克隆（按 id 恢复）**。因此编辑会话**绝不长期持有图元裸指针**，而是保存图元 id，每次操作按 id 重新解析实体，避免撤销/重做后出现悬挂指针。

## 6. 属性内容（按图元类型）

### 6.1 通用（General）

- 名称 `Name`（可编辑文本）
- 类型 `Type`（只读）
- ID（只读）
- 基点（可编辑坐标，名称按类型自动适配，见下）
- 闭合/方向（只读，按类型显示）

### 6.2 基点按类型命名

`Entity2DPropertyProvider::basePointName()`：

| 图元类型 | 基点名称 |
|---|---|
| 点 Point | `Point` |
| 圆 / 圆弧 / 椭圆 | `Center` |
| 线 / 折线 / 智能线 / 贝塞尔 / 样条 / NURBS | `Start Point` |
| 多边形 / 其它 | `Base Point` |

编辑线/折线或多边形的基点时，会同步更新其第 0 个顶点，保持一致。

### 6.3 几何（Geometry）

按图元类型动态展示：

| 图元类型 | 几何属性 |
|---|---|
| 线 / 折线 | 顶点数、总长、`Vertices` 点列表（按索引编辑每个节点） |
| 圆 | 半径、周长、面积 |
| 圆弧 | 半径、起始角、终止角 |
| 多边形 | 边数、外接圆半径、`Vertices` 点列表 |
| 二阶贝塞尔 | Start/Control/End 点 + `Control Points` 点列表 |
| 三阶贝塞尔 | Start/Control1/Control2/End 点 + `Control Points` 点列表 |
| 样条 | 次数、控制点/节点数 + `Control Points` 点列表 |
| 智能线 | 段数 |

### 6.4 图层 / 包围盒

- 图层：名称、ID、索引、颜色、可见、锁定（当前只读）
- 包围盒：Min / Max / Width / Height（只读）

---

## 7. 触发时机

`refreshPropertiesPanel()` 在以下时机被调用：

- 视口选择变化（`RenderViewport2D::selectionChanged`）
- 撤销/重做栈变化（`OperationBus::undoStateChanged`）
- 导入完成后（`ImportService` 属性刷新回调）
- 属性被编辑后（`PropertiesPanelWidget::sigPropertyEdited`，延迟重建避免编辑器提交过程重入）

---

## 8. 扩展建议

- 使图层的名称/颜色/可见/锁定可编辑：在 `Entity2DPropertyProvider` 补充对应 setter 并经图层编辑服务入撤销栈，面板无需改动。
- 多选批量编辑：`MultiEntity2DPropertyProvider` 已给出汇总模型，可扩展为批量应用。
- 自定义/替换面板：面板仅依赖 `PropertyModel` + `IPropertyEditTarget`，可通过 `UiPanelRegistry` 注册工厂替换或移除，算法层零改动。
