# 当前架构总览

> 本文只描述当前工作树中已确认的生产主路径，以及后续仍需继续收口的方向，不保留阶段性历史记录。

---

## 1. 系统分层架构

```text
SanYiCAD.exe
├── UI 层
│   ├── UICommon
│   ├── UI2D
│   └── UI3D
├── 核心层
│   ├── EngineCommon
│   ├── Engine2D
│   ├── Engine3D
│   ├── EnginePersistence
│   └── FileIO
├── 渲染层
│   └── Renderx / SanYiRender
└── 基础设施层
    ├── Utility
    ├── Log
    ├── CrashHandler
    └── License
```

## 3. 当前边界

### 3.1 渲染边界

当前生产渲染统一由 `Renderx` / `SanYiRender` 承担。

### 3.2 2D 边界

2D 生产路径为：

```text
SceneDocument2D → SceneManager → SceneGeometrySinkAdapter → RenderWidget → Renderx / SanYiRender
```

### 3.3 3D 边界

3D 生产路径以 `Workbench3D`、`Viewport3D`、`Renderer3DFactory`、`RenderWidget3DAdapter`、`RenderWidget3D`、`IRenderer3D` 组成当前链路。

### 3.4 命令边界

命令统一由 `OperationBus` 调度，菜单、工具栏、快捷键共享同一命令语义。

---

## 4. 当前约束

1. 核心层不依赖 UI。
2. 渲染层不依赖 UI 和业务真相。
3. UI 只保留入口、交互和状态同步。
4. C ABI 对外契约只暴露句柄、POD、错误码和版本约束。
5. 旧模块名只作为“已替换/已删除”的说明，不再扩展成新主线。
