# 当前架构总览

> 本文只描述当前工作树中已确认的生产主路径，以及后续仍需继续收口的方向，不保留阶段性历史记录。

---

## 1. 系统分层架构

```text
SanYiCAD.exe
├── UI 层
│   ├── UICommon
│   ├── UI2D
│   └── UI3D
├── 核心层
│   ├── EngineCommon
│   ├── Engine2D
│   ├── Engine3D
│   ├── EnginePersistence
│   └── FileIO
├── 渲染层
│   └── Renderx / RenderX
└── 基础设施层
    ├── Utility
    ├── Log
    ├── CrashHandler
    └── License
```

## 3. 当前边界

### 3.1 渲染边界

当前生产渲染统一由 `Renderx` / `RenderX` 承担。

### 3.2 2D 边界

2D 生产路径为：

```text
SceneDocument2D → SceneManager → RenderSceneBuilder (GeometryStore + DrawList) → RenderWidget → Renderx / RenderX
```

### 3.3 3D 边界

3D 生产路径以 `Workbench3D`、`Viewport3D`、`Renderer3DFactory`、`RenderWidget3DAdapter`、`RenderWidget3D`、`IRenderer3D` 组成当前链路，核心几何提交走 `RenderSceneBuilder3D`（`GeometryStore` + `DrawList`）对接 `Renderx`。

### 3.4 命令边界

命令统一由 `OperationBus` 调度，菜单、工具栏、快捷键共享同一命令语义。

---

## 4. 当前约束

1. 核心层不依赖 UI。
2. 渲染层不依赖 UI 和业务真相。
3. UI 只保留入口、交互和状态同步。
4. C ABI 对外契约只暴露句柄、POD、错误码和版本约束。
5. 旧模块名只作为“已替换/已删除”的说明，不再扩展成新主线。

## 6. 全局常量定义

### 6.1 版本信息

版本定义在 `Main/VersionInfo.h.in`（CMake 模板），由构建系统生成：

| 宏/函数 | 值 | 说明 |
|---------|-----|------|
| `APP_NAME` | "SanYiCAD" | 应用名称 |
| `APP_VERSION` | "1.0.0" | 应用版本 |
| `VERSION_MAJOR` | 1 | 主版本号 |
| `VERSION_MINOR` | 0 | 次版本号 |
| `VERSION_PATCH` | 0 | 补丁版本号 |
| `APP_ORGANIZATION_NAME` | "SanYi" | 组织名称 |
| `APP_ORGANIZATION_DOMAIN` | "sanyi-cad.com" | 组织域名 |

**访问接口：**
- `MainApp::appName()` - 应用名称
- `MainApp::appVersion()` - 应用版本字符串
- `MainApp::versionMajor()` / `versionMinor()` / `versionPatch()` - 版本号分量
- `MainApp::organizationName()` - 组织名称
- `QCoreApplication::applicationVersion()` - Qt 应用版本

### 6.2 路径定义

路径定义在 `Main/Src/Common/AppPathManager.cpp`：

| 函数 | 说明 | 典型路径 (macOS) |
|------|------|------------------|
| `AppPathManager::appLocalDataDir()` | 应用本地数据根目录 | `~/Library/Application Support/SanYiCAD/` |
| `AppPathManager::dataDir()` | 数据目录 | `~/Library/Application Support/SanYiCAD/data/` |
| `AppPathManager::configDir()` | 配置目录 | `~/Library/Application Support/SanYiCAD/config/` |
| `AppPathManager::resourcesDir()` | 资源目录 | `SanYiCAD.app/Contents/MacOS/resources/` |
| `AppPathManager::pluginsDir()` | 插件目录 | `SanYiCAD.app/Contents/MacOS/plugins/` |
| `AppPathManager::tempDir()` | 临时文件目录 | 系统临时目录 |
| `AppPathManager::logsDir()` | 日志目录 | `~/Library/Application Support/SanYiCAD/logs/` |
| `AppPathManager::crashDumpsDir()` | 崩溃转储目录 | `~/Library/Application Support/SanYiCAD/crashes/` |

**跨平台路径：**
- Windows: `C:/Users/<user>/AppData/Local/SanYiCAD/`
- macOS: `~/Library/Application Support/SanYiCAD/`
- Linux: `~/.local/share/SanYiCAD/`
