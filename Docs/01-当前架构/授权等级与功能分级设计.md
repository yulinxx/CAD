### 2.3 UiFeatureGate 解析逻辑

**文件**: `Main/Src/UI/ClientConfig/UiFeatureGate.cpp` (Line 14-55)

```cpp
void UiFeatureGate::loadFromLicenseString(const QString& featureCsv)
{
    // 支持三种分隔符: 逗号、分号、空白
    static const QRegularExpression separators(QStringLiteral("[,;\\s]+"));
    const QStringList tokens = featureCsv.split(separators, Qt::SkipEmptyParts);
    setLicensedFeatures(tokens);
}

void UiFeatureGate::setLicensedFeatures(const QStringList& features)
{
    m_features.clear();
    bool wildcard = false;

    for (const QString& raw : features)
    {
        const QString id = raw.trimmed().toLowerCase();
        if (id == "*" || id == "all")
        {
            wildcard = true;  // 全功能授权
            continue;
        }
        m_features.insert(id);  // 存入 QSet
    }

    // 通配符等价于无限制模式
    m_unrestricted = wildcard;
}
```

### 2.4 权限检查入口

**文件**: `Main/Src/UI/ClientConfig/UiFeatureGate.cpp` (Line 63-81)

```cpp
bool UiFeatureGate::isAllowed(const QString& featureId) const
{
    // 1. 空 feature 表示基础功能，不限制
    if (featureId.isEmpty())
        return true;

    // 2. 无限制模式（开发/管理员）
    if (m_unrestricted)
        return true;

    // 3. 核心检查：feature 是否在授权集合中
    const bool allowed = m_features.contains(featureId.trimmed().toLowerCase());
    return allowed;
}
```

## 7. 技术细节 FAQ

### Q: 为什么菜单隐藏而不是禁用？

**答**: `UiLayoutBuilder.cpp:44` 注释说明：
> 未授权的 UI 项直接不创建（而非禁用），避免向客户暴露未购买的功能入口

隐藏比禁用更好，不会让用户知道存在这个付费功能。

### Q: Features 字符串解析支持哪些格式？

**答**: `UiFeatureGate.cpp:17` 支持正则 `[,;\\s]+`，即：
- 逗号分隔: `nesting,vision,cam`
- 分号分隔: `nesting;vision;cam`
- 空格分隔: `nesting vision cam`
- 混用: `nesting,vision cam;3d`

### Q: 如何开启无限制模式（测试/开发）？

**答**: 不定义 `SANYI_ENABLE_LICENSE` 宏即可，或手动调用：
```cpp
UiFeatureGate::instance().setUnrestricted(true);
```

### 8.1 工具位置与用途

**位置**: `Tools/KeygenTool/`

**用途**: 内部使用，生成 RSA 密钥对和注册码。**不随主程序分发**。

### 8.2 构建方式

### 8.3 使用方法

#### 8.3.1 生成密钥对（首次使用时）

```bash
# 生成 RSA-2048 密钥对
KeygenTool genkey <private.pem> <public.pem>

# 示例
KeygenTool genkey private.pem public.pem

# 输出:
# Key pair generated:
#   Private key: private.pem
#   Public key:  public.pem
```

**注意**: 私钥必须妥善保管，仅用于生成注册码；公钥需嵌入客户端（`LicenseManager.cpp` 中的 `kPublicKey`）。

#### 8.3.2 生成注册码


## 10. 试用期功能设计

### 10.1 设计目标

让用户在首次使用软件时享有 N 天试用期（默认 30 天），试用期结束后需要激活才能继续使用。

### 10.2 试用期的三种状态

```cpp
enum class TrialStatus
{
    NotStarted,  // 刚安装，还未开始试用（首次启动后转为 Active）
    Active,      // 试用中，功能完全开放
    Expired     // 试用期已结束，需要激活
};
```

### 10.3 存储结构

**文件**: `{configDir}/trial.info`

```
start_date=2026-09-20
trial_days=30
```

**特点**:
- 首次启动时自动创建
- 试用期间用户可正常使用全部功能
- 试用期结束后强制进入激活流程

### 10.4 核心类设计

**新增文件**: `License/License/Src/TrialManager.h`

```cpp
class TrialManager
{
public:
    static TrialManager& instance();

    /// 检查试用期状态
    TrialStatus check();

    /// 剩余试用天数
    int remainingDays() const;

    /// 是否处于试用模式
    bool isInTrial() const;

    /// 试用开始日期（格式: YYYY-MM-DD）
    std::string startDate() const;

    /// 试用总天数配置
    static constexpr int kDefaultTrialDays = 30;

private:
    TrialManager() = default;
    
    /// 首次启动时初始化试用记录
    void initTrial();
    
    /// 读取试用记录文件
    bool loadTrialInfo();
    
    /// 读取当前日期
    static std::string getCurrentDate();
    
    /// 计算两个日期之间的天数差
    static int daysBetween(const std::string& date1, const std::string& date2);

    std::string m_startDate;      // 试用开始日期
    int m_trialDays = 30;        // 试用天数配置
    bool m_initialized = false;   // 是否已初始化
};
```

### 10.5 核心实现逻辑

**文件**: `License/License/Src/TrialManager.cpp`

```cpp
TrialStatus TrialManager::check()
{
    if (!m_initialized)
    {
        initTrial();  // 首次启动时创建记录
    }

    // 读取已有记录
    if (!loadTrialInfo())
    {
        return TrialStatus::NotStarted;
    }

    // 计算已用天数
    const int usedDays = daysBetween(m_startDate, getCurrentDate());

    if (usedDays >= m_trialDays)
    {
        return TrialStatus::Expired;
    }

    return TrialStatus::Active;
}

void TrialManager::initTrial()
{
    // 检查文件是否存在
    std::filesystem::path trialFile = getConfigDir() / "trial.info";
    if (std::filesystem::exists(trialFile))
    {
        return;  // 已存在，不再创建
    }

    // 首次启动，创建试用记录
    m_startDate = getCurrentDate();
    m_trialDays = kDefaultTrialDays;
    saveTrialInfo();  // 写入文件

    SY_INFO("[TrialManager] Trial started: %s, days: %d", 
            m_startDate.c_str(), m_trialDays);
}

int TrialManager::remainingDays() const
{
    const int usedDays = daysBetween(m_startDate, getCurrentDate());
    return std::max(0, m_trialDays - usedDays);
}
```

```cpp
        showLicenseDialog();  // 直接弹出激活对话框
        // 注意：不再继续正常启动流程
    }
    else if (trialStatus == TrialStatus::Active)
    {
        // 试用期间，设置无限制模式
        UiFeatureGate::instance().setUnrestricted(true);
        
        // 显示试用提示
        SY_INFO("[CADApplicationRuntime] Trial active, %d days remaining", 
                trial.remainingDays());
        
        // 可选：显示试用提示对话框
        showTrialTipDialog(trial.remainingDays());
    }
    // NotStarted 状态会在 initTrial 后转为 Active，继续正常流程

    // ... 原有 License 检查代码保持不变 ...
}
```

### 10.9 防绕过方案（可选增强）

#### 问题说明

用户删除 `trial.info` 文件即可无限试用，这是明显的漏洞。

#### 方案对比

| 方案 | 说明 | 防删除 | 防换机 | 复杂度 |
|------|------|:------:|:------:|--------|
| **A. 本地文件** | 仅靠 trial.info | ❌ | ❌ | 低 |
| **B. 注册表绑定** | 首次写入注册表 + 文件双重校验 | ✅ | ❌ | 中 |
| **C. 机器指纹绑定** | 记录 machineCode + 日期 | ✅ | ✅ | 中 |
| **D. 强制激活** | 首次启动必须联网激活 | ✅ | ✅ | 高 |

#### 推荐：方案 C（机器指纹绑定）

```cpp
// TrialManager.h - 防绕过增强版
class TrialManager
{
public:
    static TrialManager& instance();
    TrialStatus check();

private:
    // 新增方法
    void initTrialWithBinding();      // 首次启动时绑定机器
    bool validateTrialRecord();       // 校验记录有效性
    bool checkMachineMatch();        // 检查机器指纹是否匹配
    bool saveToRegistry();           // 写入注册表
    bool loadFromRegistry();         // 读取注册表
};
```

```cpp
// TrialManager.cpp - 实现

#ifdef _WIN32
    #include <windows.h>
#endif

void TrialManager::initTrialWithBinding()
{
    std::filesystem::path trialFile = getConfigDir() / "trial.info";
    
    // 1. 检查文件和注册表是否都存在
    if (std::filesystem::exists(trialFile) && loadFromRegistry())
    {
        // 已有记录，进一步验证
        if (validateTrialRecord())
        {
            return; // 有效试用
        }
    }
    
    // 2. 首次启动，创建绑定记录
    m_startDate = getCurrentDate();
    m_trialDays = kDefaultTrialDays;
    m_machineCode = MachineFingerprint::Generate();
    
    // 写入文件
    saveTrialInfo();
    
    // 写入注册表（防删除）
    saveToRegistry();
    
    SY_INFO("[TrialManager] Trial initialized with machine binding");
}

bool TrialManager::validateTrialRecord()
{
    // 必须文件和注册表都存在
    if (!std::filesystem::exists(getConfigDir() / "trial.info"))
        return false;
    
    if (!loadFromRegistry())
        return false;
    
    // 机器指纹必须匹配
    if (!checkMachineMatch())
        return false;
    
    // 检查日期有效性
    return checkDateValid();
}

bool TrialManager::checkMachineMatch()
{
    std::string currentMachine = MachineFingerprint::Generate();
    return currentMachine == m_machineCode;
}

bool TrialManager::saveToRegistry()
{
#ifdef _WIN32
    HKEY hKey;
    if (RegCreateKeyExW(HKEY_CURRENT_USER, L"Software\\SanYiCAD\\Trial", 
        0, nullptr, 0, KEY_WRITE, nullptr, &hKey, nullptr) == ERROR_SUCCESS)
    {
        // 写入开始日期
        std::wstring date = Utf8ToWideChar(m_startDate);
        RegSetValueExW(hKey, L"start_date", 0, REG_SZ, 
            (const BYTE*)date.c_str(), (date.length() + 1) * 2);
        
        // 写入机器指纹
        std::wstring machine = Utf8ToWideChar(m_machineCode);
        RegSetValueExW(hKey, L"machine_hash", 0, REG_SZ, 
            (const BYTE*)machine.c_str(), (machine.length() + 1) * 2);
        
        // 写入试用天数
        DWORD days = m_trialDays;
        RegSetValueExW(hKey, L"trial_days", 0, REG_DWORD, 
            (const BYTE*)&days, sizeof(days));
        
        RegCloseKey(hKey);
        return true;
    }
#endif
    return false;
}
```
