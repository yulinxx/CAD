# 数据库架构

## 概述

SanYiCAD 使用 SQLite 作为本地持久化存储，主要存储以下数据：
- 用户设置（字体、主题、语言、日志级别等）
- 最近文件列表
- 工作区布局快照
- 图层信息
- 文档元数据

## 数据库文件位置

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/SanYiCAD/data/cad_database.sqlite` |
| Windows | `C:/Users/<user>/AppData/Local/SanYiCAD/data/cad_database.sqlite` |
| Linux | `~/.local/share/SanYiCAD/data/cad_database.sqlite` |

数据库文件在首次使用时自动创建，使用默认配置。

## 核心表结构

### 1. settings_common - 用户通用设置

存储用户界面偏好设置。

| 列名 | 类型 | 说明 |
|------|------|------|
| key | TEXT | 设置键（如 `common/log_level`） |
| value | TEXT | 设置值（字符串形式存储） |
| type | TEXT | 数据类型（`string`/`int`/`bool`/`float`/`double`） |

**常用设置键：**

| 键名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `common/font_size` | int | 10 | 字体大小 |
| `common/font_family` | string | "" | 字体名称 |
| `common/language` | int | 0 | 语言代码 |
| `common/theme` | int | 0 | 主题（0=Light, 1=Dark） |
| `common/log_enabled` | bool | true | 日志开关 |
| `common/log_level` | int | 2 | 日志级别（0=Trace, 1=Debug, 2=Info, 3=Warn, 4=Error, 5=Critical, 6=Off） |

### 2. recent_files - 最近文件

| 列名 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| file_path | TEXT | 文件完整路径 |
| file_name | TEXT | 文件名 |
| file_type | TEXT | 文件类型扩展名 |
| last_access_time | TEXT | 最后访问时间（ISO 8601） |

### 3. workspace_snapshots - 工作区布局快照

| 列名 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| workbench_id | TEXT | 工作台 ID（如 `2D`、`3D`） |
| client_id | TEXT | 客户端 ID |
| snapshot_data | BLOB | 布局快照数据（JSON） |
| created_at | TEXT | 创建时间 |

### 4. layers - 图层信息

| 列名 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| document_id | INTEGER | 所属文档 ID |
| layer_id | INTEGER | 图层运行时 ID |
| name | TEXT | 图层名称 |
| visible | INTEGER | 可见性（0/1） |
| locked | INTEGER | 锁定状态（0/1） |
| color | TEXT | 图层颜色（#RRGGBB） |
| line_width | REAL | 线宽 |
| line_style | TEXT | 线型 |
| fill | INTEGER | 填充标志（0/1） |
| fill_color | TEXT | 填充颜色 |

### 5. documents - 文档元数据

| 列名 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| file_path | TEXT | 文件路径 |
| file_hash | TEXT | 文件哈希 |
| title | TEXT | 文档标题 |
| created_at | TEXT | 创建时间 |
| modified_at | TEXT | 修改时间 |

### 6. app_meta - 应用元数据

| 列名 | 类型 | 说明 |
|------|------|------|
| key | TEXT | 键名 |
| value | TEXT | 值 |

**重要键：**
- `schema_version`: 数据库 schema 版本号

### 核心类说明

#### IDatabase

跨模块数据库接口，特点：
- 纯 C 接口，无 STL 跨 DLL 问题
- 使用回调函数处理查询结果
- 支持事务（RAII 包装）

```cpp
// 典型用法
IDatabase* db = ...;
db->insert("settings_common", pairs, count);

// 事务用法
DatabaseTransaction tx(*db);
db->execute("INSERT INTO ...");
tx.commit();
```

#### ISettingsRepository

设置仓储接口，定义：
- `loadTable(tableName)`: 加载整张表
- `saveTable(tableName, data)`: 保存整张表
- `registerTable(tableName)`: 注册表结构

#### SettingsPersistenceHelper

设置表读写辅助类：
- `loadCommon()`: 加载公共设置
- `saveCommon(data)`: 保存公共设置
- `applyCommonSettings(data)`: 应用设置到运行时

#### SettingsService

用户设置服务：
- 管理所有 UI 设置的读写
- 提供类型安全的 get/set 接口
- 处理默认值的逻辑

## 使用示例

### 读取设置

```cpp
// 通过 SettingsService 读取
auto* settings = ApplicationCompositionRoot::getSettingsService();
int fontSize = settings->getFontSize();
AppTheme theme = settings->getTheme();
```

### 保存设置

```cpp
// 用户修改设置后保存
auto* settings = ApplicationCompositionRoot::getSettingsService();
settings->setFont(family, size);
settings->setTheme(darkTheme);
settings->setLanguage(chinese);
```

### 直接操作数据库

```cpp
// 创建新表
m_database->execute(R"(
    CREATE TABLE IF NOT EXISTS my_table (
        id INTEGER PRIMARY KEY,
        name TEXT,
        value INTEGER
    )
)");

// 插入数据
KvPair rows[] = {
    { "name", "test" },
    { "value", "42" }
};
m_database->insert("my_table", rows, 2);

// 查询数据
m_database->query("SELECT * FROM my_table", callback, userData);
```

## 设计原则

### 1. 单一数据库文件

所有持久化数据存储在同一个 SQLite 文件中：
- 避免数据分散
- 简化备份和迁移
- 保证数据一致性

### 2. 自动创建默认值

数据库初始化时：
- 自动创建所有必要的表
- 使用默认值填充缺失的设置
- 允许数据库文件不存在

### 3. 错误容忍

数据库错误处理原则：
- 数据库初始化失败不阻塞应用启动
- 使用默认值作为降级策略
- 记录错误日志但不抛异常

### 4. 接口安全

- 使用 RAII 管理资源（事务、连接）
- 参数验证防止 SQL 注入
- 类型安全的数据转换

## 扩展指南

### 添加新设置

1. 在 `SettingsPersistenceHelper.h` 中定义键常量：

```cpp
static constexpr const char* KEY_NEW_SETTING = "common/new_setting";
```

2. 在 `SettingsService` 中添加访问方法：

```cpp
int getNewSetting() const;
void setNewSetting(int value);
```

3. 在 `GeneralSettingsTab` 中添加 UI 控件

### 添加新表

1. 在 `DatabaseBootstrapper.cpp` 中添加建表语句：

```cpp
std::string sql = R"(
    CREATE TABLE IF NOT EXISTS my_table (
        id INTEGER PRIMARY KEY,
        name TEXT,
        value INTEGER DEFAULT 0
    )
)";
```

2. 如需持久化，在对应 Service 中添加 CRUD 方法

## 常见问题

### Q: 数据库文件在哪里？
A: 见上文「数据库文件位置」

### Q: 如何重置所有设置？
A: 删除数据库文件后重新启动，应用会使用默认设置创建新数据库

### Q: 设置不生效？
A:
1. 确认保存成功（检查返回值）
2. 确认数据库路径正确
3. 检查日志输出中的错误信息
4. 尝试重启应用

### Q: 数据库损坏怎么办？
A:
1. 备份现有数据库文件
2. 删除损坏的数据库
3. 重新启动应用（会自动创建新数据库）
