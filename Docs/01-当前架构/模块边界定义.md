# 模块边界定义

## 概述

本文档定义各模块之间的边界、依赖关系和通信协议，确保模块间职责清晰、耦合度低。

## 2. 模块边界详细定义

### 2.1 UICommon

**职责**：UI 公共基础设施

| 边界 | 规则 |
|------|------|
| **依赖** | Utility, Log, Qt |
| **不依赖** | Engine2D, Engine3D, Render2D, Render3D |
| **对外提供** | 主题、布局、状态中心、服务注册、公共枚举 |
| **禁止** | 业务逻辑、渲染实现、具体工具定义 |

**关键文件**：
- `UI/Common/Include/UI/Command/OperationId.h` — 公共操作枚举
- `UI/Common/Include/UI/Command/OperationBusBase.h` — 公共操作总线基类
- `UI/Common/Include/UI/Command/OperationTypes.h` — 公共操作类型

---

### 2.2 UI2D

**职责**：2D 绘图界面和交互。当前 2D 生产路径应收口到 `Render/2D/` + `RenderWidget`，`Viewport2D` 作为兼容/历史实现保留并已标记为 `deprecated`。新开发不要再往 `Viewport2D` 增加生产逻辑。

| 边界 | 规则 |
|------|------|
| **依赖** | UICommon, Engine2D, Render2D, Qt |
| **不依赖** | Engine3D, Render3D, UI3D |
| **对外提供** | 2D 视口、工具系统、命令系统、文档视图 |
| **禁止** | 3D 业务逻辑、跨模块状态管理 |

**关键文件**：
- `UI/2D/Src/Ui/ViewWidget/ViewWidget.h` — 2D 视图控件
- `UI/2D/Src/Ui/DrawTools/ToolManager.h` — 工具管理器
- `UI/2D/Src/Operation/OperationBus.h` — 操作总线

---

### 2.3 UI3D

## 3. 跨模块通信协议

### 3.1 UI → Engine

通过 **构造函数注入** 模式：
```cpp
// UI2D 通过 OperationContext 获取 Engine2D 服务
Eg::SceneManager* sm = ctx.sceneManager;
```

### 3.2 UI → Render

通过 **RenderWidget** 直接调用：
```cpp
// UI 通过 RenderWidget 与渲染层通信
renderWidget->setPreviewPoints(points, count);
renderWidget->setControlLines(lines, count);
```

### 3.3 Engine → Render

通过 **纯 C++ 接口**：
```cpp
// Engine 通过 RenderTypes 和 SceneCompiler 与渲染层通信
SceneCompiler::compile(document, renderData);
```

### 3.4 2D ↔ 3D

通过 **UICommon 公共枚举**：
```cpp
// 共享操作 ID 和操作来源定义
using OperationId = Cmd::OperationId;
using OperationSource = Cmd::OperationSource;
```

## 5. ABI 安全边界

以下模块提供 **纯 C ABI**：

| GeoModelCore | `GeoModelDLL.h` | `GeoModelHandle` |
| Engraving | `EngravingCAPI.h` | `EngravingVolumeHandle`（类型安全） |

| RenderNext | `CAPI.h` | `RNWorldImpl*` |

## 7. 命令处理器拆分（2026-07-11 更新）

原 `UiCommandHandler.cpp`（约 2700 行）已拆分为多个独立文件，各文件职责明确：

| 文件 | 职责 | 依赖 |
|------|------|------|
| `CreateCommands.h/cpp` | 创建命令（DrawLine、Circle、Arc、Polyline、Polygon）及对应 UndoCommand | OperationBus, SceneDocument2D |
| `TransformCommands.h/cpp` | 变换命令（Move、Rotate、Copy、Delete、Mirror）及对应 UndoCommand | OperationBus, SceneDocument2D |
| `SelectCommands.h/cpp` | 选择命令（Select）及对应 UndoCommand | OperationBus, SceneDocument2D |
| `CommandSnapshots.h/cpp` | 快照辅助函数（takeSnapshot、restoreFromSnapshot） | OperationBus, SceneDocument2D |
| `CommandGeometry.h/cpp` | 几何变换辅助函数（rotatePoint、mirrorPoint） | OperationBus |

### 7.1 拆分原则

1. **命令系统架构**：各命令通过 OperationBus 注册为 Operation，公共接口定义在各 Command 头文件中
2. **功能分组**：创建命令、变换命令、选择命令分别独立
3. **辅助函数抽取**：快照和几何变换逻辑独立为公共工具

### 7.2 新增接口

#### IUndoStack 刷新回调

```cpp
class IUndoStack
{
public:
    using RefreshCallback = std::function<void()>;
    virtual void setRefreshCallback(RefreshCallback callback) = 0;
};
```

`DefaultUndoStack` 在 `push()`、`undo()`、`redo()` 时触发回调，支持视图增量刷新。

#### EntitySnapshot 结构

```cpp
struct EntitySnapshot
{
    QString id;           // 图元 ID
    int type;             // 图元类型
    QPointF basePoint;    // 基点
    QVector<QPointF> points;  // 顶点列表
    double radius;        // 半径（圆/弧）
    double startAngle;    // 起始角度（弧）
    double endAngle;      // 终止角度（弧）
    bool closed;          // 是否闭合（多边形）
    bool ccw;             // 逆时针方向（多边形缠绕顺序）
};
```
