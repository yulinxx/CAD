# 模块边界定义

本文只描述当前模块边界与约束，不保留历史记录。

---

## 1. 模块分层

```text
应用层: Main
UI 层: UICommon / UI2D / UI3D
核心层: EngineCommon / Engine2D / Engine3D / EnginePersistence
渲染层: Renderx / SanYiRender
基础设施层: Utility / Log / CrashHandler / License
扩展模块: FileIO / Nesting / Hardware / Network / Vision / Engraving / GeoModelCore / PythonHost / PyBindCore
```

---

## 2. 当前模块职责

### 2.1 UICommon

负责 UI 公共基础设施：主题、布局、状态中心、服务注册。

### 2.2 UI2D

负责 2D 绘图入口、工具系统、命令系统、视口宿主与交互。

### 2.3 UI3D

负责 3D 场景入口、场景树、属性面板、相机控制和 3D 工作台组织。

### 2.4 Engine2D

负责 2D 几何、图元、拓扑、布尔运算、约束求解。

### 2.5 Engine3D

负责 3D 几何、BRep、网格、布尔、投影。

### 2.6 Renderx / SanYiRender

负责统一渲染管线、Shader、OpenGL/Vulkan/Metal 后端，当前生产目标为 `SanYiRender`。

### 2.7 FileIO

负责导入导出与文档序列化。

---

## 3. 当前边界规则

1. 核心层不依赖 UI。
2. 渲染层不依赖 UI 和业务状态。
3. UI 通过适配层连接渲染层，不直接操纵渲染内部实现。
4. C ABI 边界只暴露句柄、POD 和明确错误约束。
