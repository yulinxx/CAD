# 渲染与视口边界

本文只描述当前可用的渲染与视口边界，不保留旧路径的阶段记录。

---

## 1. 当前边界概览

### 1.1 UI 层

UI 层负责：

- 接收输入
- 管理窗口与视口
- 展示状态
- 发起刷新请求

### 1.2 适配层

适配层负责：

- 把文档几何转换为渲染层可消费的数据
- 把 UI 事件与渲染层状态连接起来
- 维持 UI 与渲染之间的语义边界

### 1.3 渲染层

渲染层负责：

- 接收几何
- 批次组织
- 资源管理
- GPU 绘制

---

## 2. 当前生产路径

### 2.1 2D

```text
SceneDocument2D
→ SceneManager
→ RenderSceneBuilder (GeometryStore + DrawList)
→ RenderWidget
→ Renderx / RenderX
→ Screen
```

### 2.2 3D

```text
SceneDocument3D / SceneManager3D
→ Viewport3D / RenderWidget3DAdapter
→ RenderSceneBuilder3D (GeometryStore + DrawList)
→ RenderWidget3D / IRenderer3D
→ Renderx / RenderX
→ Screen
```

---

## 3. 当前约束

1. UI 不直接实现渲染核心。
2. 适配层只做转换，不做业务编排。
3. 渲染层只负责 GPU 输出，不持有文档真相。
4. 旧命名只作为已删除或已替换组件的提示，不再扩展。
