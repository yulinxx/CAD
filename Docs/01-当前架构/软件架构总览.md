# SanYiCAD 软件架构文档

本文档全面介绍 SanYiCAD 软件系统的整体架构设计，涵盖技术栈、模块划分、依赖关系、核心流程等。

---

## 1. 产品概述

### 1.1 软件定位

**SanYiCAD** 是一款面向工业制造领域的计算机辅助设计软件，主要用于激光切割、数控加工、3D建模等场景。

### 1.2 适用场景

| 场景 | 描述 |
|------|------|
| **激光切割** | 2D图纸设计、排样、激光加工路径生成 |
| **CNC加工** | 刀路规划、轨迹优化、G代码生成 |
| **3D建模** | 3D几何创建、网格处理、雕刻设计 |
| **视觉检测** | 图像处理、轮廓识别、定位引导 |
| **文件兼容** | DXF/SVG/PDF/STEP等多种格式导入导出 |

### 1.3 运行环境

| 项目 | 要求 |
|------|------|
| **操作系统** | Windows 10/11 (x64), macOS 11+ (Apple Silicon/Intel), Linux (Ubuntu 20.04+) |
| **开发环境** | CMake 4.3+, Qt 6.x, C++20 |
| **显卡** | 支持 OpenGL 4.6 / Metal |
| **内存** | 推荐 16GB+ |
| **磁盘** | SSD 推荐 |

## 6. 关键设计模式

### 6.1 观察者模式

```cpp
// SceneNotifier - 场景变更广播
class SceneNotifier {
    std::vector<IObserver*> m_observers;

public:
    void addObserver(IObserver* obs) { m_observers.push_back(obs); }
    void notifySceneChanged() {
        for (auto* obs : m_observers) {
            obs->onSceneChanged();  // 通知所有观察者
        }
    }
};
```

```cpp
// FileParserFactory - 解析器工厂
class FileParserFactory {
    std::map<FileFormat, CreatorFunc> m_creators;

    }
};
```
