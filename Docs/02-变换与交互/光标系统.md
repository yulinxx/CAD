# 光标（鼠标指针）系统

本文描述 2D/3D 视口共用的光标系统：分层职责、角色语义、皮肤解析、捕捉命中时的隐藏策略，
以及扩展 / 替换方式。核心位于 `UI/Common`，2D 视口已接入，3D 可复用同一套。

---

## 1. 设计目标

- **语义与图形解耦**：工具/视口只说「现在是什么交互」（角色），不关心光标长什么样。
- **可替换**：换皮肤、换图、换实现（SVG → PNG → 平台内置）只换一个 `ICursorTheme`。
- **高内聚**：`CursorManager` 只管「角色 + 目标控件 + 皮肤刷新」；`ICursorTheme` 只管「角色 → QCursor」。
- **低耦合**：新增交互状态只加一个枚举值；新增皮肤只加一套同名资源目录，不动代码。
- **复用**：核心不依赖任何具体视口，2D / 3D 都能挂。

---

## 2. 分层结构

```text
┌──────────────────────────────────────────────────────────────────┐
│ 调用方（工具 / 视口）                                             │
│   IToolBase::cursorRole()  →  UI::CursorRole（语义）              │
│   RenderViewport2D::syncCursorRole() 合成最终角色                 │
└───────────────────────────────┬──────────────────────────────────┘
                                │ setRole() / setHidden()
                                ▼
┌──────────────────────────────────────────────────────────────────┐
│ UI::CursorManager（协调层，QObject）                              │
│   - 持有目标控件 QPointer<QWidget>                                │
│   - 持有可替换主题 std::unique_ptr<ICursorTheme>                  │
│   - 监听 ThemeManager::themeChanged → invalidate + apply          │
│   - effective = hidden ? Hidden : role                            │
└───────────────────────────────┬──────────────────────────────────┘
                                │ cursorFor(role)
                                ▼
┌──────────────────────────────────────────────────────────────────┐
│ UI::ICursorTheme（解析层，接口）                                  │
│   UI::SvgCursorTheme（默认实现）                                  │
│     - 角色 → 资源文件名 → 按皮肤 flavor 覆盖解析路径              │
│     - 用 ThemeManager 语义色令牌（%fg%/%bg%/%accent%）着色        │
│     - QSvgRenderer 栅格化 → QCursor(pixmap, hotspot)             │
└──────────────────────────────────────────────────────────────────┘
```

关键约束：`CursorManager::setTargetWidget` 必须传**鼠标下的那个控件**。
2D 里是 `RenderWidget`（QOpenGLWidget 子控件），不是包着它的 `RenderViewport2D`——
Qt 按指针下的控件取光标，设在外层会被子控件默认光标覆盖。

## 3. 光标角色（语义层）

`UI/Common/Include/UI/CursorRole.h`：

| 角色 | 语义 | 典型触发 |
|------|------|----------|
| `Default` | 系统箭头 | 对话框类工具、无交互 |
| `Select` | 选择 | `SelectTool` 空闲 |
| `Crosshair` | 绘制 / 精确落点 | 所有绘图工具（`BaseTool` 默认） |
| `Precision` | 高精度绘制 | 预留（小十字） |
| `Move` | 移动对象 | 拖拽选择框内部 |
| `Rotate` | 旋转 | 拖拽旋转手柄 |
| `Scale` | 缩放 | 拖拽角/边缩放手柄 |
| `Pan` | 平移模式（可抓取） | 平移模式开启 |
| `Panning` | 平移进行中 | 空格/中键/平移模式拖拽中 |
| `Text` | 文本输入 | `TextEditTool` |
| `ZoomIn` / `ZoomOut` | 放大 / 缩小 | 预留 |
| `Hidden` | 隐藏 | **捕捉命中时**（见 §5） |

新增一种交互状态：在枚举里加一项，并在主题里提供同名 SVG 即可；工具只返回新角色。

## 4. 角色如何被合成

`RenderViewport2D::syncCursorRole()` 的优先级（从高到低）：

```text
1. 平移进行中            → Panning
2. 平移模式开启          → Pan
3. 当前工具 cursorRole()  → 选择 / 绘制 / 文字 / 移动 / 缩放 / 旋转…
4. 兜底                  → Default

再叠加隐藏：hidden = 捕捉命中 && 非平移态
```

调用时机（保证状态一变光标就变）：

- `applySnap()` 每次算出 `didSnap` 后；
- `eventFilter()` 在事件派发后（`Enter/Leave/MouseMove/MouseButton*/Wheel`）；
- `setActiveTool()` 切换工具后；
- `setPanModeEnabled()` 切换平移模式后。

工具侧只覆写一个方法，例如：

```cpp
// BaseTool.h：所有绘图工具默认十字
UI::CursorRole cursorRole() const override { return UI::CursorRole::Crosshair; }

// SelectTool.cpp：按 Gizmo 当前手柄返回
UI::CursorRole SelectTool::cursorRole() const
{
    switch (m_gizmo->activeHandle()) {
    case SelectionGizmo::HandleKind::Body:   return UI::CursorRole::Move;
    case SelectionGizmo::HandleKind::Rotate: return UI::CursorRole::Rotate;
    // 角/边手柄
    default:                                 return UI::CursorRole::Scale;
    }
}
```

## 5. 捕捉命中时隐藏光标

需求：捕捉成功后已经画出捕捉标记，光标再压在标记上会挡住它。

- `RenderViewport2D::applySnap()` 在算出 `didSnap` 后写入 `m_snapCursorHidden`；
- `syncCursorRole()` 里 `setHidden(m_snapCursorHidden && !panning)`；
- `CursorRole::Hidden` 由 `SvgCursorTheme` 解析为 `Qt::BlankCursor`。

两个边界：

- 平移时不隐藏（手型必须可见），即使上一帧处于捕捉命中；
- 快速移动跳过捕捉的分支会清除隐藏，避免「光标莫名消失」。

## 6. 皮肤（主题）适配

`SvgCursorTheme` 的路径解析与 `IconHelper` 的图标覆盖规则一致：

```text
<prefix>/<flavor>/<role>.svg    ← 优先（flavor 来自 ThemeManager::iconFlavor()）
<prefix>/<role>.svg             ← 回退（默认集）
```

- 默认前缀：`:/ui/common/Cursors/`
- 颜色：SVG 内用 `%fg%`（描边）/ `%bg%`（填充）/ `%accent%`（强调）等令牌，
  渲染前按当前 `ThemeColors` 替换。因此同一张 SVG 在 Light / Dark / Blue / Slate /
  HighContrast 下自动得到双色对比（深色描边 + 浅色填充，或反之）。
- 想让某皮肤用完全不同的图形：在 `Resources/Cursors/<flavor>/` 放同名 SVG 覆盖即可。

新增一个角色图形：

1. `Resources/Cursors/<role>.svg`（viewBox `0 0 32 32`）；
2. `ui_common.qrc` 登记；
3. 在 `SvgCursorTheme.cpp` 的 `roleFileName` / `roleHotspot` 各加一项。

## 7. 替换与扩展

| 想做的事 | 做法 |
|----------|------|
| 换一套内置形状 | 换 `ICursorTheme` 实现，`CursorManager::setTheme()` |
| 换成 PNG 位图光标 | 实现 `PixmapCursorTheme : ICursorTheme`，加载 PNG + 热点 |
| 某皮肤换图 | 放 `Cursors/<flavor>/*.svg` 覆盖目录 |
| 新增交互状态 | `CursorRole` 加枚举 + 主题提供图形 + 工具返回 |
| 3D 复用 | `RenderWidget3D` 也持有 `CursorManager`，目标设为 3D 控件 |

`CursorManager` 不依赖任何具体视口，也不依赖 2D/3D，故可直接复用。

## 9. 已知边界

- 当前 `SelectTool` 只在**拖拽手柄**时区分 Move/Rotate/Scale；悬停未按下时仍是 `Select`
  （Gizmo 未暴露悬停手柄类型，后续可在 `onMouseMove` 中判定并返回更细的角色）。
- `ZoomIn` / `ZoomOut` / `Precision` 已定义并提供了图形，但尚未有工具返回它们。
