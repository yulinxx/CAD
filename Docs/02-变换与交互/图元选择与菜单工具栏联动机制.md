# 图元选择与菜单/工具栏联动机制

## 1. 概述

本文档详细描述 2D 工作台中，当用户选择（或取消选择）图元时，菜单栏和顶部工具栏的按钮启用状态如何实时联动的完整技术流程。

---

## 2. 核心概念

### 2.1 命令中枢 (CommandActionHub)

`CommandActionHub` 是整个 UI 命令系统的核心枢纽，负责：
- 托管所有命令的 QAction（菜单项、工具栏按钮）
- 维护命令启用状态的单一事实来源 (`CommandUiSnapshot`)
- 处理命令分发（点击后执行什么操作）

### 2.2 命令 UI 快照 (CommandUiSnapshot)

`CommandUiSnapshot` 是选择状态的单一事实来源，包含：

```cpp
struct CommandUiSnapshotBase
{
    bool hasSelection{ false };      // 是否有选中图元
    int selectionCount{ 0 };        // 选中的图元数量
    bool hasClipboard{ false };    // 剪贴板是否有内容
    bool canUndo{ false };         // 撤销栈是否可撤销
    bool canRedo{ false };         // 重做栈是否可重做

    // 锁定维度
    bool anyLockedLayer{ false };    // 选中的图元是否位于锁定图层
    bool anyLockedEntity{ false };   // 选中的图元本身是否被锁定
    bool anyEditable{ false };       // 是否有可编辑的图元
    bool anyHidden{ false };         // 是否有隐藏的图元

    // 类型直方图（用于工具栏上下文切换）
    uint32_t typeMask{ 0 };

    // 辅助方法
    bool anyLocked() const { return anyLockedLayer || anyLockedEntity; }
};
```

### 2.3 命令目录 (CommandCatalog)

`CommandCatalog` 定义了所有命令的元数据，包括：
- 命令 ID（如 `edit.delete`、`edit.mirror_horizontal`）
- 启用规则 (`CommandEnable2D`)

```cpp
enum class CommandEnable2D : uint8_t
{
    Always = 0,                      // 始终可用
    RequiresSelection = 1,           // 需要有选中图元
    RequiresMultiSelection = 2,      // 需要多选（>=2）
    RequiresClipboard = 3,           // 需要剪贴板有内容
    RequiresUndo = 4,               // 需要可撤销
    RequiresRedo = 5,               // 需要可重做
    RequiresUnlockedSelection = 6,   // 需要选中且未锁定
    RequiresUnlockedMultiSelection = 7, // 需要多选且未锁定
    RequiresVisibleSelection = 100,      // 需要选中且可见（无锁定无隐藏）
    RequiresVisibleMultiSelection = 101   // 需要多选且可见
};
```

## 4. 关键代码路径

### 4.1 状态提供器注入

在 `Workbench2D::createToolbars()` 中：

```cpp
// 1. 注入选择上下文提供器
m_commandHub->setSelectionContextProvider([selectionService = m_services.selectionService,
                                          layerManager = m_services.layerManager,
                                          sceneEditService = m_services.sceneEditService]() -> SelectionContext {
    // 遍历选中图元，计算 selectionCount / anyLockedLayer / anyLockedEntity / anyHidden
    SelectionContext result;
    // ...
    result.hasSelection = result.selectionCount > 0;
    result.groupEnabled = result.hasSelection && !(result.anyLockedLayer || result.anyLockedEntity || result.anyHidden);
    return result;
});

// 2. 注入撤销/重做状态提供器
m_commandHub->setUndoRedoProvider([undoManager = m_services.undoManager]() -> UndoRedoState {
    UndoRedoState state;
    if (undoManager) {
        state.canUndo = undoManager->canUndo();
        state.canRedo = undoManager->canRedo();
    }
    return state;
});

// 3. 注入剪贴板状态提供器
m_commandHub->setClipboardProvider([clipboard = m_services.clipboard]() -> bool {
    return clipboard && clipboard->hasContent();
});
```

### 4.2 按钮创建与 commandId 设置

`createEditAction()` 必须设置 `commandId` 属性，否则 `applySnapshotToAction()` 会跳过该按钮：

```cpp
QAction* CommandActionHub::createEditAction(const CommandEntry2D& entry)
{
    QAction* action = new QAction(parentWidget);
    action->setText(...);
    action->setData(static_cast<int>(entry.menuId));

    // 关键：必须设置 commandId 属性！
    if (entry.shortcutId)
    {
        const QString commandId = QString::fromUtf8(entry.shortcutId);
        action->setProperty("commandId", commandId);
        action->setObjectName(commandId);
    }
    // ...
}
```

### 4.3 启用规则判断

`applySnapshotToAction()` 中的规则判断：

```cpp
void CommandActionHub::applySnapshotToAction(QAction* action, const CommandUiSnapshot& snapshot)
{
    // 从 commandId 反查目录条目
    const QString commandId = action->property("commandId").toString();
    const UI::MenuActionId menuId = CommandCatalog::menuIdForCommandId(commandId);
    const CommandEntry2D* entry = CommandCatalog::findByMenuId(menuId);

    // 根据 enableRule 计算 enabled
    if (entry->enableRule == CommandEnable2D::RequiresVisibleSelection)
    {
        const bool enabled = snapshot.hasSelection && !snapshot.anyLocked() && !snapshot.anyHidden;
        action->setEnabled(enabled);
        return;
    }
    if (entry->enableRule == CommandEnable2D::RequiresVisibleMultiSelection)
    {
        const bool enabled = snapshot.selectionCount >= 2 && !snapshot.anyLocked() && !snapshot.anyHidden;
        action->setEnabled(enabled);
        return;
    }
    // ... 其他规则
}
```

## 5. 刷新触发源

所有 UI 刷新都通过 `UiStateBridge2D::install()` 统一挂载：

| 触发源 | 信号 | 刷新动作 |
|--------|------|----------|
| 用户选择图元 | `RenderViewport2D::selectionChanged` | 刷新所有按钮 |
| 锁定/解锁图层 | `QtLayerManagerBridge::sigLayerChanged` | 刷新锁定相关按钮 |
| 撤销/重做 | `OperationBus::undoStateChanged` | 刷新撤销/重做按钮 |
| 操作完成 | `OperationBus::operationCompleted` | 刷新所有按钮 |
| 场景变化 | `SceneMonitor::sceneChanged` | 刷新所有按钮 |

## 6. 常见问题排查

### 6.1 按钮总是亮着（不变灰）

可能原因：
1. **commandId 未设置**：`createEditAction()` 未设置 `commandId` 属性 → `applySnapshotToAction()` 直接返回
2. **enableRule 配置错误**：使用了 `Always` 而不是 `RequiresVisibleSelection`
3. **selectionContextProvider 未注入**：快照中 `hasSelection` 始终为默认值 `false`
4. **捕获快照时 m_mainWindow 为空**：导致快照所有字段都是默认值

### 6.2 按钮一直是灰的

可能原因：
1. **undoManager 未注入**：`ApplicationCompositionRoot` 未设置 `uiServices.undoManager`
2. **selectionContextProvider 返回错误值**：比如 `selectionCount` 始终为 0
3. **snapshot.anyLocked() 始终为 true**：检查图层锁定状态是否正确

### 6.3 菜单和工具栏状态不一致

可能原因：
1. **菜单使用了旧代码路径**：菜单应该通过 `WorkbenchMenuManager::refreshCommandStates()` 刷新
2. **工具栏按钮未注册到中枢**：导致创建了非托管 QAction

## 7. 本次 Bug 修复总结

### 7.1 问题 1：Group 按钮总是亮着

**原因**：
1. `CommandCatalog.cpp` 中 Group 的 `enableRule` 错误配置为 `Always`
2. `UiWorkbench.cpp` 中 `groupEnabled` 计算缺少 `hasSelection` 检查

**修复**：
```diff
// CommandCatalog.cpp
- CommandEnable2D::Always
+ CommandEnable2D::RequiresVisibleSelection

// UiWorkbench.cpp
- result.groupEnabled = !(result.anyLockedLayer || result.anyLockedEntity || result.anyHidden);
+ result.groupEnabled = result.hasSelection && !(result.anyLockedLayer || result.anyLockedEntity || result.anyHidden);
```

### 7.2 问题 2：Mirror/Align/Copy/Delete 按钮总是亮着

**原因**：
1. `createEditAction()` 未设置 `commandId` 属性，导致 `applySnapshotToAction()` 中的检查失败
2. `refreshEditActionStates()` 使用了错误的模板函数，无法处理扩展的 `RequiresVisibleSelection` 规则

**修复**：
```diff
// createEditAction() 中添加
+ if (entry.shortcutId)
+ {
+     const QString commandId = QString::fromUtf8(entry.shortcutId);
+     action->setProperty("commandId", commandId);
+     action->setObjectName(commandId);

// refreshEditActionStates() 改为直接调用 applySnapshotToAction
- Cmd::refreshActionsFromSnapshot(entries, snapshot, ...);

+     QAction* action = editAction(entry.menuId);
+     if (action) applySnapshotToAction(action, snapshot);
+ }
```

## 9. 测试建议

1. **无选择时**：所有需要选择的命令（Delete/Mirror/Copy/Align/Group）应该灰
2. **单选时**：Delete/Mirror/Copy 可用，Align 需要多选所以灰
3. **多选时**：所有编辑命令都可用
4. **选中锁定图层图元时**：相关命令变灰
5. **选中隐藏图元时**：相关命令变灰（RequiresVisibleSelection 规则）
6. **撤销栈非空时**：撤销按钮变亮
7. **重做栈非空时**：重做按钮变亮
8. **剪贴板有内容时**：粘贴按钮变亮
