## 2. 命令分发主链路

### 2.1 完整数据流

```
QAction::triggered
    │
    ├─→ [WorkbenchMenuManager] lambda 捕获 commandId
    │       │
    │       └─→ CommandCatalog::operationForCommandId(cmdId) → OperationId
    │               │
    │               └─→ OperationBus::run(OperationId, params, source)
    │                       │
    │                       └─→ OperationRegistry::get(OperationId) → IOperation
    │                               │
    │                               └─→ IOperation::execute(ctx, request) → OperationResult
    │                                       │
    │                                       └─→ OperationBus::postExecute() → 场景刷新 / Undo 压栈
    │
    └─→ [MenuManager] sigMenuAction(cmdId, params)
            │
            └─→ OperationRouting::dispatch(menuActionId, source, params)
                    │
                    └─→ CommandCatalog::operationForMenu(menuActionId) → OperationId
                            │
                            └─→ OperationBus::run(OperationId, params, source)
```

### 2.2 WorkbenchMenuManager 分发模式

每个菜单项通过 lambda 直接连接 `OperationBus`，核心模式如下：

```cpp
// WorkbenchMenuManager.cpp 中的典型模式
auto* action = m_menuState.fileMenu->addAction(tr("New"));
setCmdId(action, "file.new");  // 设置命令 ID
connect(action, &QAction::triggered, this, [this]() {
    if (m_operationBus)
        m_operationBus->run(CommandCatalog::operationForCommandId("file.new"));
});
```

**关键点**：
- `setCmdId()` 将命令字符串（如 `"file.new"`）存入 QAction 的 `data()`
- 点击时通过 `CommandCatalog::operationForCommandId()` 将字符串映射为 `OperationId`
- 最终调用 `OperationBus::run()` 执行

### 2.3 MenuManager 分发模式

`MenuManager` 通过信号机制分发：

```cpp
// MenuManager::connectSignals()
connect(act, &QAction::triggered, this, [this, cmdId, act]() {
    QVariantMap params;
    if (act && act->isCheckable())
        params["checked"] = act->isChecked();
    emit sigMenuAction(cmdId, params);  // 发出信号
});
```

外部连接 `sigMenuAction` 到 `OperationRouting::dispatch()`。

## 3. CommandCatalog 命令映射中心

### 3.1 2D/3D 统一命令结构

经过归一化重构，2D 和 3D 的命令目录现在使用相同的设计模式：

| 维度 | 2D CommandCatalog | 3D CommandCatalog3D |
|------|-------------------|---------------------|
| **基类** | `Cmd::CommandCatalogBase<OperationId, MenuActionId, CommandEntry2D>` | `Cmd::CommandCatalogBase<OperationId3D, MenuActionId3D, CommandEntry3D>` |
| **命令结构** | 单一 `CommandEntry2D` | 单一 `CommandEntry3D` |
| **查找方式** | `findByMenuId()`, `findByOperation()` | `findByMenuId()`, `findByOperation()` |
| **插件扩展** | `appendPluginCommands()` | `appendPluginCommands()` |

### 3.2 命令结构定义

#### 3.2.1 CommandEntry2D（2D 命令条目）

```cpp
struct CommandEntry2D {
    OperationId operationId;           // 操作 ID
    UI::MenuActionId menuId;           // 菜单项 ID
    const char* text;                  // 显示文本
    const char* shortcutId;            // 快捷键 ID
    const char* iconResource;          // 图标路径
    CommandSurface2D surfaces;         // 显示位置（位掩码）
    CommandEnable2D enableRule;        // 启用规则
    bool checkable;                    // 是否为切换型命令
    
    // 切换型命令专用字段
    const char* offText;               // 关闭状态文本
    const char* onText;                // 开启状态文本
    const char* offIconResource;       // 关闭状态图标
    const char* onIconResource;        // 开启状态图标
    
    const char* toolName;              // 工具名称（绘图工具专用）
};
```

#### 3.2.2 CommandEntry3D（3D 命令条目）

```cpp
struct CommandEntry3D {
    OperationId3D operationId;         // 操作 ID
    UI3D::MenuActionId3D menuId;       // 菜单项 ID
    const char* text;                  // 显示文本
    const char* shortcutId;            // 快捷键 ID
    const char* iconPath;              // 图标路径
    CommandSurface3D surfaces;         // 显示位置（位掩码）
    CommandEnable3D enableRule;        // 启用规则
    bool checkable;                    // 是否为切换型命令
};
```

#### 3.2.3 命令分类方式

2D 命令通过 `CommandEntry2D` 的字段区分类型：

| 命令类型 | 判断条件 | 用途 |
|----------|----------|------|
| **工具命令** | `toolName != nullptr` | 绘图工具（左侧工具栏） |
| **编辑命令** | `toolName == nullptr && !checkable` | 普通编辑操作 |
| **切换命令** | `checkable == true` | Group/Ungroup 等切换操作 |
| **菜单路由** | `toolName == nullptr && !checkable` | 文件/算法/激光/帮助等菜单入口 |

### 3.3 共享查找逻辑

`CommandCatalogBase` 模板提供共享的查找方法：

```cpp
template<typename OpId, typename MenuId, typename Entry>
class CommandCatalogBase {
public:
    static const Entry* findByMenuId(MenuId menuId, const QVector<Entry>& entries);
    static const Entry* findByOperation(OpId opId, const QVector<Entry>& entries);
    static OpId operationForMenu(MenuId menuId, OpId noneValue, const QVector<Entry>& entries);
    static bool mapsToOperation(MenuId menuId, OpId noneValue, const QVector<Entry>& entries);
    static QString shortcutIdForMenu(MenuId menuId, const QVector<Entry>& entries);
    static QString shortcutIdForOperation(OpId opId, const QVector<Entry>& entries);
};
```

```

            ├─→ 创建 5 个顶级菜单（File/Edit/View/Tools/Help）;
            │     Draw/Algorithm 收敛为 Tools 子菜单，Modify 收敛为 Edit 子菜单

            ├─→ buildViewMenu()                — 视图菜单（工作台切换/图层/单位/网格捕捉/缩放）
```

### 4.3 工作台动态刷新机制

`WorkbenchMenuManager` 通过 `refreshXxxMenuForWorkbench()` 系列方法根据当前工作台动态重建菜单。以下为当前实现（3D 早退 + `clearMenuActions` 清理 + 由 `addMenuAction` 统一工厂接线）：

```cpp
void WorkbenchMenuManager::refreshDrawMenuForWorkbench(const QString& workbenchId)
{
    if (!m_menuState.drawMenu)
        return;

    // 旧路径下 Draw 菜单仅服务 2D（3D 由 MenuManager3D 自理）。
    // 旧有的 CommandCatalog3D "model." 前缀过滤分支属死代码，已删除。
    if (workbenchId.compare(QStringLiteral("3D"), Qt::CaseInsensitive) == 0)
    {
        SY_DEBUGF("[WorkbenchMenuManager] refreshDrawMenuForWorkbench skip 3D (managed by MenuManager3D)");
        return;
    }

    clearMenuActions(m_menuState.drawMenu);   // 连带删除子菜单对象，避免孤儿 QMenu 累积

    bool firstSeparatorAdded = false;
    for (const CommandEntry2D& cmdEntry : CommandCatalog::commands())
    {
        if (!cmdEntry.toolName)
            continue;
        if (!hasSurface(cmdEntry.surfaces, CommandSurface2D::Menu))
            continue;
        if (!firstSeparatorAdded && cmdEntry.menuId != UI::MenuActionId::Draw_Select)
        {
            m_menuState.drawMenu->addSeparator();
            firstSeparatorAdded = true;
        }
        const QString iconRes = cmdEntry.iconResource ? QString::fromUtf8(cmdEntry.iconResource) : QString();
        // toolName 作为 commandId，由 Workbench2D::dispatchCommand 兜底按
        // operationForToolName 解析，与左侧工具栏/右键菜单为同一条分发路径。
        addMenuAction(m_menuState.drawMenu, m_window->tr(cmdEntry.text),
            QString::fromUtf8(cmdEntry.toolName), iconRes);
    }
}
```

`refreshEditMenuForWorkbench` / `refreshModifyMenuForWorkbench` / `refreshAlgorithmMenuForWorkbench` / `refreshFileMenuForWorkbench` 采用相同的「3D 早退 + `clearMenuActions`（或显式删除子菜单）+ `addMenuAction`」模式。

### 4.4 命令分发链（收敛后）

> 2026-08-11 复核：菜单命令的**执行路径已收敛为每个工作台一条**。同一命令不存在第二套分发。

**2D（legacy 菜单，默认开启）**

```
菜单 QAction → addMenuAction 统一工厂
  → WorkbenchMenuManager::dispatchCommandSafely()      (WorkbenchMenuManager.cpp)
  → Workbench2D::dispatchCommand()                     (UiWorkbench.cpp)
  → OperationRouting::dispatch(menuId)                 (优先，带 angle/mode 参数)
     或 OperationBus::run(op, {}, OperationSource::Menu)  (回退，UiWorkbench.cpp)
```

2D 工具栏（`CommandActionHubActions2D`）/右键/快捷键同走 `OperationRouting::dispatch`，与菜单同一条路径；`addMenuAction` 内部固定为 `setCmdId → applyMenuIcon → logMenuTrigger → dispatchCommandSafely`。

**配置驱动模式（`SANYI_ENABLE_CONFIG_DRIVEN_UI=ON`）**

JSON 菜单由 `UiLayoutBuilder` 生成，点击走 `MenuDispatcher::dispatch` → `workbench->dispatchCommand()`（含工作台切换命令 `view.switch_to_2d` / `view.switch_to_3d` 特殊放行 → `WorkbenchWindow::triggerWorkbench`）。与 legacy 菜单**汇合到同一个 workbench dispatch**，不是第二套执行路径。

**3D（legacy 模式，`managesOwnMenus()=true`）**

```
MenuManager3D::sigMenuAction → Workbench3D::onMenuAction
  → OperationBus3D::run(operationId)                   (UiWorkbench.cpp)
```

配置驱动模式下 3D 交由 `WorkbenchMenuManager` 建菜单，走 `Workbench3D::dispatchCommand` → `OperationBus3D::run`；高频工具栏动作走 `CommandActionHub3D` 直连总线。

**刻意不进总线的非命令类菜单项**（窗口/服务级动作，无命令 ID，不属于命令分发路径）：

| 菜单项 | 处理方式 |
|--------|----------|
| Theme（System/Light/Dark/Blue） | `MenuActionOption_Theme` → `WorkbenchWindow::triggerTheme(commandId)` |
| Language | `LanguageManager::setLanguage()`（触发全局菜单重建） |
| Layer 管理对话框 | `LayerManagerDialog` / `LayerEditService` / `LayerManager` 直调 |
| Zoom 系列 | `m_viewportZoomHandler("zoom_in" ...)` 窗口级回调 |
| Switch to 2D/3D | `WorkbenchWindow::triggerWorkbench()` |

**2D/3D 数据面隔离（非重复路径）**：2D 用 `OperationId`/`OperationBus`/`CommandCatalog`，3D 用 `OperationId3D`/`OperationBus3D`/`CommandCatalog3D`。每个命令只存在于其所属工作台目录，两者之间无同命令双发。

**已删除（2026-08-11）**：旧 `UI/2D` 模块的 `MenuManager` 及具体菜单类（`Src/Ui/MenuManager/`，共 20 文件）已整体删除。删除前核查确认：该子系统从未被实例化（`new MenuManager(` 无调用、旧 `MainWindow2D` 未使用），且其 `Src/Ui/MenuManager` 目录不在 `UI/2D/CMakeLists.txt` 的编译 GLOB 清单内，全部引用者（`ShortcutManager`/`PluginManager`/`FileOperations`/`ViewOperations`/`CommandRegistry`）本就未参与编译。共享基类 `UI/Common` 的 `BaseMenu` 因被 3D 菜单（`FileMenu3D` 等）复用而保留。删除后 `UI2D` DLL 编译通过。

### 5.4 CommandActionHub 动作枢纽

[CommandActionHubActions2D.cpp](file:///C:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/CommandActionHubActions2D.cpp) 负责创建和管理工具栏动作：

#### 5.4.1 工具动作创建

```cpp
void CommandActionHub::rebuildToolActions(ShortcutManager* shortcutManager)
{
    auto* group = new QActionGroup(this);
    group->setExclusive(true);
    
    for (const CommandEntry2D& entry : CommandCatalog::commands()) {
        if (!entry.toolName)
            continue;
            
        QAction* action = new QAction(parentWidget);
        action->setCheckable(true);
        IconHelper::setThemedIcon(action, QString::fromUtf8(entry.iconResource));
        action->setText(entry.text);
        action->setData(static_cast<int>(entry.menuId));
        
        applyShortcut(action, QString::fromUtf8(entry.shortcutId), shortcutManager);
        connectToolAction(entry, action);
        m_toolActions.insert(QString::fromUtf8(entry.toolName), action);
    }
}
```

```cpp
void CommandActionHub::populateContextMenu(QMenu* menu, 
    const ViewContextMenuState& state, LayerManager* layerManager) const
{
    menu->setObjectName("ViewContextMenu");
    
    const bool hasSelection = state.hasSelection();
    const bool hasMultiSelection = state.hasMultiSelection();
    
    if (hasSelection) {
        addEditToMenu(menu, Edit_Cut, CommandSurface2D::ContextMenu);
        addEditToMenu(menu, Edit_Copy, CommandSurface2D::ContextMenu);
        addEditToMenu(menu, Edit_Delete, CommandSurface2D::ContextMenu);
    }
    
    addEditToMenu(menu, Edit_SelectAll, CommandSurface2D::ContextMenu);
    addEditToMenu(menu, View_ZoomFit, CommandSurface2D::ContextMenu);
    
    if (layerManager) {
        QMenu* layerSubMenu = menu->addMenu("Set Current Layer");
        for (int layerId : layerManager->getAllLayerIds()) {
            QAction* act = layerSubMenu->addAction(layerManager->layerName(layerId));
            connect(act, &QAction::triggered, [layerId, layerManager]() {
                OperationBus::instance()->run(OperationId::Edit_SetColor, params, 
                    OperationSource::ContextMenu);
            });
        }
    }
}
```

## 8. 工作台切换交互流程

`WorkbenchWindow::triggerWorkbench()` 执行以下 10 个阶段：

```
阶段 1: 权限检查 + 保存旧布局快照
    │
    ├─→ canExecuteCommand("workbench.switch.xxx")
    ├─→ saveLayoutSnapshot(previousWorkbenchId)
    └─→ stateCenter->setBusy(true)
    │
阶段 2: 停用旧工作台
    └─→ m_workbench->deactivate()
    │
阶段 3: 清理 transient 状态
    └─→ resetWorkbenchTransientState()
        ├─→ resetCommandStateToIdle()      — 命令状态归位
        ├─→ clearSelectionState()          — 清除选择状态
        ├─→ resetWorkbenchLocalMirror()    — 清空本地镜像
        └─→ stateCenter->setDirty(false)
    │
阶段 4: 清除旧工作台 UI 内容
    └─→ clearWorkbenchContent()
        ├─→ removeDockWidget() + delete    — 移除面板
        ├─→ removeToolBar() + delete       — 移除工具栏
        └─→ setCentralWidget(nullptr)      — 清空中央控件
    │
阶段 5: 设置新工作台上下文
    └─→ setWorkbenchSwitchContext(workbenchId, switchContextText)
    │
阶段 6: 获取新工作台实例
    └─→ m_workbenchFactory(workbenchId) → m_workbench
    │
阶段 7: 附加新工作台
    └─→ m_workbench->attachToWindow(*this)
        ├─→ registerDockWidget()           — 注册面板
        ├─→ registerToolBar()              — 注册工具栏
        └─→ setCentralWidget()             — 设置中央控件
    │
阶段 8: 恢复布局快照
    └─→ restoreLayoutSnapshot(workbenchId)
    │
阶段 9: 激活新工作台
    └─→ m_workbench->activate()
    │
阶段 10: 刷新 UI + 清除繁忙状态
    ├─→ refreshWorkbenchMenuChecks()       — 刷新菜单勾选状态
    ├─→ refreshXxxMenuForWorkbench()       — 刷新各菜单内容（非 3D）
    ├─→ setSkeletonDocksVisible(!is3D)     — 3D 隐藏骨架面板
    ├─→ refreshFromState()                 — 从状态中心刷新界面
    └─→ stateCenter->setBusy(false)
```

## 13. 归一化重构说明

### 13.1 2D CommandCatalog 重构

**重构前**：四个独立命令表（ToolCommandEntry、EditCommandEntry、ToggleEditCommandEntry、MenuRouteEntry），各自维护查找逻辑。

**重构后**：单一 `CommandEntry2D` 结构，继承 `CommandCatalogBase` 模板，与 3D 共享查找逻辑。

**重构收益**：

| 方面 | 重构前 | 重构后 |
|------|--------|--------|
| **代码复用** | 2D/3D 各自实现查找逻辑 | 共享 `CommandCatalogBase` 模板 |
| **扩展性** | 添加新命令类型需修改多处 | 单一结构，易于扩展 |
| **一致性** | 2D/3D 结构差异大 | 2D/3D 使用相同设计模式 |
| **维护成本** | 需维护四个独立表 | 只需维护一个命令表 |

### 13.2 状态栏归一化

**重构前**：2D 和 3D 的状态栏各自独立实现，代码重复度高，没有共享基类。

**重构后**：创建 `StatusBarBase` 基类（位于 UI/Common），统一处理公共行为。

**基类设计**：

```cpp
// StatusBarBase.h — 统一接口
class UI_COMMON_API StatusBarBase : public QWidget {
public:
    void setPositionText(const QString& text);   // 位置信息
    void setMessageText(const QString& text);    // 消息提示
    void setInfoText(const QString& text);       // 状态信息
    void clearAll();                             // 清除所有文本
    void retranslateUi();                        // 语言切换
    
protected:
    virtual void setupUI() = 0;                                    // 子类实现布局
    virtual void setSelectionInfo(int nSelected, const QString& detail) = 0;  // 子类实现选择信息
};
```

**2D/3D 继承关系**：

```
                  QWidget
                      │
                      ▼
            ┌─────────────────┐
            │  StatusBarBase  │  ← 新增基类，统一位置/消息/信息/语言切换
            └────────┬────────┘
                     │
        ┌────────────┴────────────┐
        ▼                         ▼
   ┌──────────┐             ┌───────────┐
   │StatusBar │ (2D)        │StatusBar3D│ (3D)
   │          │             │           │
   │- W/H尺寸 │             │- 模型名    │
   │          │             │- 三角形数  │
   └──────────┘             └───────────┘
```

**重构收益**：

| 方面 | 重构前 | 重构后 |
|------|--------|--------|
| **代码复用** | 2D/3D 各自实现位置/消息/清除/语言切换 | 基类统一实现，子类只需实现差异部分 |
| **一致性** | 两套独立的 `changeEvent`/`retranslateUi` | 基类统一处理语言切换 |
| **扩展成本** | 新增状态栏功能需修改两处 | 只需修改基类 |

### 13.3 工具栏归一化

**现状**：2D 的工具栏继承 `ToolBarBase`，3D 的工具栏直接继承 `QToolBar`。

**归一化方向**：3D 的 `LeftToolBar3D` 应继承 `ToolBarBase`，统一语言切换处理。

**ToolBarBase 设计**：

```cpp
// ToolBarBase.h — 统一语言切换
class UI2D_API ToolBarBase : public QToolBar {
public:
    virtual void retranslateUi() = 0;  // 子类实现具体翻译
    
protected:
    void changeEvent(QEvent* event) override;  // 统一处理 LanguageChange
};
```

**2D/3D 工具栏对比**：

| 工具栏 | 基类 | 特性 |
|--------|------|------|
| LeftToolBar（2D） | ToolBarBase | 绘图工具、互斥组、语言切换 |
| LeftToolBar3D（3D） | QToolBar → ToolBarBase | 视图导航、模型创建、固定宽度 |
| TopToolBar（2D） | ToolBarBase | 编辑操作、缩放控制 |
| TopToolBar3D（3D） | QToolBar → ToolBarBase | 编辑操作、变换工具、显示模式 |
