# 设置对话框架设计与实现文档

## 概述

本文档详细描述 SanYiCAD 中 2D/3D 共用的设置对话框架架构设计、数据流转流程、核心类职责及扩展方式。

---

## 1. 整体架构

### 1.1 分层结构

```
┌─────────────────────────────────────────────────────────────────┐
│                      SettingsDialog2D/3D                        │  ← 子类：注册具体 Tab 页
├─────────────────────────────────────────────────────────────────┤
│                    SettingsDialogBase                           │  ← 基类：Tab 容器、按钮、数据分发、懒加载
├─────────────────────────────────────────────────────────────────┤
│                    ISettingsTab (接口)                          │  ← 页签契约：load/save/restore/validate
├──────────────┬──────────────┬──────────────┬───────────────────┤
│ GeneralTab   │ CanvasTab    │ SnapTab      │ ShortcutsTab      │  ← 具体实现
│ View3DTab    │ Camera3DTab  │ Light3DTab   │ ...               │
└──────────────┴──────────────┴──────────────┴───────────────────┘
                              │
                              ▼
                    SettingsTable (DTO)      ← 纯数据载体，键值对映射
                              │
                              ▼
              SettingsPersistenceHelper / SettingsService  ← 落库、应用到全局
```

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **基类无业务** | `SettingsDialogBase` 完全不知道具体业务字段，只负责 Tab 容器管理、按钮逻辑、数据分发 |
| **子类注册 Tab** | `SettingsDialog2D/3D` 在 `initTabs()` 中通过 `addLazyTab()` 注册所需页签 |
| **数据流向单向** | `SettingsTable` 作为 DTO 在对话框与各 Tab 间流动，不跨越 DLL 边界 |
| **懒加载** | 首次切换到某 Tab 时才创建其控件，首次打开对话框更快 |
| **实时预览** | 页内控件变更 → `editingChanged` 信号 → 基类收集数据 → `previewCallback` 回调视图 |

## 2. 核心类详解

### 2.1 SettingsDialogBase (UI/Common/Src/Dlg/SettingsDialogBase.cpp)

**职责**：设置对话框通用基类

**关键成员**：
```cpp
struct TabSlot {
    SettingsTabFactory factory;      // 创建 Tab 的工厂函数
    const char* titleSource;         // 标题翻译键 (QT_TR_NOOP)
    std::unique_ptr<ISettingsTab> tab;  // 实际 Tab 对象 (懒加载后)
    QWidget* placeholder;            // 占位 widget (加载前)
    QWidget* page;                   // 实际挂入 QTabWidget 的页 (QScrollArea 包裹)
};
```

**核心流程**：

1. **构造/初始化**：
   - `applyAdaptiveSizing()` - 基于字体度量计算最小/初始尺寸
   - `initBaseUI()` - 创建 QTabWidget + 底部按钮栏 (OK/Cancel/Restore Current Tab/Restore All)

2. **Tab 注册** (`addLazyTab`)：
   - 存入 factory + titleSource
   - 创建 placeholder widget 加入 QTabWidget
   - 此时不创建真实 Tab 控件

3. **懒加载** (`ensureTabLoaded(index)`)：
   - 用户切换到 index 时触发 `onCurrentTabChanged`
   - 调用 factory 创建真实 Tab
   - 用 `QScrollArea` 包裹 (自动滚动条)
   - 替换 placeholder
   - 连接 `editingChanged` 信号到 `onTabEditingChanged`
   - 若数据已就绪，调用 `loadFromData`

4. **数据分发** (`applyDataToTabs` / `collectDataFromTabs`)：
   - 遍历所有已加载 Tab，调用 `loadFromData` / `saveToData`

5. **实时预览** (`onTabEditingChanged`)：
   - 收集所有 Tab 数据 → `m_previewCallback(m_data)`

6. **恢复默认**：
   - `slotRestoreDefaults()` - 仅当前 Tab
   - `slotRestoreAllDefaults()` - 全域 (按 `defaultResetPrefixes()` 清空键前缀)

### 2.2 ISettingsTab (UI/Common/Include/UI/Dlg/ISettingsTab.h)

**职责**：页签接口契约

```cpp
class ISettingsTab : public QWidget {
    virtual QString tabName() const = 0;           // Tab 标题
    virtual void loadFromData(const SettingsTable& data) = 0;  // 从数据填充控件
    virtual void saveToData(SettingsTable& data) = 0;          // 从控件收集数据
    virtual void restoreDefaults() = 0;            // 重置为出厂默认
    virtual bool validateBeforeAccept(QString* errorMessage = nullptr); // OK 前校验
    void setupLivePreviewSignals();                // 连接控件信号到 editingChanged
signals:
    void editingChanged();                         // 任一控件修改时发出
};
```

**实现约定**：
- `loadFromData` 使用 `data.getInt(key, default)` 等读取，控件显示默认值
- `saveToData` 使用 `data.setInt(key, value)` 等写回
- `restoreDefaults` 应将控件恢复到**硬编码的出厂默认值**，不依赖 `m_data`

### 2.3 SettingsTable (UI/Common/Src/Persistence/SettingsTable.cpp)

**职责**：UI 层设置表 DTO，键值对存储

**特点**：
- PIMPL 隐藏 `std::map<std::string, std::variant<int,float,double,bool,string>>`
- ABI 安全：导出接口仅用 `const char*` / 缓冲区 / 基础类型
- 提供类型安全的 `get/set` 重载
- 支持前缀提取/删除 (`extractPrefix` / `removePrefix`) 用于域隔离

### 2.4 GeneralSettingsTab (UI/Common/Src/Dlg/GeneralSettingsTab.cpp)

**职责**：通用设置页 (语言、主题、日志、字体、**单位**)

**关键依赖**：
- `LanguageManager` (LM) - 语言列表、切换
- `ThemeManager` (TM) - 主题列表、切换
- `IUnitProvider` - **单位列表提供者** (解耦 2D/3D)

**单位下拉框填充流程**：
```cpp
// 初始化
refillUnitCombo(m_unitCmb, m_unitProvider, defaultUnit);

// 语言切换时
retranslateUi() → refillUnitCombo(m_unitCmb, m_unitProvider, currentUnit);
```

### 2.5 IUnitProvider / UnitProvider2D (解耦 2D 单位系统)

**问题背景**：原 `GeneralSettingsTab` 直接 `#include "UI2D/Manager/UnitManager.h"`，导致 3D 强制依赖 2D 代码。

**解决方案**：
```cpp
// UI/Common/Include/UI/Dlg/IUnitProvider.h
class IUnitProvider {
    virtual QVector<UnitEntry> selectableUnits() const = 0;
    virtual int defaultUnit() const = 0;
};

struct UnitEntry {
    QString text;      // 显示文本 (已翻译)
    int unitEnum;      // 单位枚举值
    QString unitId;    // 唯一标识 ("mm", "cm", "inch")
};

// UI/2D/Include/UI2D/Settings/UnitProvider2D.h
class UnitProvider2D : public IUnitProvider {
    QVector<UnitEntry> selectableUnits() const override {
        // 复用 UnitSelectionMenu::selectableUnits()
    }
    int defaultUnit() const override { return (int)UnitManager::Unit::Millimeter; }
};
```

**使用方式**：
- `SettingsDialog2D` 构造 `UnitProvider2D` 并传给 `GeneralSettingsTab`
- `SettingsDialog3D` 传 `nullptr` (3D 不显示单位下拉框)

### 2.6 SettingsDialog2D / SettingsDialog3D

**SettingsDialog2D**：
```cpp

Prefixes: canvas/, table/, grid/, ruler/, snap/, gsm/, selection/, machine/
```

**SettingsDialog3D**：

## 3. 数据流转完整流程

### 3.1 打开设置对话框

```cpp
// 调用方 (如 MainWindow)
SettingsTable data = settingsRepository->loadAll();  // 从数据库加载
bool ok = SettingsDialog2D::showDialog(this, data, shortcutModel, gridSnapMgr, previewCb);
if (ok) {
    settingsRepository->saveAll(data);  // 持久化
    settingsPersistenceHelper->applyAllSettings(data);  // 应用到全局 (SyLogger, ThemeManager 等)
}
```

### 3.2 对话框内部流程

```
showDialog()
  ├─ 构造 SettingsDialog2D
  │    ├─ SettingsDialogBase()
  │    │    ├─ applyAdaptiveSizing()  // 计算尺寸
  │    │    ├─ initBaseUI()           // TabWidget + 按钮
  │    │    └─ connect signals
  │    └─ initTabs(shortcutModel)
  │         └─ addLazyTab(...) x N    // 注册工厂，不创建控件
  ├─ setPreviewCallback(previewCb)
  ├─ setData(data)
  │    └─ m_data = data; m_dataReady = true; ensureTabLoaded(0); applyDataToTabs()
  │         └─ Tab0.loadFromData(data)  // 首页立即加载
  ├─ exec()  // 模态事件循环
  │    ├─ 用户切换 Tab → onCurrentTabChanged → ensureTabLoaded → loadFromData
  │    ├─ 用户修改控件 → editingChanged → onTabEditingChanged → collectDataFromTabs → previewCallback
  │    ├─ 用户点 "Restore Current Tab" → slotRestoreDefaults()
  │    │    └─ currentTab.restoreDefaults() → saveToData(m_data) → previewCallback
  │    ├─ 用户点 "Restore All" → slotRestoreAllDefaults()
  │    │    └─ restoreDefaultsByPrefixes() → applyDataToTabs() → previewCallback
  │    └─ 用户点 OK → slotAccept()
  │         ├─ 遍历所有 Tab validateBeforeAccept()
  │         ├─ collectDataFromTabs()
  │         └─ accept()
  └─ 返回 true/false，data 已更新
```

### 3.3 关闭后持久化与应用

```cpp
// SettingsPersistenceHelper::applyCommonSettings(data)
//   ├─ ThemeManager::setTheme(data.getInt(KEY_THEME))
//   ├─ LanguageManager::setLanguage(data.getInt(KEY_LANGUAGE))

//   ├─ SyLogger::setLevel(data.getInt(KEY_LOG_LEVEL))
```

## 5. 扩展指南

### 5.1 新增设置页签 (以 2D 为例)

1. **实现 ISettingsTab 子类**：
```cpp
// MySettingsTab.h
class MySettingsTab : public ISettingsTab {
    QString tabName() const override { return tr("MyTab"); }
    void loadFromData(const SettingsTable& data) override { ... }
    void saveToData(SettingsTable& data) override { ... }
    void restoreDefaults() override { ... }
    bool validateBeforeAccept(QString* err) override { return true; }
};
```

2. **定义键名常量** (UI/2D/Include/UI2D/Settings/SettingsKeys2D.h)：
```cpp
inline constexpr const char* MY_FEATURE_ENABLED = "myfeature/enabled";
```

3. **在 SettingsDialog2D::initTabs 注册**：
```cpp
addLazyTab(
    [this](QWidget*) { return std::make_unique<MySettingsTab>(this); },
    QT_TR_NOOP("My Feature"));
```

4. **加入 RESTORE_PREFIXES** (如需"恢复所有"生效)：
```cpp
inline constexpr const char* RESTORE_PREFIXES[] = {
    ..., "myfeature/"
};
```

### 5.2 3D 新增专属页签

同理，在 `SettingsDialog3D::initTabs` 注册，键名用 `3d/` 前缀。

### 5.3 新增共享设置项 (common/)

1. 在 `SettingsKeysCommon.h` 定义键名
2. 在 `GeneralSettingsTab` 或新建共享 Tab 中实现 UI
3. 在 `SettingsPersistenceHelper::applyCommonSettings` 中处理落地生效

## 6. 关键修复记录 (2026-09-11)

### 问题 1：GeneralSettingsTab 依赖 UI2D 代码 (严重)
- **现象**：`#include "UI2D/Manager/UnitManager.h"` 导致 3D 强制链接 2D
- **修复**：引入 `IUnitProvider` 接口，`UnitProvider2D` 实现，3D 传 `nullptr`

### 问题 2："恢复默认值" 仅重置当前页签
- **现象**：按钮连接 `slotRestoreDefaults()` 只操作当前 Tab
- **修复**：
  - 重命名按钮为 "Restore Current Tab"
  - 新增 "Restore All" 按钮 → `slotRestoreAllDefaults()` → `restoreDefaultsByPrefixes()`

### 问题 3：代码风格
- `SettingsDialog2D.cpp` 中 `if (shortcutModel) {` 多余空行
- **修复**：标准化缩进
