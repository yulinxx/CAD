# 三维光照配置（自定义可调节光照）

## 一、背景

3D 模型主要用于激光/雕刻等加工行业，用户需要从多角度观察模型的深腔、切面、
雕刻深浅等细节。原实现光照参数硬编码（单方向光 + 固定亮度下限 0.45），
存在以下问题：

- 光照方向不可调，暗部/背面细节难以观察
- 深腔、窄槽等区域在全黑与过曝之间没有中间调节手段
- 单光源无法勾勒轮廓，模型立体感弱
- CAD 导出的模型绕序/法线不一致时缺乏双面光照开关

## 二、方案

新增低耦合光照配置模块，并贯通渲染、设置 UI、设置持久化全链路：

- **`UI3D::Lighting3D`（纯 POD 结构体）**：环境光 + 主光 + 补光 + 轮廓光 +
  镜面高光 + 双面光照 + 亮度下限 + 曝光 + 预设。
- 方向光以「方位角 + 仰角 + 强度 + 颜色」描述，用户无需理解向量数学即可调节。
- 着色器改为多光源累加，`RenderWidget3D` 渲染循环只读 `Lighting3D`，
  不感知设置来源（低耦合）。

## 四、设计要点

### 低耦合 / 可移植

- `Lighting3D.h` 仅依赖 `<cstdint>`、`<cmath>` 与 `UI3DAPI.h`，
  不包含 Qt、OpenGL、引擎类型，可整体抽出复用于 Renderx 等其它后端。
- 方向向量在 CPU 侧由方位角/仰角计算，着色器只接收归一化方向。

### DLL 导出

- 全部配置结构体为纯 POD，`sizeof` 有 `static_assert` 约束（`DirLight3D`=32B、
  `Lighting3D`=168B，含 ABI 预留填充），配合 `UI3D_API` 可安全按值跨 DLL 传递。
- `RenderWidget3D::setLighting()/lighting()` 随类导出。

### 注释与日志

- 所有字段/函数均有中文文档注释。
- `setLighting()` 与 `SettingsUiCoordinator3D` 在应用/收集时输出 `SY_INFOF` 日志，
  含各光源开关、角度、强度与方向向量，便于排查显示问题。

## 五、预设说明

| 预设 | 适用场景 |
| --- | --- |
| Default（默认） | 均衡观察，主光 + 补光 + 轮廓光 |
| Bright（明亮均匀） | 高环境光 + 高亮度下限，快速浏览整体 |
| Engraving Detail（雕刻细节） | 高角度主光 + 高光泽，突出深浅层次 |
| High Contrast（高对比） | 低环境光 + 强主光，暗背景下观察轮廓/边界 |
| Flat（无方向均匀） | 近似无光影，查看整体外形与遮挡关系 |

切换预设会回填面板各控件，用户可在预设基础上继续微调，微调结果随设置持久化。
