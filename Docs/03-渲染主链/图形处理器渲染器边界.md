# 图形处理器渲染器边界

本文只描述当前有效的渲染边界，不保留历史路径。

---

## 1. 当前边界

当前生产渲染边界以 `Renderx` / `RenderX` 为准。

### 1.1 对外入口

公共头只有一个：`Renderx/include/render/renderx.h`（`namespace Render::RT`）。当前 ABI 是句柄式，
没有 `RenderDevice*` 这类指针句柄：

```cpp
RuntimeHandle  rxRuntimeCreate(const RuntimeDesc* desc);
void           rxRuntimeDestroy(RuntimeHandle runtime);
SessionHandle  rxSessionCreate(const SessionDesc* desc);
void           rxSessionDestroy(SessionHandle session);
void           rxSessionSetViewMatrix(SessionHandle session, const float viewMatrix[16]);
void           rxSessionSetModelMatrix(SessionHandle session, const float modelMatrix[16]);
RxResult       rxSessionBeginFrame(SessionHandle session);
RxResult       rxSessionSubmit(SessionHandle session, const DrawPacket* packet);      // 逐帧重建的命令
RxResult       rxSessionSubmitDrawList(SessionHandle session, DrawListHandle list);   // 2D 常驻命令
RxResult       rxSessionSubmitDrawList3D(SessionHandle session, DrawListHandle list); // 3D 常驻命令（视锥剔除）
RxResult       rxSessionEndFrame(SessionHandle session);
DrawListHandle rxDrawListCreate(RuntimeHandle runtime, const DrawListDesc* desc);
```

> 2026-11-10 复核：原来的 `renderCreateDevice` / `renderDestroyDevice` / `renderResize` /
> `renderSubmitGeometry` / `renderFrame` 五个入口已随 RenderX 重构删除，替换为上表。
> 生产代码不直接 include 该头，统一经 `RenderBridge::RenderSessionHost` 与 `RenderAbstraction`
> 接口（`IRenderDevice` / `IRenderSurface` / `IRenderScene`）访问。

### 1.2 当前职责

- 接收几何与状态
- 编译并提交绘制任务
- 执行 GPU 绘制
- 输出到窗口或离屏缓冲区

### 1.3 当前禁止

- 修改文档
- 处理业务 selection 真相
- 处理用户输入
- 直接耦合 UI 对象
- 实现业务逻辑

---

## 2. 当前分层

### 2.1 UI 适配层

UI 层通过 `RenderWidget` 和 `RenderSceneBuilder` 连接渲染层。

### 2.2 渲染层

`Renderx` 内部负责：

- 几何接收
- 批次组织
- 资源管理
- OpenGL / Vulkan / Metal 后端实现

### 2.3 回退实现

无图形环境或测试环境可使用最小回退实现，但不作为业务主线。
