# 文本渲染集成指南

## 文件清单

| 文件 | 目标位置 | 说明 |
|------|---------|------|
| `text_renderer.h` | `Renderx/src/core/text_renderer.h` | 统一文本渲染器头文件 |
| `text_renderer.cpp` | `Renderx/src/core/text_renderer.cpp` | 统一文本渲染器实现 |
| `text_unified.vert` | `Renderx/src/shader/text_unified.vert` | 统一顶点着色器 |
| `text_unified.frag` | `Renderx/src/shader/text_unified.frag` | 统一片段着色器 |

---

## 修改步骤

### 1. shaders.h — 添加 shader 声明

在 `TEXT_SCREEN_FRAG` 声明后面添加：

```cpp
/// 统一文本渲染顶点着色器（屏幕/世界双模式）
extern const char* TEXT_UNIFIED_VERT;
/// 统一文本渲染片段着色器
extern const char* TEXT_UNIFIED_FRAG;
```

### 2. shaders.cpp — 添加 shader 加载

在静态变量区添加：

```cpp
static std::string textUnifiedVertSource;
static std::string textUnifiedFragSource;
```

在全局指针区添加：

```cpp
const char* TEXT_UNIFIED_VERT = nullptr;
const char* TEXT_UNIFIED_FRAG = nullptr;
```

在 `initialize()` 函数中，`loadShaderFile(shaderDir, "text_screen.frag", ...)` 后添加：

```cpp
loadShaderFile(shaderDir, "text_unified.vert", textUnifiedVertSource);
loadShaderFile(shaderDir, "text_unified.frag", textUnifiedFragSource);
```

在指针赋值区添加：

```cpp
TEXT_UNIFIED_VERT = textUnifiedVertSource.empty() ? "" : textUnifiedVertSource.c_str();
TEXT_UNIFIED_FRAG = textUnifiedFragSource.empty() ? "" : textUnifiedFragSource.c_str();
```

### 3. CMakeLists.txt — 添加 shader 文件

在 `SHADER_FILES` 列表中添加：

```cmake
${CMAKE_CURRENT_SOURCE_DIR}/src/shader/text_unified.vert
${CMAKE_CURRENT_SOURCE_DIR}/src/shader/text_unified.frag
```

在 `RENDER_SOURCES` 列表中添加：

```cmake
src/core/text_renderer.cpp
```

### 4. RenderDevice — 添加成员

在 `render_c_api.cpp` 的 `RenderDevice` 结构体中添加：

```cpp
/// 统一文本渲染器
core::TextRenderer textRenderer;
```

### 5. renderCreateDevice — 初始化

在设备创建时初始化 TextRenderer：

```cpp
if (!dev->textRenderer.initialize(dev->rhiDevice)) {
    SY_ERROR("Failed to initialize TextRenderer");
}
```

### 6. 字体加载

在 `renderCreateDevice` 中，替换原有的默认字体加载逻辑：

```cpp
// 旧代码（ScreenTextRenderer）：
// dev->screenTextRenderer.loadFont(buf.data(), ...);

// 新代码（TextRenderer）：
dev->textRenderer.loadFont(buf.data(), static_cast<uint32_t>(buf.size()), 14.0f);
```

### 7. renderFrame — 替换渲染调用

在 `renderFrame()` 中，替换屏幕文本渲染段：

```cpp
// 旧代码：
// if (!dev->pendingScreenTexts.empty()) {
//     dev->screenTextRenderer.beginFrame();
//     ...
//     dev->screenTextRenderer.render(rhi, dev->view2D.viewWidth, dev->view2D.viewHeight);
// }

// 新代码：
if (!dev->pendingScreenTexts.empty())
{
    dev->textRenderer.beginFrame();

    for (const auto& pst : dev->pendingScreenTexts)
    {
        TextRenderer::TextItem item{};
        item.text     = pst.text.c_str();
        item.x        = pst.x;
        item.y        = pst.y;
        item.color[0] = pst.color[0];
        item.color[1] = pst.color[1];
        item.color[2] = pst.color[2];
        item.color[3] = pst.color[3];
        item.fontSize = pst.fontSize;
        item.mode     = TextRenderer::CoordMode::Screen;
        dev->textRenderer.submitText(item);
    }

    dev->textRenderer.render(rhi, dev->view2D.viewWidth,
                             dev->view2D.viewHeight,
                             dev->view2D.viewMatrix);
    dev->pendingScreenTexts.clear();
}
```

### 8. 添加世界文字支持（可选）

如果需要世界文字，在 RenderDevice 中添加 pending 列表：

```cpp
struct PendingWorldText {
    std::string text;
    float x, y;
    float color[4];
    float fontSize;
};
std::vector<PendingWorldText> pendingWorldTexts;
```

在 renderFrame 中添加世界文字渲染：

```cpp
if (!dev->pendingWorldTexts.empty())
{
    dev->textRenderer.beginFrame();  // 如果屏幕文字已 beginFrame，这里不重复调用

    for (const auto& pwt : dev->pendingWorldTexts)
    {
        TextRenderer::TextItem item{};
        item.text     = pwt.text.c_str();
        item.x        = pwt.x;
        item.y        = pwt.y;
        item.color[0] = pwt.color[0];
        item.color[1] = pwt.color[1];
        item.color[2] = pwt.color[2];
        item.color[3] = pwt.color[3];
        item.fontSize = pwt.fontSize;
        item.mode     = TextRenderer::CoordMode::World;
        dev->textRenderer.submitText(item);
    }

    dev->pendingWorldTexts.clear();
}
```

注意：屏幕文字和世界文字应该在同一个 `beginFrame/render` 周期内提交。

### 9. C API 接口（可选）

可以在 `render.h` 中添加新的 C API：

```cpp
/// 提交世界空间文本
RENDER_API void renderSetWorldTexts(RenderDevice* dev,
    const WorldTextItem* items, uint32_t count);
```

## 使用示例

### 屏幕文字（标尺刻度）

```cpp
TextRenderer::TextItem item{};
item.text     = "100.5";
item.x        = 120.0f;   // 像素 X
item.y        = 30.0f;    // 像素 Y
item.color[0] = 0.2f;
item.color[1] = 0.2f;
item.color[2] = 0.2f;
item.color[3] = 1.0f;
item.fontSize = 14.0f;
item.mode     = TextRenderer::CoordMode::Screen;

dev->textRenderer.beginFrame();
dev->textRenderer.submitText(item);
dev->textRenderer.render(rhi, vpW, vpH, viewMatrix);
```

### 世界文字（图元标注）

```cpp
TextRenderer::TextItem item{};
item.text     = "Line #1";
item.x        = 150.0;    // 世界坐标 X
item.y        = 200.0;    // 世界坐标 Y
item.color[0] = 1.0f;
item.color[1] = 0.0f;
item.color[2] = 0.0f;
item.color[3] = 1.0f;
item.fontSize = 16.0f;
item.mode     = TextRenderer::CoordMode::World;

dev->textRenderer.beginFrame();
dev->textRenderer.submitText(item);
dev->textRenderer.render(rhi, vpW, vpH, viewMatrix);
```

### 混合提交（屏幕 + 世界同时渲染）

```cpp
dev->textRenderer.beginFrame();

// 屏幕文字
screenItem.mode = TextRenderer::CoordMode::Screen;
dev->textRenderer.submitText(screenItem);

// 世界文字
worldItem.mode = TextRenderer::CoordMode::World;
dev->textRenderer.submitText(worldItem);

// 一次 render 调用，内部分两批绘制
dev->textRenderer.render(rhi, vpW, vpH, viewMatrix);
```
