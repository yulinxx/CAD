# 渲染数据结构重构方案

## 概述

本文档记录渲染数据结构的统一重构方案，旨在消除重复定义、降低耦合性、提高代码可维护性。

## 重构目标

| 问题 | 重构前 | 重构后 |
|------|--------|--------|
| 顶点格式 | 6+ 种定义散落各处 | 单一来源 (Utility/Ut/VertexFormat.hpp) |
| 图元枚举 | 4 处重复定义 | 单一来源 (Utility/Ut/PrimitiveType.hpp) |
| 渲染批次 | DisplayMesh/RenderBatch/Entry 各自为政 | 统一 DrawItem 接口 |
| SyEntity 耦合 | 2D 字段混入基类 | SyEntity2D 中间层 |

## 重构详情

### 1. 统一顶点格式

#### 新增文件

- `Utility/Utility/Include/Ut/VertexFormat.hpp`

#### 预定义顶点结构

| 结构 | 布局 | 步长 | 用途 |
|------|------|------|------|
| `Ut::VertexP3C3` | px,py,pz + cr,cg,cb | 24 字节 | 2D/3D 通用几何 |
| `Ut::VertexP3C4` | px,py,pz + cr,cg,cb,ca | 28 字节 | 覆盖层、透明度 |
| `Ut::VertexP3N3` | px,py,pz + nx,ny,nz | 24 字节 | 3D 网格带光照 |
| `Ut::VertexP2T2C4` | px,py + u,v + cr,cg,cb,ca | 32 字节 | 屏幕空间贴图 |
| `Ut::VertexP3T2C4` | px,py,pz + u,v + cr,cg,cb,ca | 36 字节 | 世界空间贴图 |
| `Ut::VertexP3O2C4` | ax,ay,az + ox,oy + cr,cg,cb,ca | 36 字节 | 恒定尺寸标记 |

#### 引用关系

```
Engine2D/DisplayMesh.h     → Ut::VertexP3C3 (via using)
UI/Common/Render/RenderTypes.h → Ut::VertexP3C3, Ut::VertexP3C4... (via using)
Utility/Ut/RenderData.h    → Ut::VertexP3C3, Ut::VertexP3N3 (via using)
```

### 2. 统一图元枚举

#### 新增文件

- `Utility/Utility/Include/Ut/PrimitiveType.hpp`

#### 枚举值

```cpp
enum class Ut::PrimitiveType : uint8_t {
    Points        = 0,
    Lines         = 1,
    LineStrip     = 2,
    LineLoop      = 3,
    Triangles     = 4,
    TriangleStrip = 5,
    TriangleFan   = 6   // CAD 专用，需展开为 Triangles
};
```

#### 引用关系

```
Engine2D/DisplayMesh.h     → Ut::PrimitiveType (via using EDisplayPrimitiveType)
UI/Common/Render/RenderTypes.h → Ut::PrimitiveType (via using)
Utility/Ut/RenderData.h    → Ut::PrimitiveType (via using RenderPrimitiveType)
```

### 3. 创建 SyEntity2D 中间层

#### 新增文件

- `Engine/Common/Include/Engine/SyEntity/SyEntity2D.h`

#### 架构变更

```
重构前：
┌─────────────────┐
│    SyEntity     │ ← basePoint, bClosed, bCCW 混在这里
├─────────────────┤
│   (公共字段)    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  SyMeshEntity   │
└─────────────────┘

重构后：
┌─────────────────┐
│    SyEntity     │ ← 只有公共字段 (id, name, visible, locked...)
├─────────────────┤
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌───────┐ ┌────────────┐
│SyEntity│ │ SyEntity2D │
│(基类)  │ │ (中间层)   │
└───────┘ └─────┬──────┘
                ▼
         ┌──────────────┐
         │ 2D 图元类    │
         │ (SyCircle,   │
         │  SyLine...)  │
         └──────────────┘
```

#### SyEntity2D 字段

```cpp
struct SyEntity2D : public SyEntity {
    Ut::Vec2d basePoint;  // 基点（圆心、起点等）
    bool bClosed = false;  // 是否闭合
    bool bCCW = true;     // 是否逆时针
};
```

## 各层引用方式

### Engine2D

```cpp
// DisplayMesh.h
#include "Ut/VertexFormat.hpp"
#include "Ut/PrimitiveType.hpp"

using EDisplayPrimitiveType = Ut::PrimitiveType;
using DisplayVertex = Ut::VertexP3C3;
```

### UI/Common

```cpp
// RenderTypes.h
#include "Ut/VertexFormat.hpp"
#include "Ut/PrimitiveType.hpp"

using VertexP3C3 = Ut::VertexP3C3;
using VertexP3C4 = Ut::VertexP3C4;
using VertexP3N3 = Ut::VertexP3N3;
using VertexP3O2C4 = Ut::VertexP3O2C4;
using PrimitiveType = Ut::PrimitiveType;
```

### Utility

```cpp
// RenderData.h
#include "Ut/VertexFormat.hpp"
#include "Ut/PrimitiveType.hpp"

using RenderPrimitiveType = Ut::PrimitiveType;
using MeshVertex = Ut::VertexP3N3;
using RenderVertex = Ut::VertexP3C3;
```

## 兼容性保证

所有变更均保持向后兼容：

1. **using 别名**：旧代码中的 `Eg::EDisplayPrimitiveType`、`Render::VertexP3C3` 等仍然可用
2. **static_assert**：保留字节步长校验，确保与渲染后端一致
3. **枚举值兼容**：数值与 RenderAbstraction::PrimitiveType 保持一致

## 收益

1. **单一数据源**：顶点格式和图元类型只在一处定义，避免同步更新遗漏
2. **降低耦合**：各层按需引用，不引入不必要的依赖
3. **代码复用**：统一后更容易在各处共享渲染数据处理逻辑
4. **可维护性**：新增顶点格式只需修改 Ut/VertexFormat.hpp 一处
