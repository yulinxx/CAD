# 选中轮廓"流水虚线"渲染原理与配置

## 1. 概述

本文描述选中轮廓的虚线高亮实现方式：

- 虚线沿轮廓弧长驱动
- 虚线支持流动动画
- 虚线参数可配置
- 曲线和折线统一处理
- 缩放时保持最高精度 LOD

---

## 2. 设计核心

虚线不是按离散段逐段套用，而是按整条轮廓的弧长坐标统一处理。这样可以避免短段被整段吞掉，也能保证拐角和闭合轮廓的连续性。

---

## 3. 数据结构

当前相关类型包括：

- `SelectionOutlineVertex` - 轮廓顶点（含累积弧长）
- `SelectionOutlinePath` - 轮廓路径
- `SelectionDashStyle` - 虚线样式

---

## 4. 渲染流程

```
选中变化
→ SelectTool（计算选中集指纹 + 缩放档位）
→ SelectionOutlineBuilder::buildFromEntities（离散化轮廓）
→ ViewRenderCoordinator
→ RenderWidget
→ OverlayScene::appendSelectionDash（虚线离散）
→ 渲染后端
```

### 4.1 轮廓构建缓存

`SelectTool` 按「实体集指纹 + 缩放档位 + 预算参数」缓存离散结果：

- 指纹：选中图元 ID 集合的哈希（XOR+旋转哈希，O(N)）
- 缩放档位：`log2(pixelToWorld)` 量化到 0.5 档，档位不变则离散结果视觉无差异

---

## 5. 核心算法

虚线离散的大致思路是：

1. 先把轮廓折线按弧长参数化
2. 再把像素单位的 dash / gap 换算到世界坐标
3. 按相位枚举可见实线区间
4. 在每个实线区间内保留折线拐点
5. 将结果提交为线段列表

### 5.1 屏幕空间自适应离散

轮廓离散化使用屏幕空间自适应容差，确保在不同缩放级别下保持一致的视觉精度：

```cpp
// 弦高误差 0.25 像素，与场景渲染 LOD 一致
const double worldToScreenScale = 1.0 / pixelToWorld;
const double tolerance = kOutlineTolerancePx / std::max(1e-6, worldToScreenScale);
```

---

## 6. 动画

动画通过定时器推进相位实现：

- 相位按像素空间累积
- 每次刷新重新离散
- 这样在不同缩放级别下动画速度保持一致

---

## 7. 当前原则

- 虚线只做高亮，不承担业务语义
- 虚线颜色 = 图元自身颜色（覆盖色优先，否则图层色）。选中态下虚线是本体视觉的替代品（可选隐藏原图），换色会让人以为"换了支笔"
- 轮廓构建和虚线离散应分开
- 选择高亮应继续保持和正式图元分离

---

## 8. 关键实现点

### 8.1 离散化层（Engine/2D）

`SelectionOutlineBuilder::buildFromEntities` 负责将选中图元离散为带累积弧长的折线：

- 圆/弧/椭圆/贝塞尔：使用 `BezierAlgorithms::discretizeEntity` 自适应离散
- 折线：直接使用顶点
- SmartLine：递归处理各段

### 8.2 渲染层（RenderBridge）

`OverlayScene::appendSelectionDash` 负责将轮廓离散为虚线段：

- 使用单调游标算法，O(V+D) 复杂度
- 每条路径最大 16384 段

### 8.3 虚线参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `dashLengthPx` | 10.0 | 虚线长度（像素） |
| `gapLengthPx` | 8.0 | 间隙长度（像素） |
| `speedPxPerSec` | 48.0 | 流动动画速度 |
| `animated` | true | 是否启用动画 |

---

## 9. 预算控制

虚线渲染有预算限制，防止选中大量图元时性能下降：

| 预算项 | 默认值 | 说明 |
|--------|--------|------|
| `maxEntities` | 2000 | 最大虚线实体数 |
| `maxVertices` | 200000 | 最大顶点数 |

超过预算时只绘制选区包围盒，不绘制虚线轮廓。
