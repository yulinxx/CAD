# 选中轮廓“流水虚线”渲染原理与配置

## 1. 概述

本文描述选中轮廓的虚线高亮实现方式：

- 虚线沿轮廓弧长驱动
- 虚线支持流动动画
- 虚线参数可配置
- 曲线和折线统一处理

---

## 2. 设计核心

虚线不是按离散段逐段套用，而是按整条轮廓的弧长坐标统一处理。这样可以避免短段被整段吞掉，也能保证拐角和闭合轮廓的连续性。

---

## 3. 数据结构

当前相关类型包括：

- `SelectionOutlineVertex`
- `SelectionOutlinePath`
- `SelectionDashStyle`

它们分别描述轮廓顶点、轮廓路径和虚线样式。

---

## 4. 渲染流程

```text
选中变化
→ SelectionGizmo / SelectTool
→ 轮廓构建
→ ViewRenderCoordinator
→ RenderWidget
→ 虚线离散
→ Overlay 提交
→ 渲染后端
```

---

## 5. 核心算法

虚线离散的大致思路是：

1. 先把轮廓折线按弧长参数化
2. 再把像素单位的 dash / gap 换算到世界坐标
3. 按相位枚举可见实线区间
4. 在每个实线区间内保留折线拐点
5. 将结果提交为线段列表

---

## 6. 动画

动画通过定时器推进相位实现：

- 相位按像素空间累积
- 每次刷新重新离散
- 这样在不同缩放级别下动画速度保持一致

---

## 7. 当前原则

- 虚线只做高亮，不承担业务语义
- 轮廓构建和虚线离散应分开
- 选择高亮应继续保持和正式图元分离
