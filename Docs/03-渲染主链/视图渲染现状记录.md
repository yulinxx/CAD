## 1. 视图渲染技术选择

### 1.1 结论

**2D 和 3D 视图的核心渲染已经全部使用 RenderX DLL**，不再使用 Qt 原生绘制（QPainter）进行几何渲染。

### 1.2 证据

| 视图 | 主渲染技术 | 证据位置 |
|------|-----------|----------|
| 2D 视图 | RenderX (OpenGL) | `UI/2D/Include/RenderWidget.h` 注释 |
| 3D 视图 | RenderX (OpenGL) | `UI/3D/Include/UI3D/Render3D/RenderWidget3D.h` |

## 2. 遗留的 QPainter 使用

### 2.1 仅有两处（UI 叠加层）

| 位置 | 用途 | 保持原因 |
|------|------|----------|
| `AxisIndicator3D` | 3D 视口角落坐标轴指示器 (X/Y/Z) | 需要渲染文字标签，需先接入 RenderX 字形图集 |
| `drawSelectionRubberBand()` | 框选时的半透明矩形 | 简单的 2D 绘制，用 QPainter 实现最简单 |

### 2.2 代码位置

```cpp
// RenderWidget3D.cpp:1020-1024
// QPainter 叠加层必须在整帧结束之后：Qt 的画笔会重设 GL 状态，
// 夹在 DLL 的命令记录中间会互相干扰。
// 这两处是本轮尚未迁进 Renderx 的部分（轴指示器要文字，得先接字形图集）。
renderAxisIndicator();
drawSelectionRubberBand();
```

### 2.3 建议

**保持现有 QPainter 实现**。原因：
1. 收益不大 - 极简单的 UI 叠加层，性能影响可忽略
2. 迁移成本 - 坐标轴指示器需要接入 RenderX 的文字系统
3. 这是有意的技术决策，不是遗漏

## 3. 2D 视图文字渲染实现

### 3.1 两种文字类型

| 构建器 | 用途 | 坐标空间 | 图集类型 |
|--------|------|----------|----------|
| `TextQuadBuilder` | 屏幕定尺寸文字（标尺刻度值、HUD） | Screen 空间（物理像素） | 覆盖率图集 |
| `WorldTextQuadBuilder` | 图纸里的文字（SyText 实体） | World 空间（世界坐标） | SDF 距离场图集 |

### 3.2 渲染架构

```
RenderWidget
├── m_text (TextQuadBuilder)          ← 屏幕文字
│   └── 用途：标尺刻度值、UI 文字
│   └── 字号：像素高度（每个字号一个批次）
│   └── 顶点：P2T2C4（屏幕坐标 + UV + 颜色）
│
└── m_worldTexts (WorldTextQuadBuilder)  ← 世界文字
    └── 用途：图纸中的文本标注
    └── 字号：世界单位（统一 SDF 图集）
    └── 顶点：P3T2C4（世界坐标 + UV + 颜色）
```

### 3.3 字体来源

```cpp
// 从 Qt 资源文件加载字体
QFile fontFile(QStringLiteral(":/ui/common/Fonts/default_screen_font.ttf"));
// 注入到 RenderX DLL
m_text.initialize(m_runtime, data, size);        // 覆盖率图集
m_worldTexts.initialize(m_runtime, data, size); // SDF 图集
```

### 3.4 渲染管线

```cpp
// 帧渲染流程
rxSessionBeginFrame
    ├── buildSceneEnvCommands()      // 场景环境（网格/标尺线）
    ├── m_bitmaps.flush()           // 位图
    ├── m_scene.flush()             // 场景实体
    ├── m_worldTexts.flush()        // 世界文字（图纸文本）
    └── buildSceneEnvText()         // 屏幕文字（标尺刻度）
        └── m_text.flush()          // ← 标尺刻度值等
rxSessionEndFrame
```

### 3.5 关键设计要点

1. **排版在宿主侧** - RenderX 不做文本布局，只提供字形度量（`rxFontGlyph`）
2. **字形图集在 DLL 侧** - 纹理由 RenderX 管理，宿主只提交顶点
3. **覆盖率图集 vs SDF 图集**：
   - 覆盖率：屏幕定尺寸文字，放大后模糊
   - SDF：世界文字，缩放级别无关（用 `fwidth(d)` 自动抗锯齿）

### 5.3 网格 (GridLayer)

**实现**: 集成在 `TableLayer` 中

**自适应步长算法** (1-2-5 序列):
```cpp
float TableLayer::computeNiceStep(float wpp, float targetPx) {
    float targetStep = wpp * targetPx;
    float magnitude = std::pow(10.0f, std::floor(std::log10(targetStep)));
    float norm = targetStep / magnitude;

    // 1-2-5 序列
    if (norm < 1.5f)      return 1.0f * magnitude;
    else if (norm < 3.5f) return 2.0f * magnitude;
    else if (norm < 7.5f) return 5.0f * magnitude;
    else                  return 10.0f * magnitude;
}
```

## 6. 多语言文字渲染支持

### 6.1 技术架构概述

RenderX 的字体渲染采用 **宿主- DLL 分离架构**：

```
宿主侧 (UI)                    RenderX DLL
┌─────────────────┐           ┌─────────────────┐
│ TextQuadBuilder │           │   rxFont.cpp   │
│                 │           │                 │
│ 1. UTF-8 解码  │ ──────►   │ stb_truetype   │
│ 2. 字形度量查询 │  codepoint │                │
│ 3. 排版计算    │ ◄──────── │ 字形光栅化      │
│ 4. 四边形组装   │  GlyphInfo │ 字形图集打包    │
│                 │ ──────►   │ GPU 纹理上传    │
└─────────────────┘ 顶点       └─────────────────┘
```

**职责分工**：
- **宿主侧**：UTF-8 解码、文本排版（换行、对齐）、四边形顶点计算
- **DLL 侧**：字形光栅化、图集管理、GPU 纹理上传

### 6.2 RenderX 字体 API

#### 6.2.1 字体创建 (`rxFontCreate`)

```cpp
// renderx.h
struct FontDesc {
    const void* data;        // TTF/OTF 字体字节数据
    uint64_t dataBytes;     // 字体数据大小
    float pixelHeight;      // 光栅化像素高度
    uint32_t sdfPadding;   // SDF 距离场边距（>0 表示 SDF 模式）
    uint32_t atlasWidth;    // 图集宽度（默认 1024）
    uint32_t atlasHeight;   // 图集高度（默认 1024）
};

RxResult rxFontCreate(RuntimeHandle runtime, const FontDesc* desc, FontHandle* outFont);
```

#### 6.2.2 字形查询 (`rxFontGlyph`)

```cpp
// 查询单个 Unicode 码点的字形信息
RxResult rxFontGlyph(RuntimeHandle runtime, FontHandle font, 
                     uint32_t codepoint, GlyphInfo* outGlyph);

// 字形信息包含：
struct GlyphInfo {
    float u0, v0, u1, v1;    // 图集 UV 坐标（归一化到 [0,1]）
    float bearingX, bearingY; // 相对笔位置的像素偏移
    float width, height;      // 字形像素尺寸
    float advance;            // 笔位置推进量
};
```

#### 6.2.3 关键设计点

1. **懒加载图集**：创建字体时不预烘任何字符，字形在首次 `rxFontGlyph` 时才光栅化
2. **缺字处理**：当字体中没有某个码点时，返回全零字形（静默跳过，不崩溃）
3. **两套模式**：
   - **覆盖率图集** (`sdfPadding = 0`)：用于屏幕定尺寸文字
   - **SDF 图集** (`sdfPadding > 0`)：用于世界空间文字，缩放级别无关

### 6.3 UTF-8 支持实现

#### 6.3.1 码点解码

```cpp
// TextQuadBuilder.cpp
uint32_t codepoint = 0;
i += decodeUtf8(item.text + i, textLength - i, codepoint);

// 查询字形
if (Render::RT::rxFontGlyph(m_runtime, batch->font, codepoint, &glyph)) {
    // 组装四边形顶点...
}
```

#### 6.3.2 旧实现的缺陷修复

代码注释中提到旧实现的三个缺陷：

> 1. **UTF-8**：旧实现逐**字节**当码点（`for (const char* p = text; *p; ++p)`），ASCII 正常，任何中文会被拆成 2~3 个 0x80~0xFF 的伪码点，画出乱码方块。
> 2. **vAlign 编号**：旧实现用 1=Top / 2=Middle / 3=Bottom，而 Eg::UiTextVAlign 是 0=Top / 1=Middle / 2=Bottom，整体错位一位。
> 3. **行高**：旧实现用本行字形包围盒，导致「100」和「120」因为有没有下伸部而落在不同基线上。

| 其他 Unicode | ❌ 不支持 | 取决于字体是否包含 |

#### 6.4.3 缺字时的行为

```cpp
// rxFont.cpp:219-225
const int glyphIndex = stbtt_FindGlyphIndex(&font.info, static_cast<int>(codepoint));
if (glyphIndex == 0)
{
    // 字体里没有该码点。这不是错误：CAD 图纸里出现字体不覆盖的字符很常见，
    // 整行排版不该因此中断。缓存全零结果，避免每帧重复查同一个缺字。
    font.glyphs.emplace(codepoint, info);
    *outGlyph = info;
    return RxResult::Ok;  // 返回成功，但不绘制任何内容
}
```

### 6.5 多语言支持方案

#### 6.5.1 方案对比

| 方案 | 描述 | 优点 | 缺点 | 工作量 |
|------|------|------|------|--------|
| **替换字体** | 使用支持多语言的字体 | 简单直接 | 字体文件较大，无法覆盖所有语言 | 低 |
| **字体回退链** | 主字体缺字时尝试备用字体 | 支持更多语言 | 需要管理多个字体文件 | 中 |
| **系统字体** | 动态加载系统字体 | 覆盖全面 | 跨平台兼容性处理复杂 | 中 |
| **混合方案** | 常用语言内置 + 系统字体回退 | 平衡性能与覆盖 | 实现复杂度最高 | 高 |

#### 6.5.2 推荐方案：内置字体 + 系统字体回退

**第一步：准备多语言字体**

**第二步：实现字体回退链**

```cpp
class FontFallbackManager {
    std::vector<FontHandle> m_fonts;  // 按优先级排序的字体列表

    GlyphInfo queryGlyph(uint32_t codepoint) {
        for (auto& font : m_fonts) {
            GlyphInfo info;
            if (rxFontGlyph(m_runtime, font, codepoint, &info) == Ok 
                && info.width > 0) {
                return info;  // 找到字形
            }
        }
        return GlyphInfo{};  // 所有字体都缺字
    }
};
```
