# i18n 文案与自检门禁

> 状态说明（2026-11-11）　状态：现行　维护：架构组

## 1. 目标与范围

本文说明配置驱动 UI 的文案从哪里来、如何被翻译、以及如何用 `Tools/check_i18n.py`
在提交前发现「缺译文 / 缺提取声明」。范围仅限 `base.json` 的 `label` 与 `tooltip`；
代码里的 `tr()` 文案、状态栏、对话框等仍由常规 `lupdate` / `lrelease` 流程覆盖。

## 2. 文案来源与运行时链路

```text
Main/Src/UI/ClientConfig/configs/base.json
    label / tooltip（英文源文案）
        → UiLayoutBuilder::localizedLabel() / localizedTooltip()
            → uiLocalizedLabel()（UiLabelLocalizer.cpp）
                → QCoreApplication::translate(<context>, source)
                    → UI/Common/Translations/April_zh.qm（编译产物）
```

要点：

- 运行时按 `TRANSLATION_CONTEXTS` 顺序尝试多个 context，命中即缓存；
- context 首选 `WorkbenchMenuManager`，这也是 `.ts` 与 `QT_TRANSLATE_NOOP` 使用的 context；
- 未命中译文时回退原始英文，不阻断渲染；
- `skippedByBuilder: true` 的节点不参与检查（其工具栏由 `Workbench2D` / `Workbench3D` 自建，JSON 文案不会渲染）。

## 3. 提取声明

`UI/Common/Src/MenuLayoutTranslationStrings.cpp` 集中存放配置文案的
`QT_TRANSLATE_NOOP("WorkbenchMenuManager", "...")` 声明。它们不参与运行逻辑，
只用于让 `lupdate` 把 JSON 里的文案当作可翻译条目收录。

- 文案一旦从该文件消失，`lupdate` 会把它当「过期条目」从 `.ts` 删除；
- 因此**新增或修改 `base.json` 文案时，必须同步该声明文件**；
- `label` 与 `tooltip` 走同一套声明与 context。

## 4. 自检门禁 `Tools/check_i18n.py`

### 4.1 用法

```bash
python Tools/check_i18n.py
python Tools/check_i18n.py --config Main/Src/UI/ClientConfig/configs/base.json
python Tools/check_i18n.py --config a.json --config b.json --ts UI/Common/Translations/April_zh.ts
```

| 参数 | 说明 |
|---|---|
| `--config` | 要检查的配置 JSON，可重复；默认 `Main/Src/UI/ClientConfig/configs/base.json` |
| `--ts` | 目标翻译文件；默认 `UI/Common/Translations/April_zh.ts` |

### 4.2 检查项

1. 配置中每个去重后的 `label` / `tooltip` 都能在目标 `.ts` 的 `WorkbenchMenuManager`
   context 中命中 `<source>`；
2. 命中的 `<message>` 必须有非空 `<translation>`，`type="unfinished"` 视为未完成；
3. 每条文案都能在 `MenuLayoutTranslationStrings.cpp` 找到对应的 `QT_TRANSLATE_NOOP`。

`Help → Language` 下的原生语言名（`English`、`简体中文` 等）刻意保持原文，跳过检查。

### 4.3 输出与退出码

```text
检查完成: label 161 条, tooltip 27 条, 跳过原生语言名 14 条, 问题 0 条
```

- `0`：全部通过；
- `1`：存在缺译文、空译文或缺少提取声明；
- `2`：配置或 `.ts` 文件不存在。

失败时逐条打印 `ERROR:` 前缀的原因，可直接接入 CTest / 构建流水线。

### 4.4 当前状态（重要）

- **本机可用，尚未入仓**：`.gitignore` 的 `Tools/*` 规则未给 `check_i18n.py` 开例外，
  因此该脚本当前**不在版本库内**，其他机器拉取仓库后不会自带此门禁；
- 是否把 `Tools/check_i18n.py` 加入 `.gitignore` 白名单（与 `docs_check.py` 同级）

## 5. 修改文案的标准步骤

1. 改 `Main/Src/UI/ClientConfig/configs/base.json` 的 `label` / `tooltip`；
2. 同步 `UI/Common/Src/MenuLayoutTranslationStrings.cpp` 的 `QT_TRANSLATE_NOOP`；
3. 运行 `lupdate` 生成/更新 `April_zh.ts`，补齐 `<translation>`；
4. 运行 `python Tools/check_i18n.py`，确认退出码为 `0`；
5. 运行 `lrelease` 产出 `.qm`，启动应用目视确认菜单与 tooltip 显示中文。

## 6. 与文档门禁的分工

| 门禁 | 检查内容 | 入口 |
|---|---|---|
| `Tools/docs_check.py` | Markdown 断链、过期、未入索引 | [文档总览](../00-索引与总览/文档总览.md) 维护约定 |
| `Tools/check_i18n.py` | 配置文案的译文与提取声明 | 本文 |

两者互不替代：文档门禁不检查 `.ts`，i18n 门禁也不检查 Markdown。
