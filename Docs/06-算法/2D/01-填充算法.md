## 4. 处理流程

### 4.1 准备与分发

1. 取当前选中图元存入 `m_entities`，并调用 `prewarmCaches` 在主线程预热惰性缓存（[AlgorithmTaskRegistration2D.cpp L205-L206](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L205-L206)）。
2. 弹 `FillDialog`，`getUIParams().toTaskParams()` 直接生成 `FillTaskParams`，再做 `isValid()` 校验（[AlgorithmTaskUiHost2D.cpp L77-L95](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskUiHost2D.cpp#L77-L95)）。
3. `doCompute` 按 `style` 调不同引擎函数（[AlgorithmTaskRegistration2D.cpp L210-L263](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L210-L263)）；`doApply` 只负责把计算结果写入场景。

### 4.2 线填充（hatch）

`EntityFiller::computeFill`（[EntityFiller.cpp L102-L175](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityFiller.cpp#L102-L175)）：

1. `EntityDiscretizer::doDiscretize` 把选中图元离散为折线点集；返回 0 则失败。
2. 构造 `EntityFill`，`setOutlines` 后执行 `doFill()`。
3. 若 `bCrossFill`，复制参数并把 `dAngle += 90.0` 再跑一遍，两次结果按"主线 + 交叉线"顺序合并。

`EntityFill::doFill`（[EntityFill.cpp L686-L716](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L686-L716)）：

1. **边界内缩**：`dInset = dMargin + 0.5 * dKerf`，`dInset > 0` 时调用 `Geo2DOffset::offsetContours`（`bInset=true`、圆角）内缩全部轮廓；内缩后为空则直接判定失败（[EntityFill.cpp L649-L683](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L649-L683)）。
2. **轮廓简化**：`simplifyAllOutlines()`；注释明确说明不能改用 `LinesIntersection`，否则水平/共线顶点会拆坏轮廓。
3. **建边**：`initAllEdge` 对每条轮廓按顶点顺序建 `FillEdge`，跳过零长度边；把坐标先反向旋转 `-dAngle`、再乘精度并四舍五入成整点，使后续扫描统一为水平扫描（[EntityFill.cpp L103-L195](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L103-L195)）。
4. **分组**：`ScanlineFill::buildFillGroups` 按轮廓嵌套关系分组（外环 + 孔洞成组），因此孔洞区域不会被填充。
5. **弓形填充**（`FillType::Bow`）额外建立按 Y 分桶的边哈希表，`filterEdge` 用奇偶射线法标记需要绘制的边，再逐边扫描（[EntityFill.cpp L359-L446](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L359-L446)）。
6. **扫描线填充**（`L2R` / `R2L` / `Bi`）：以 `dSpacing * nPrecision` 为整型步长逐行扫描；`Bi` 每行左右交替；输出点用同一采样 Y 值并反向旋转回原角度（[EntityFill.cpp L482-L539](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L482-L539)）。
7. 结束后清理临时数据，返回是否产生填充线。

写回（[EntityFiller.cpp L177-L229](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityFiller.cpp#L177-L229)）：所有线段合并为**一个批次**，每条生成 `AprLine`（开放、继承首源图元的 `basePoint` 与图层），通过 `SceneEditService::addEntities(..., "Fill", CommitMode::Undoable)` 一次提交，因此一次撤销即可清空整次填充。

### 4.3 色块填充

`EntityColorFiller::computeRegions`（[EntityColorFiller.cpp L190-L206](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityColorFiller.cpp#L190-L206)）：

1. **连通分量划分**：包围盒空间索引 + 并查集，把 bbox 相交的图元合并为同一分量（[EntityColorFiller.cpp L537-L585](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityColorFiller.cpp#L537-L585)）。
2. **图元 → 闭合轮廓**：`Geo2DBoolean::entityToContours`，只保留点数 ≥3 的轮廓。
3. **可选的并集**：`mergeIntersecting && 分量图元数 > 1` 时用 `uniteContours(EvenOdd)` 消融重叠区域（[EntityColorFiller.cpp L622-L630](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityColorFiller.cpp#L622-L630)）。
4. **嵌套解析**：`ContainmentResolver::resolveDepths` 求每个环的嵌套深度，`buildFillRegions` 把环分成外环与孔洞；`EvenOdd` 规则下孔洞不填充。
5. **面积过滤**：外环面积 `< minRegionArea` 的区域直接丢弃。
6. **三角剖分**：`PolygonTriangulator::triangulateToSoup(outer, holes)` 生成三角形汤；失败仅告警并跳过该区域。
7. 每个区域记录 `sourceEntityIds`，供后续按来源删除旧填充。

写回（[AlgorithmTaskRegistration2D.cpp L327-L361](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L327-L361)）：`findOrCreateFillLayer(targetLayerName)` 取得目标填充图层；在 `runAsSingleUndoStep("Color Fill")` 内先按来源图元删除旧填充、再写入新的 `AprFillRegion`（三角形 + 来源 id + 覆盖色）。最后同步该图层的填充色与 `isLayerFill` 标志。

### 4.4 同心环填充

`EntityContourFiller::computeRings`（[EntityContourFiller.cpp L187-L288](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityContourFiller.cpp#L187-L288)）：

1. `collectClosedLoops`：离散化后只收闭合轮廓（首尾点差 ≤ 线性容差），**开路径直接跳过并计数**，去掉与首点重合的收尾点（[EntityContourFiller.cpp L107-L152](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityContourFiller.cpp#L107-L152)）。
2. `Geo2DOffset::insetRingLayers`：先 EvenOdd Union 归一化，再逐层 `InflatePaths(-step)` 内缩；每层强制 EvenOdd Union 归一化，防止细颈分裂后的绕向混乱逐层放大（[Geo2DOffset.cpp L595-L723](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DOffset.cpp#L595-L723)）。
3. 层终止条件（任一满足）：归一化结果为空；该层净面积 `< dMinArea`；相邻两层最小间距 `< 0.3 × step`（防止过烧）。层数同时受 `nMaxLayers` 与内部硬上限 `kInsetRingMaxLayers = 500` 约束（[Geo2DOffset.h L18](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Geometry/Geo2DOffset.h#L18)）。
4. `bKeepOuterBoundary`：把归一化后的原始轮廓作为一层（`nLayerIndex = -1`）插到最前。
5. `bOuterToInner == false`：整体反转层序，保证输出顺序即加工顺序。

### 4.5 螺旋填充

`EntityContourFiller::computeSpiralPaths`（[EntityContourFiller.cpp L290-L377](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityContourFiller.cpp#L290-L377)）：

1. 同样只收闭合轮廓，开路径计数跳过。
2. `Geo2DOffset::insetSpiralPaths` 先生成环层，再把环按拓扑层级串成连续路径（[Geo2DOffset.cpp L725 起](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DOffset.cpp#L725)）：
   - 桥接容差 `dLinkTolerance == 0` 时取 `2 × step`，仅用于记录/诊断，不作主配对判据。
   - 跨层配对按"几何包含比例 ≥ 0.8"判断，不按最小距离，避免把凹口两侧壁面误配。
   - 塌缩残渣剔除需同时满足：内切半径 `2A/P < 1.5×step`、周长 `< 6×step`、面积 `< 2×step²`。
   - 输出点必须落在源区域（EvenOdd 归一化）内，越界守卫容差为 `0.5 × 10^-4`（Clipper 量化半格）。
3. 拓扑分裂时降级为多条路径，每条路径之间需要空移；`outJumpCount = paths.size() - 1`。
4. `bOuterToInner == false` 时先反转路径顺序，再反转每条折线，使起点落在最内圈。
5. `bKeepOuterBoundary` 对螺旋无效（会破坏单条连续路径语义）。

## 5. 坐标、单位与精度

- 工程长度单位为 **mm**；对话框偏移/间距按 mm 输入（`FillDialog` 单位标签为 mm/°/mm²，[FillDialog.cpp L163-L260](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/UI/Dlg/FillDialog.cpp#L163-L260)）。
- 线填充内部使用定点网格：`step = lround(dSpacing × nPrecision)`，坐标 `lround(x × nPrecision)`，实际取调用方传入的 `nPrecision`（[EntityFill.cpp L73-L90](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Fill/PolygonFill/EntityFill.cpp#L73-L90)）。`EntityFill` 构造函数内部的 10000 只是默认值，会被 `setParameters` 覆盖。
- 几何布尔/偏移统一使用 Clipper 十进制精度 `kClipperDecimalPrecision = 4`（[Geo2DTypes.h L17](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Geometry/Geo2DTypes.h#L17)）。
- 同心环/螺旋的 `GeometryContext` 使用默认容差（线性 1e-8、角度 1e-6 量级），偏移的圆弧逼近由 `dArcTolerance` 控制。
- 色块填充的 `GeometryContext` 由参数构造：`GeometryContext(1e-8, 1e-6, discretizeTolerance, 1.0, minTriangleArea)`（[EntityColorFiller.cpp L75-L79](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityColorFiller.cpp#L75-L79)）。

## 6. 绕向与孔洞处理

- 布尔/偏移前统一用 `EFillRule::EvenOdd` 做一次 Union，外环 CCW、孔洞 CW，随后交给 Clipper 识别孔洞（[Geo2DOffset.cpp L536-L544](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DOffset.cpp#L536-L544)）。
- 线填充按 `buildFillGroups` 分组，孔洞所在的组不会被扫描线填充。
- 色块填充按嵌套深度区分外环/孔洞；仅外环参与三角剖分，孔洞作为 `holes` 传入剖分器。
- 同心环每层面积按有符号面积累加后取绝对值，孔洞面积不会被误算成材料面积（[Geo2DOffset.cpp L669-L687](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DOffset.cpp#L669-L687)）。

## 7. 输出与撤销

| 样式 | 输出图元 | 图层 | 撤销 |
|---|---|---|---|
| 线填充 | 多条开放 `AprLine` | 首源图元图层 | `addEntities(..., CommitMode::Undoable)`，整批一次撤销 |
| 色块填充 | `AprFillRegion`（三角形汤 + 来源 id + 颜色） | `findOrCreateFillLayer` 目标填充层 | `runAsSingleUndoStep("Color Fill")` 合并"删旧 + 写新" |
| 同心环 | 每条闭合环一个闭合 `AprPolygon` | 与首源图元同层（含 0 号图层回填） | 整批 `CommitMode::Undoable` |
| 螺旋 | 每条连续路径一个开放 `AprPolygon` | 与首源图元同层 | 整批 `CommitMode::Undoable` |

同心环/螺旋不设置覆盖色，写入后由 `restoreSourceLayer` 统一归位到首源图元图层（[EntityContourFiller.cpp L156-L185](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/EntityContourFiller.cpp#L156-L185)），颜色回落到图层色，源图层改色后填充同步变色。

## 11. 旧文档差异

- 旧文档 `Docs/06-算法专题/线填充算法.md` 记录结构体默认角度 0°，而旧版对话框硬编码 33.3°，两处不一致。现已统一：**33.3° 提升为结构体默认值**（[FillParameters.h L32](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Algorithm/Fill/FillParameters.h#L31)）。判定依据：初始提交中对话框显式注释掉 `setValue(0.0)` 并改为 33.3，且 33.3° 可避免扫描线与水平/垂直轮廓边平行导致的重合切割。

- 两处默认值由 `UI/2D/Test/FillDialogColorTests.cpp` 的 `FillDialogDefaults.WidgetsFollowParameterStruct` 与 `Engine/2D/Test/FillAlgorithmTests.cpp` 的默认值断言共同锁定。
- 旧文档未包含同心环/螺旋的层终止条件（`0.3 × step` 最小间距、`kInsetRingMaxLayers = 500`、塌缩三条件）与"开路径静默跳过"行为。
