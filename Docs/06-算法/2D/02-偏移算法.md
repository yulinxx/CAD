## 4. 处理流程

### 4.1 准备

1. 校验场景与选中集（先校验再弹窗，避免无效弹窗）。
2. 弹 `OffsetDialog`；取消返回 `userCancelled=true`。
3. 校验参数；`prewarmCaches` 在主线程预热源图元惰性缓存（[L540-L541](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L540-L541)）。

### 4.2 计算（`EntityOffset::computeOffsetEntities`）

1. **并行离散化**：`EngineParallel::parallelForIndex` 逐图元离散，结果写入 `perEntity[i]`；空指针图元跳过（[EntityOffset.cpp L132-L144](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Offset/EntityOffset.cpp#L132-L144)）。
2. **汇总轮廓**：按图元顺序展平为 `allContours`；为空则返回 false（无任何可偏移几何）。
3. **参数转换**：`toGeo2DOffsetParams` 把 `Inset` 转为 `bInset=true`，角点类型映射到 `Geo2DJoinType`（[EntityOffset.cpp L19-L39](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Offset/EntityOffset.cpp#L19-L39)）。
4. **整体偏移**（`Geo2DOffset::offsetContours`，[Geo2DOffset.cpp L527-L593](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DOffset.cpp#L527-L593)）：
   - ① 以 `EvenOdd` 规则 `uniteContours` 归一化：消融重叠区域，并把"外轮廓 + 孔洞"整理为正确嵌套与相反绕向；结果为空则返回空。
   - ② 所有归一化轮廓作为**单一主体**调用 `Clipper2Lib::InflatePaths(..., EndType::Polygon, miterLimit, kClipperDecimalPrecision=4, arcTolerance)`；内缩时 delta 取负。
   - 孔洞随外轮廓同步外扩/内缩，内缩到消失时自动丢弃。
5. **结果转图元**：每条路径 `Geo2DBoolean::contourToPolygon` 生成闭合 `AprPolygon`（`basePoint` = 首点，[Geo2DBoolean.cpp L219-L231](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Geometry/Geo2DBoolean.cpp#L219-L231)）；点数 <3 的路径被丢弃。

### 4.3 落场景

`doApply` 在 `runWithFullSceneUndo(..., "Offset")` 内执行（[L597-L609](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L597-L609)）：

- `bKeepOriginal == false`：`deleteEntitiesBatch(原选中集)`；
- 然后 `addEntities(新多边形)`。

整次操作是**一条全场景撤销记录**，撤销可同时恢复被删的原图元与新图元。

## 5. 处理规则与精度

- 长度单位 mm；偏移量在 UI 侧按显示单位输入后折算为 mm。
- Clipper 十进制精度固定为 `kClipperDecimalPrecision = 4`（[Geo2DTypes.h L17](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Geometry/Geo2DTypes.h#L17)），即内部按 1e-4 mm 量化。
- 归一化使用 `EvenOdd`：重叠的同向轮廓会被视为"并集 + 交替孔洞"，不按奇偶填充以外的规则处理。
- `EndType::Polygon` 意味着**所有输入都按闭合多边形处理**；开放折线会被隐式首尾相连后再偏移，不会生成"沿开路径两侧"的带状结果。
- 偏移结果不携带源图元颜色/线宽，落场景后按当前图层规则分配；与填充算法"归位到源图层"的行为不同。
- 输出只有外环/孔洞路径，不含原始顶点对应关系，无法逐图元回溯。

## 6. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 场景为空 | `canRun` 返回 false，菜单不可执行 |
| 未选中图元 | 准备失败：`No entities selected for offset.` |
| 参数非法 | 准备失败：`Offset parameters are invalid, please check.` |
| 所有图元都离散不出轮廓 | `computeOffsetEntities` 返回 false → `Offset produced no result, please check parameters.`（`OffsetEmpty`） |
| 内缩量大于几何最小半宽 | Clipper 返回空集 → 同上 `OffsetEmpty` |
| 计算中取消 | 清空结果，`userCancelled=true`，不写场景 |
| 部分图元离散化失败 | **静默忽略**该图元，其余图元继续偏移（离散化失败不报错） |
| `bKeepOriginal=false` 且结果为空 | 由于先判断 `m_created<=0` 就返回，原图元**不会被删除** |

## 9. 旧文档差异

- 旧文档记录结构体默认 `joinType = Round`，而旧版 `OffsetDialog` 打开时默认选中 Square，两处不一致。判定依据：初始提交在设置方角处留有 `// 默认方角` 注释，属明确意图，因此**把 Square 提升为结构体默认值**（[OffsetParameters.h L27](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Algorithm/Offset/OffsetParameters.h#L27)），对话框改为从结构体取初值。
- 该默认值由 `Engine/2D/Test/OffsetAlgorithmTests.cpp` 的默认值断言与 `UI/2D/Test/DialogDefaultsTests.cpp` 的 `DialogDefaults.OffsetDialogJoinTypeFollowsStruct` 共同锁定。
- 旧文档把 `algo.offset` 与 `edit.offset` 当作两条实现，实际二者都解析到 `OperationId::Algo_Offset`，共用同一 handler。
- 旧文档未说明"开放折线会被 `EndType::Polygon` 隐式闭合"以及"离散化失败的图元被静默忽略"这两条边界行为。
