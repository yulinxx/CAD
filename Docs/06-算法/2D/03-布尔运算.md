## 4. 处理流程

### 4.1 准备

1. 校验场景与选中数量。
2. 从 `req.params["booleanOp"]` 读取并校验类型；缺失或非法直接失败（[L685-L707](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L685-L707)）。
3. 弹 `BooleanDialog`（取消返回 `userCancelled`），参数回填 `bKeepOriginal`。
4. `prewarmCaches` 预热源图元缓存。

### 4.2 计算（`EntityBoolean::computeBooleanEntities`）

1. `EngineParallel::parallelForIndex` 并行离散化每个图元，每个图元保留"轮廓列表"层级；点数 <3 的轮廓丢弃（[EntityBoolean.cpp L202-L235](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L202-L235)）。
2. 任一图元无轮廓 → 整体返回空（全有或全无）。
3. 按运算类型调用 `computeBoolean`（[EntityBoolean.cpp L46-L140](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L46-L140)）。
4. 每条结果轮廓通过 `Geo2DBoolean::contourToPolygon` 生成闭合 `AprPolygon`（`basePoint` = 首点）。

### 4.3 四种运算的语义

**Union（并集）**：把所有图元的所有轮廓展平后一次性 `uniteContours`（[EntityBoolean.cpp L70-L72](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L70-L72)）。所有被覆盖区域合并，内部重叠边界消融；孔洞按 NonZero 规则保留。

**Intersection（交集）**：以第一个图元的轮廓为初始结果，依次与后续每个图元的轮廓求交，**链式折叠**；中间结果为空则提前结束（[EntityBoolean.cpp L73-L94](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L73-L94)）。顺序不影响最终交集，但会决定提前退出的时机。

**Difference（差集）**：第一个图元为被减数，其余所有图元的轮廓先 `uniteContours` 成"减数集合"，再一次性相减（[EntityBoolean.cpp L96-L119](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L96-L119)）。因此"选中顺序"很关键：**第一个选中的图元是被减数**。

**Xor（异或）**：同样链式折叠，每次与下一个图元做异或；奇数次覆盖保留，偶数次覆盖消去（[EntityBoolean.cpp L121-L135](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/Boolean/EntityBoolean.cpp#L121-L135)）。

### 4.4 落场景

`doApply` 在 `runWithFullSceneUndo(..., "Boolean")` 内执行（[L770-L779](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L770-L779)）：

- `bKeepOriginal == false`：先 `deleteEntitiesBatch(选中集)`；
- 再 `addEntities(结果多边形)`。

整次操作一条撤销记录，撤销同时恢复被删图元并移除结果。

## 5. 绕向、孔洞与精度

- 布尔底层统一走 Clipper2，精度 `kClipperDecimalPrecision = 4`（[Geo2DTypes.h L17](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Include/Engine2D/Geometry/Geo2DTypes.h#L17)）。
- 默认填充规则 `NonZero`；轮廓绕向由 Clipper 输出保证（外环/孔洞相反），调用方不再额外归一化。
- `Geo2DBoolean::entityToContours` 只处理闭合轮廓；而 `EntityBoolean::collectContours` 直接使用离散化结果，**开放折线会被 Clipper 当作闭合轮廓填充**，命令层不做拦截。
- 结果图元只保留几何，不携带源图元的颜色、线宽、图层；落场景后按当前图层规则分配。

## 6. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 选中图元 < 2 | 准备失败，明确提示 |
| `booleanOp` 缺失 / 非法 | 准备失败：`Boolean operation type is missing/invalid.` |
| 任一图元离散化失败 | 整次失败，日志给出图元 id；不产生部分结果 |
| 交集/差集无公共区域 | 结果为空 → `Boolean operation produced no result.`（`BooleanEmpty`） |
| 用户取消 | `userCancelled=true`，不写场景 |
| 结果为空且 `bKeepOriginal=false` | 由于先判空再落场景，原图元**不会被删除** |
| 开放折线参与运算 | 隐式按闭合区域处理，不报错 |
| 自相交图元 | 由 Clipper NonZero 规则自行解释，可能出现孔洞/重叠区域合并，代码不做预校验 |
