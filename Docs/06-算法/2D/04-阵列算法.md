## 4. 处理流程

### 4.1 准备

1. 取 `getSelectedEntities()` 并过滤空指针。
2. 绑定取消回调 `isCancelled()` 与进度回调。
3. 若 `req.params` 有关键字则直接覆盖参数；否则弹 `ArrayDialog`，并用 `toAlgorithmParams()` 回填，同时保留调用方预置的取消/进度回调（[L234-L242](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskUiHost2D.cpp#L234-L242)）。
4. 逐图元 `prewarmCaches()`（工作线程会并发 `clone/getBbox`，惰性缓存必须先在主线程预热）。

### 4.2 矩形阵列（`createRectangularArray`）

1. **规模护栏**：`rows × cols` 必须 > 1，且 `rows × cols × 源图元数 ≤ kMaxCreatedEntities = 2,000,000`，超限返回 `InvalidParams`（"Array result too large"）（[ArrayAlgorithm.cpp L326-L363](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L326-L363)）。
2. 源包围盒取所有选中图元的并集，得到 `sourceWidth/sourceHeight`。
3. 按 `traversalOrder` 生成位置顺序（`RowFirst/ColumnFirst/Spiral/Zigzag`；`TSPGreedy/TSP2Opt` 当前只保留枚举、不改变顺序）（[L227-L317](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L227-L317)）。
4. `EngineParallel::parallelCollect` 每个位置独立克隆：跳过 `(0,0)` 原位；平移量 `offsetX = c × (sourceWidth + colSpacing)`、`offsetY = r × (sourceHeight + rowSpacing)`；克隆体执行 `transform(translation)`、继承源图层（`setLayer`）、清空群组指针（[L396-L443](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L396-L443)）。
5. 合并顺序固定为位置升序，保证 EntityId 分配与撤销栈可复现。
6. 取消时清空结果并返回 `ArrayErrorCode::Cancelled`。

**注意**：间距是"图元包围盒边到边"的净间距，不是中心距；跨格步长 = 源包围盒尺寸 + 间距。

### 4.3 环形阵列（`createCircularArray`）

1. 规模护栏同上，`count × 源图元数 ≤ 2,000,000`；`count <= 1` 直接判无效（[L474-L504](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L474-L504)）。
2. 角度步长（[L539-L545](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L539-L545)）：
   - `angle < 360°`：`step = angle / (count - 1)`，末位副本正好落在 `angle` 上；
   - `angle >= 360°`：`step = angle / count`，避免末位与首位重叠（`count=6, angle=360` → 60°，而非旧实现的 72°）。
3. `count` 是**含原位的总份数**，实际新增 `count-1` 份。
4. 每个副本的变换：`translate(circleX, circleY) × rotate(signedAngle) × translate(-center)`，即"绕中心旋转后平移到半径圆上的位置"；顺时针取负角，位置与自转共用同一个带符号角度（[L566-L586](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L566-L586)）。
5. 旋转中心：`centerSpecified ? center : 源包围盒中心`。
6. 克隆体同样继承图层、清空群组。

### 4.4 落场景与群组

`doApply`（[L173-L286](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Option/ArrayProcessor.cpp#L173-L286)）：

1. 经 `SceneEditService::addEntities(..., "Array", CommitMode::Undoable, progress)` 一次批量提交，**一次撤销清空整份阵列**。
2. 撤销命令内部会再克隆一次，因此必须按返回的 `insertedIds` 反查场景对象，否则群组会持有撤销栈中的场外指针（[L229-L240](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Option/ArrayProcessor.cpp#L229-L240)）。
3. **群组镜像**：按"每份副本 N 个图元"分块，每份副本内部按源群组关系各自建新组（组名 `源组名_copy`），副本之间互不相关，源群组不变（[ArrayAlgorithm.cpp L153-L225](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L153-L225)）。
4. 无 `SceneEditService` 时退化为 `SceneManager::addEntities`，日志 `array result will be un-undoable`。

## 5. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 未选中图元 | 准备失败，提示 `No entities selected for array operation` |
| 无 UI 且无 `req.params` | 失败：`Array parameters are unavailable (no UI host)` |
| `rows × cols ≤ 1` | `InvalidParams`（没有可复制的副本） |
| 计划图元数 > 2,000,000 | 直接拒绝，日志给出 planned 数值，不尝试部分生成 |
| `clone()` 返回空 | 跳过该图元，不报错（可能导致副本不完整） |
| 计算中取消 | 结果清空，`userCancelled=true`，不落场景 |
| 落场景数量与计划不一致 | 仅 `SY_WARN`（landed mismatch），任务仍成功 |
| 群组数量除不尽 | 仅告警 `grouping may shift`，后续副本可能错位分组 |
| 圆形 `angle=360` | 末位不与原位重叠，按 `angle/count` 均分 |

## 8. 旧文档差异

- 旧文档写"环形阵列 `count` 为新增副本数"，当前代码 `count` 是**含原位的总份数**，实际新增 `count-1`。
- 旧文档写"整圈步长 = angle / (count-1)"，当前代码整圈改为 `angle / count`，修复了末位与首位重叠问题（[L539-L545](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/2D/Src/Algorithm/ArrayAlgorithm.cpp#L539-L545)）。
- 旧文档称"阵列结果统一放入一个 `_copy` 群组"，当前实现是每份副本各自成组、镜像源群组结构。
- 旧文档未记录 2,000,000 的产出上限与 `traversalOrder` 在菜单路径不可配置的事实。
- 旧版 `ArrayDialog` 把行数/列数/间距/数量/角度/半径/方向全部写成字面量，虽与 `Eg::ArrayParams` 数值一致但属重复定义；现已改为直接读取 `m_params`（默认构造自结构体），并由 `UI/2D/Test/DialogDefaultsTests.cpp` 锁定初值。
