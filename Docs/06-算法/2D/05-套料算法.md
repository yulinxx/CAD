## 4. 处理流程

### 4.1 零件抽取（prepare，主线程）

1. 选择零件来源并按需展开群组叶子（见第 2 节）。
2. 并行离散化 + 清洗每个零件（[L357-L377](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingPartPreparer.cpp#L357-L377)）：
   - `cleanPolygon`：去重/去共线；自相交时用 Clipper2 `uniteContours(NonZero)` 修复，**只保留面积最大的连通分量**；
   - 外环强制逆时针（有符号面积为负时反转）；面积 <1e-9 视为退化。
3. 面积计算：外环面积减所有孔洞面积，得到净面积。
4. **相同几何合并**：把轮廓平移到以 `refPoint`（外环包围盒中心）为原点的局部坐标，按容差 `tolerance` 量化到 4 位小数生成几何 key；相同 key 的图元归为同一 `partId`，`quantity` 累加（[L392-L459](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingPartPreparer.cpp#L392-L459)）。
5. 零件按面积降序排序后交给求解器。
6. 统计 `totalInstances = Σ quantity`，准备阶段结束；此后 compute 不再访问场景。

### 4.2 求解（compute，工作线程）

`NestingEngine::runNestingAlgorithm`（[L259-L587](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingEngine.cpp#L259-L587)）：

1. 空零件 → `No parts to nest`；重入（已有任务在跑）→ `Nesting engine is already running`。
2. `Nesting_CreateJob` → `Nesting_InitOptions`，透传：间距、板间距、容差、镜像、排序规则、策略、时间上限、线程数、最大板材数、自动板材、目标填充率、迭代代数、孔内套料、共边参数、纹理模式。
3. **旋转角度**（[L153-L185](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingEngine.cpp#L153-L185)）：`enableRotation=false` 只留 0°；否则按 `angleMode` 取 4/8/24 向，再被 `maxRotationCount` 截断（取 min），最后均匀取 `360°/count` 步长。
4. `Nesting_AddSheet`：`marginLeft/Right = marginX`、`marginBottom/Top = marginY`；`sheet.quantity = 0`（不限量），实际由 `opt.maxSheets` 约束。
5. 逐零件 `Nesting_AddPart`：`contours[0]` 为外环，后续为孔洞；点数 <3 的孔洞静默跳过；外环无效直接失败。
6. 注册进度回调：**回调返回 0 即请求中止求解**；框架取消令牌在进度回调中轮询并置位 `cancelFlag`。
7. 启动取消监视线程，每 100 ms 检查 `cancelFlag` 并调用 `Nesting_Cancel`（防止求解器长时间不响应）。
8. `Nesting_Run` → `Nesting_GetReport` → `Nesting_GetPlacement*`。
9. 多板材展开：库返回的 `tx/ty` 是**每张板的局部坐标**，UI 侧按 `k × (sheetWidth + sheetSpacing)` 沿 X 平移第 k 张板，避免多张板重叠（[L540-L568](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingEngine.cpp#L540-L568)）。
10. 结果统计：
    - `placedParts / unplacedParts / totalParts` 来自后端报告；
    - `utilization` 优先取后端 `packedUtilization`（放置面积 / 实际包围盒面积），为 0 时退回 `utilization`；
    - 自动板材模式下用后端推导的 `autoSheetWidth/Height` 覆盖板尺寸。

### 4.3 预览与落场景（apply，主线程）

1. `NestingPreviewDialog(parts, result, sheetPitch)` 展示真实排版；`reject` 或未点"应用" → `success=true, userCancelled=true`，**不落场景**（[L1042-L1054](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L1042-L1054)）。
2. `NestingProcessor::apply` → `NestingEngine::buildNestingEditResult`（[L589-L662](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingEngine.cpp#L589-L662)）：
   - 有独立源图元（阵列/复制实例）：对源图元 `clone` 后做放置变换，作为 **replacement**（保留原 id，撤销可恢复）；
   - 无独立源图元（quantity 扩展出的副本）：`clone` 后作为 **addition**。
3. 放置矩阵：`M = T(tx,ty) · R(rot) · MirrorX?(flip) · T(-refPoint)`；每个实例使用**自己的**包围盒中心作 `refPoint`（阵列实例位置不同，否则会残留原始阵列偏移）。
4. `SceneEditService::applyEditResult(editResult, "Nesting")` 压成一条撤销命令；缺失编辑服务时退回 `applyNestingResults`（直接变换，不可撤销，仅告警）。
5. 结果统计写入 `result.stats`：`totalParts / placedParts / unplacedParts / utilization`。

## 5. 坐标、精度与单位

- 长度单位 mm；板材/边距/间距直接按 mm 传入，无显示单位换算。
- 零件以 `refPoint` 为原点送入核心库，库契约：`p_final = T(tx,ty)·R(rot)·M(mirror)·p_in`（无参考点），回写时补 `T(-refPoint)`。
- 几何归并 key 使用 `tolerance` 量化，输出固定 4 位小数（[L182-L198](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/NestingPartPreparer.cpp#L182-L198)）。
- 自相交修复/清洗使用 `linear = max(1e-9, tolerance × 0.1)`。

## 6. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 场景无图元 | `canRun=false`，菜单不可用 |
| 零件全部无效 | 准备失败：`No valid closed-shape entities` |
| 零件含自相交 | 自动用 Union 修复；修复后只保留最大连通分量（**可能丢小岛**） |
| 图元像板材边框（≥92% 板幅） | 静默过滤，不参与套料 |
| `nestSelectedOnly=true` 但未选中 | 静默回退到全部图元 |
| 部分零件未排下 | **任务仍成功**，`unplacedParts > 0`，不报错 |
| 求解超时（timeLimit） | 按后端返回结果收场；未排下部分按 unplaced 统计 |
| 用户取消求解 | 丢弃部分排版，`Nesting cancelled`，不落场景 |
| 预览阶段取消 | `success=true, userCancelled=true`，不落场景 |
| 多张板材 | 沿 X 方向按 `板宽 + sheetSpacing` 展开到同一画布 |
| `partQuantity > 1` | 同几何合并为同一 partId，放置时第 2..N 份作为 addition 克隆 |
| 核心库创建 job 失败 / 选项设置失败 | 失败并返回 `Nesting_StatusText` + `Nesting_GetLastError` 文本 |

## 9. 旧文档差异

- 旧文档按结构体默认值描述参数（`partSpacing=0.5`、`sheetSpacing=2.0`、`strategy=QUALITY`、孔内套料/共边默认关闭、`angleMode=0`、`allowFlip=false`），与旧对话框初值不一致。判定依据：`NestingDialog` 构造函数对上述字段均标注"质量优化：…"注释，属明确设计意图，因此**将这些值提升进 `Eg::NestingParameters`**：`0.1 / 0.5 / angleMode=1 / allowFlip=true / holeNesting=true / commonLine=true / strategy=1`，对话框改为从结构体取初值。
- `maxRotationCount` 旧记录为对话框 `setValue(24)`，但构造函数随后执行 `syncRotationPreset(1)`，实际初值是 **8**（与 8 向档位一致）。结构体默认值因此定为 8，不再记录 24。
- 仍存在、**未改**的三处漂移（依据不足，待产品确认）：`iterations` 结构体 50 vs 对话框 30；`timeLimitMs` 结构体 0 vs 对话框 300000（代码注释写"60 秒"但实际 5 分钟，注释与值也不一致）；`autoSheetSize` 结构体 true vs 对话框 false。
- 旧文档称"多板材结果会叠加在原点"，当前代码已按 `板宽 + 板间距` 沿 X 展开。
- 旧文档未记录"`nestSelectedOnly` 未选中时回退全场景"与"≥92% 板幅的图元被当作板材边框过滤"。
- 旧文档把"有未排下零件"当作失败；当前代码视为成功，仅在统计与消息中体现。
