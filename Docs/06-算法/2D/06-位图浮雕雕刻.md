## 2. 输入

- 高度图/灰度图文件，由对话框文件选择器提供；**不要求场景中选中位图**。
- 支持格式由 Raster 库决定（`Raster_LoadImage`，底层 OpenCV）；文件路径为空时提示 `Please select a height map image.`（[L71-L78](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L71-L78)）。
- 图像 DPI 不参与计算：Raster 扫描线只输出像素坐标，UI 侧显式声明 `"unit": "px"`，不做 mm 换算（[L27-L29](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L27-L29)、[L115](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L115)）。

## 4. 处理流程

1. 弹模态对话框；`Rejected` 直接返回（[L65-L69](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L65-L69)）。
2. 校验图片路径非空。
3. `BUILD_RASTER` 未开启时提示 `Raster module is not available in this build.` 并结束（[L163-L167](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L163-L167)）。
4. `buildScanlineJob`：
   1. `Raster_LoadImage` 加载图像；失败或空句柄 → 返回 false；
   2. `Raster_GetImageInfo` 读取 `width/height`；
   3. 填充 `RasterScanlineParams`（见第 3 节）；
   4. `Raster_ScanlineJobs` 生成作业列表；
   5. `Raster_DestroyImage` 释放图像。
5. 生成失败 → 提示 `No scanline job generated from the image.`（[L90-L97](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L90-L97)）。
6. `QFileDialog::getSaveFileName` 选择导出路径；用户取消 → 销毁作业列表并返回（[L102-L110](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L102-L110)）。
7. 组装 JSON：
   - 顶层：`type="raster_scanline_job"`、`sourceImage`、`unit="px"`、`width`、`height`；
   - `params`：`lineSpacing / passes / powerPercent / speedMmPerSec`；
   - `segments[]`：逐条 `x0 / x1 / y / y1 / power / speed / pass / dir / laserOn`（[L127-L145](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/ReliefEngravingOperation2D.cpp#L127-L145)）。
8. 写文件，成功弹 `Toolpath exported to <path>`；打开失败弹 `Unable to write: <path>`。

## 5. 输出形态

- 唯一产物：JSON 刀路文件（缩进格式）。
- 不生成 `AprPolygon`/`AprLine`，不修改场景，不进撤销栈。
- 段坐标是**像素坐标**，`dir` 表示扫描方向（0/1），`laserOn` 表示该段是否出光。

## 6. 失败与边界行为

| 场景 | 行为 |
|---|---|
| 未选择图片 | 警告 `Please select a height map image.` |
| `BUILD_RASTER` 关闭 | 提示不支持，无文件产出 |
| 图像加载失败 | 提示 `No scanline job generated from the image.` |
| 图像为纯色/无有效扫描线 | 库返回空作业列表 → 同上提示 |
| `layerHeight` 极小 | 被 `max(0.001, …)` 兜底，`passes` 可能非常大（无上限保护） |
| `maxHeight <= minHeight` | `|差|` 为 0 → `passes` 被钳到 1 |
| 保存路径不可写 | 警告 `Unable to write: …` |
| 中途取消保存 | 释放作业列表，静默返回 |

## 9. 旧文档差异

- 旧文档称该功能"生成浮雕刀路图元写入场景并可撤销"；当前实现只导出 JSON 文件，**不写场景、无撤销**。
- 旧文档称"按图像 DPI 换算毫米"；当前代码把 `pixelPitchMm` 固定为 0，明确不做 DPI 换算，输出单位是像素。
- 旧文档把"需先选中位图"当作前置条件；当前实现通过文件对话框选图，与场景选择无关。
