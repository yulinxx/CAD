## 2. 输入

- **只处理用户显式选中的位图实体**，不做"无选择回退全场景"（破坏性操作，[L322-L332](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L322-L332)）。未选中时提示 `Select one or more image entities to process.`。
- 支持多张同时处理；所有选中图会被**整批替换**，任何一张失败则整批放弃。
- 输入像素统一先转 `Gray8`（[RasterImageSnapshot.h L38-L55](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/RasterImageSnapshot.h#L38-L55)、实现见 [RasterImageSnapshot.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/RasterImageSnapshot.cpp)）：
  - `RGB24`：`0.299R + 0.587G + 0.114B`；
  - `RGBA32`：先按 alpha 合成到白底再转灰度（透明 = 白纸 = 不出光）；
  - `Gray8` 若实际 2 字节/像素，取**高字节**降级；
  - 未知格式按字节宽度推断，仅接受 1/2/3/4 字节。
- 加工极性：**暗 = 加工**。

### 参数合法性矩阵（UI 强制 + Route 校验）

- `Black/White`：阈值可选 Otsu / Fixed；`None` 会被自动改回 Otsu；抖动方法禁用（[L202-L226](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L202-L226)）。
- `Dither` / `Keep Gray`：阈值强制 `None`，抖动控件仅 Dither 可用。
- Route 侧再校验一次：阈值模式必须 0/1/2；抖动方法必须 1..8 且 Dither 模式不得为 None（[ProcessRouteRegistry.cpp L94-L150](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L94-L150)）。非法组合直接拒绝，不进入后台。

## 4. 处理流程

### 4.1 主线程准备

1. 检查 `sceneEdit` 与场景管理器；缺失提示 `Scene manager is not available.`。
2. 防重入：`AsyncPipelineExecutor::isBusy()` 为真时提示 `Another task is already running.`。
3. `RasterProcess::collectSelectedImages` 收集选中的 `AprImage`；空则提示。
4. 构造对话框并生成第一张图的初始灰度预览（`RasterBridge::toGray8` → `QImage::Format_Grayscale8`）。
5. 取消 → 直接返回，场景不变。
6. 组装 `ProcessRoute::Request`：`routeId=BitmapProcess`、`input=ImagePOD`、`output=ImagePOD`，并拷贝 5 个 UI 参数。
7. `ProcessRouteRegistry::find(BitmapProcess)`；未注册 → 错误框 `BitmapProcessRoute is not registered.`。
8. `route->match(req)`；不匹配 → 警告并显示原因。
9. `buildSnapshotFromSources`：主线程把**全部选中图**转 Gray8，并按
   `[version][count]{ [w][h][channels][reserved][quad 8×double][gray w*h] }`
   打包为单条快照（[RasterImageSnapshot.cpp L130-L195](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/RasterImageSnapshot.cpp#L130-L195)）。
10. 记录源图 id 列表。

### 4.2 后台执行（`BitmapProcessRoute::execute`）

逐图处理，所有 Raster 返回值必须为 `RASTER_OK`，否则整批失败（[L190-L330](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L190-L330)）：

1. `Raster_CreateImageFromView` 由快照创建单通道图。
2. 按模式执行（顺序很关键）：
   - **Black/White**：`Raster_Threshold` — Otsu 用 `RASTER_THRESH_OTSU`，固定阈值用 `RASTER_THRESH_BINARY`（阈值取自 UI，最大值 255）；随后若 `invert` 再 `Raster_Invert`；
   - **Dither**：先 `Raster_Invert`（若勾选），再 `Raster_Dither`，**必须在未阈值化的灰度上抖动**；
   - **Keep Gray**：仅 `Raster_Invert`（若勾选）。
3. `Raster_GetImageView` 校验：通道必须为 1、宽高必须与源图一致、`stride >= width`。
4. 按 `stride` **逐行**拷贝像素（避免把行尾对齐填充算进数据）。
5. 记录结果尺寸与世界四角；单图失败即整批返回 `Error`。
6. 每张图之间与关键步骤后检查取消（`ctx.checkCancel()`），取消返回 `Canceled`。

### 4.3 主线程落场景

`apply` 回调只有在后台成功时才执行（[L406-L479](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L406-L479)）：

1. `RasterBridge::parseSnapshot` 还原源快照；失败提示 `The processed snapshot could not be decoded… No source image was modified.`。
2. 三重完整性校验（任一失败都不修改场景）：
   - 快照图数 == 源 id 数；
   - `hasCompleteReplacement(源数, 像素缓冲数)`；
   - `res.sizes.size() == 像素缓冲数 × 2`。
3. `decodeResultImage` 为每张结果创建 `AprImage`（`Gray8`，`setPixelData`），并用 `restoreQuad` 按新尺寸与源四角还原世界位置（[L255-L273](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L255-L273)）。
4. 再次校验新实体数量完整。
5. `runAsSingleUndoStep("Process Bitmap")` 内：`deleteEntities(源 id)` + `addEntities(新图)`（[L470-L476](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L470-L476)）。

## 5. 坐标、单位与精度

- 像素当量来自 `AprImage` 的四角世界坐标（导入时按 DPI 建立的毫米四边形），宿主侧不假设 1 px = 1 mm（文件头注释 [L10-L12](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L10-L12)）。
- 处理前后像素尺寸不变（阈值/反相/抖动均为逐像素操作），`restoreQuad` 缩放比为 1，包围盒保持完全一致。
- `pixelToWorld` 采用仿射假设：只用左上/右上/左下三角，右下角由平行四边形推出（[RasterImageSnapshot.h L91-L110](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/RasterImageSnapshot.h#L91-L110)）；支持旋转/斜切，不支持透视。
- 灰度权重 `0.299 / 0.587 / 0.114`。

## 6. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 场景编辑器缺失 | 警告 `Scene manager is not available.` |
| 已有任务在跑 | 提示并返回（防重入） |
| 未选中图片 | 提示必须显式选择；**不回退全场景**（避免误替换所有原图） |
| 路由未注册 | 错误框（构建配置问题） |
| 参数组合非法 | Route 拒绝并显示原因，无后台任务 |
| 快照构建失败（空像素/尺寸不符） | 警告 `Could not collect snapshot: …`，场景不变 |
| 后台任一图处理失败 | 整批 `Error`，`finished` 信号弹警告，场景不变 |
| 结果数量/尺寸不完整 | 主线程拒绝应用，明确提示 `No source image was modified.` |
| 结果图像解码失败 | 同上，整批放弃 |
| 用户取消后台任务 | `Canceled`，不应用结果 |
| `BUILD_RASTER` 关闭 | 菜单项不注册，无法触发 |

## 9. 旧文档差异

- 旧文档称"未选中时处理场景中全部位图"；当前实现明确禁止回退，只处理显式选中项。
- 旧文档称"处理结果在源图旁新增一份"；当前实现是**原位替换**（先删源再写新，单条撤销）。
- 旧文档称"阈值 + 抖动可同时生效"；当前 UI 与 Route 都禁止该组合，抖动必须在未阈值化灰度上执行。
- 旧文档未记录多图整批"全有或全无"的 apply 校验与逐行 `stride` 拷贝。
