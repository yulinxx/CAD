## 2. 输入

- 图片来源（[L530-L543](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L530-L543)）：
  1. 优先使用**选中**的 `AprImage`；
  2. 未选中时**回退到场景内全部图片**（非破坏性操作，允许回退）；
  3. 场景无图片 → 提示 `No image entities in the scene.`。
- 多图会逐张矢量化，结果按 `contourImageIndex` 归属到对应源图的坐标系。
- 源图**删除与否**：不删除，只新增矢量图元。

## 3. 参数（固定值）

请求参数在 `runVectorize` 中写死（[L504-L512](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L504-L512)）：

| 字段 | 值 | 含义 |
|---|---|---|
| `routeId` | `VectorizeBitmap` | 路由 |
| `inputType` | `ImagePOD` | 输入契约 |
| `expectedOutput` | `ContourSetPOD` | 输出契约 |
| `fitMethod` | `0`（Polygon） | 拟合方式，可选 0 Polygon / 1 Smooth / 2 Arc，菜单路径只用 0 |
| `tolerance` | `1.0` | 轮廓简化容差（像素） |
| `minArea` | `10.0` | 最小轮廓面积（**平方像素**），更小的噪点丢弃 |
| `kerfMm` | `0.0` | 割缝单边补偿（mm）；菜单路径为 0，即不补偿 |

Route 能力协商（[L351-L396](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L351-L396)）：拒绝 `requestEvenOdd` / `requestColor`，并校验 `fitMethod ∈ [0,2]`、`tolerance ≥ 0`、`minArea ≥ 0`、`kerfMm` 有限。

## 4. 处理流程

### 4.1 主线程准备

1. 校验场景编辑器；缺失提示 `Scene manager is not available.`。
2. 查找 `VectorizeBitmapRoute`；未注册提示 `VectorizeBitmapRoute is not registered.`。
3. 组装固定参数请求并 `match`；不匹配显示原因。
4. 防重入检查 `AsyncPipelineExecutor::isBusy()`。
5. 收集源图并构建多图 Gray8 快照（与位图工艺处理相同的快照格式）。

### 4.2 后台执行（`VectorizeBitmapRoute::execute`）

逐图处理（[L417-L574](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L417-L574)）：

1. `Raster_CreateImageFromView` 创建单通道图（像素来自快照）。
2. **Step 1 轮廓提取**：`Raster_Vectorize(img, fitMethod, tolerance, &rawSet)`。库内部先做 **Otsu 阈值**（极性"暗 = 待加工"），再提取连通域轮廓；每条轮廓带 `isHole` 标记与有符号面积（[L436-L447](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L436-L447)）。
3. **Step 2 切割路径工艺**：`Raster_ApplyPathParams`，参数全部关闭/归一化（[L449-L472](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L449-L472)）：
   - 引入线/引出线：`NONE`，长度 0；
   - 微连接：数量 0、长度 0；
   - `normalizeDirection = 1`（统一绕向）；
   - `passes = 1`；`cornerRadius = 0`。
4. **Step 4 面积过滤与收集**：`Raster_ContourSetGetInfo` 取面积，`|area| < minArea` 丢弃；`pointCount < 2` 丢弃；保留 `isHole`（[L474-L504](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L474-L504)）。
5. **Step 5 可选割缝补偿**（`kerfMm != 0` 时，菜单路径不会触发）：
   - 像素点 → `RasterBridge::pixelToWorld` 转世界 mm；
   - `RasterBridge::applyKerfCompensation` → Engine2D `KerfCompensator`：`kerfWidth = 2 × |kerfMm|`，`side = kerfMm > 0 ? Outside : Inside`（**按符号统一决定内外，不使用 `isHole`**），`arcTolerance = 0.01`、`simplify = 0`（[KerfCompensatorBridge.h L100-L124](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/KerfCompensatorBridge.h#L100-L124)）；
   - 补偿后再 `worldToPixel` 转回像素，保持路由输出契约不变（[L506-L558](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/ProcessRouteRegistry.cpp#L506-L558)）。
6. 所有轮廓与 `isHole / isOpen / imageIndex` 写入结果；全部图片都没有轮廓 → `Vectorize produced no contour above min area`（错误）。

### 4.3 主线程落场景

1. `parseSnapshot` 解码源图信息；失败提示且**不添加任何轮廓**。
2. 逐条轮廓 `contourToPolygon`：
   - 纯像素坐标每 2 个数一组；
   - `RasterBridge::pixelToWorld` 映射为世界坐标（仿射：原点 + 两条边向量按宽高归一，[RasterImageSnapshot.h L91-L110](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Adapter/RasterImageSnapshot.h#L91-L110)）；
   - 生成闭合 `AprPolygon`（`bClosed = !isOpen`，本路由恒为 true）（[L276-L295](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Operation/RasterProcessOperation2D.cpp#L276-L295)）。
3. 任一轮廓的 `imageIndex` 越界，或任一轮廓转换失败 → 提示并**整批放弃**，一条都不加（全有或全无）。
4. 全部转换成功且非空 → `addEntities(..., "Vectorize Bitmap")`；默认提交模式可撤销，一次撤销移除整批矢量。
5. 轮廓为空 → 提示 `No contour was generated. Check threshold, minimum area or invert settings.`，不改场景。

## 5. 坐标、单位与精度

- 像素 → 世界：`world = origin + ux·px + uy·py`，其中 `ux/uy` 为源图两条边向量除以像素宽高；**隐含仿射假设**，不支持透视/独立第四角。
- `tolerance=1.0` 与 `minArea=10.0` 的单位都是**像素**（面积是平方像素）。
- 割缝补偿在世界 mm 空间进行（`kerfMm`），但菜单路径固定 0，因此实际输出即像素轮廓的直接映射。
- 输出不保留源图颜色/图层；`AprPolygon` 按当前图层规则落场景。

## 6. 失败、退化与边界行为

| 场景 | 行为 |
|---|---|
| 场景编辑器缺失 | 警告，直接返回 |
| 路由未注册 | 错误框 |
| 已有任务在跑 | 提示 `Another task is already running.` |
| 无选中且场景无图 | 提示 `No image entities in the scene.` |
| 快照构建失败 | 警告 `Could not collect snapshot: …`，不改场景 |
| 后台矢量化失败 | 整批 `Error`，`finished` 弹警告 |
| 全部轮廓小于 `minArea` | Route 返回错误 `Vectorize produced no contour above min area` |
| 某条轮廓 `imageIndex` 越界 | 主线程拒绝整批，`No contour was added.` |
| 某条轮廓世界坐标转换失败 | 同上，整批放弃 |
| 用户取消 | `Canceled`，不添加轮廓 |
| 源图为全白/全黑 | Otsu 可能给出空轮廓集 → 提示无轮廓，不改场景 |

## 9. 旧文档差异

- 旧文档称矢量化会弹参数对话框（阈值/最小面积/拟合方式可调）；当前菜单路径**没有对话框**，参数全部写死为 `Polygon / tolerance=1.0 / minArea=10.0 / kerf=0`。
- 旧文档称"需选中图片，否则不执行"；当前实现允许回退到场景全部图片。
- 旧文档把"无轮廓"当作静默结束；当前 Route 会返回错误并弹出提示。
- 旧文档称"割缝补偿默认开启"；当前默认 `kerfMm=0.0`，补偿关闭。
