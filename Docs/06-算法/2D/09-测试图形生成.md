## 4. 处理流程

### 4.1 生成（纯计算，无 Qt/场景依赖）

1. `std::mt19937_64 rng(randomSeed ? random_device{}() : seed)`（[L263](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/RandomShapeGenerator.cpp#L263)）。
2. 按固定权重抽取形状类型（总和 1.0，[L266-L277](file:///c:/Users/xx/Documents/Cpp/CAD/UI/Common/Src/Algorithm/RandomShapeGenerator.cpp#L266-L277)）：

| 类型 | 权重 | 生成方式 |
|---|---|---|
| Rectangle | 0.14 | 矩形 + 最大 12° 旋转 |
| RightTriangle | 0.10 | 直角边随机、斜边偏移 ±20% + 10° 旋转 |
| IrregularTriangle | 0.10 | 随机三点 + 3 mm 抖动 |
| ConvexPolygon | 0.14 | 5–8 边极坐标凸包 + 15° 旋转 |
| LShape | 0.08 | L 形 + 10° 旋转 |
| TShape | 0.07 | T 形 + 10° 旋转 |
| Cross | 0.06 | 十字形 + 12° 旋转 |
| Circle | 0.05 | 16 边扰动圆 + 25° 旋转 |
| Ellipse | 0.04 | 16 边扰动椭圆 + 30° 旋转 |
| ConcavePolygon | 0.22 | 3–20 边、若干顶点向内塌陷 + 15° 旋转 |

3. `scaleToArea(verts, targetArea)` 统一缩放到 8000 mm²（形状间面积一致，便于算法比较）。
4. 顶点数 <3 的退化结果直接丢弃（返回值可能 < count）。

### 4.2 摆放与写场景

1. 单元尺寸：`cellW = maxWidth + spacing = 105`，`cellH = maxHeight + spacing = 115`（[L30-L31](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/RandomShapeSceneBuilder.cpp#L30-L31)）。
2. 第 i 个图形：`row = i / columns`、`col = i % columns`，偏移 `col*105 + jitter`、`row*115 + jitter`（[L45-L48](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/RandomShapeSceneBuilder.cpp#L45-L48)）。
3. 每个图形平移后构造闭合 `AprPolygon`（`eType=POLYGON`、`bClosed=true`），`scene->addEntities` 写入（内部 clone，栈对象安全）。
4. 返回实际写入数量。

### 4.3 撤销

`runWithFullSceneUndo(..., "Generate Test Shapes")` 包装（[L834-L839](file:///c:/Users/xx/Documents/Cpp/CAD/UI/2D/Src/Algorithm/AlgorithmTaskRegistration2D.cpp#L834-L839)）：一次撤销清空本次生成的全部图元。

## 5. 输出形态

- 输出 100 个（默认）闭合 `AprPolygon`，按 10 列网格排列，带 ±25 mm 抖动。
- 图元无孔洞、无覆盖色，颜色/线宽按当前图层。
- 任务结果：`success = created > 0`；`message = "Generated N test shapes"`；`stats.createdCount = N`。

## 6. 失败与边界行为

| 场景 | 行为 |
|---|---|
| 场景管理器为空 | `success=false`，`message="Scene is not ready"` |
| 生成结果为空（退化过滤到 0） | `success=false`，`message="Generated 0 test shapes"` |
| 部分图形退化 | 静默丢弃，只写入有效图形，不报错 |
| 场景为空 | 正常执行（本功能允许空场景） |
| 图形与相邻单元重叠 | 可能发生：单元 105×115，但图形可达 80×90 且 jitter ±25，边界情形会越格；代码不做碰撞检查 |
| 生成器异常 | 无 try/catch，异常会向上冒泡到算法运行框架 |

## 9. 旧文档差异

- 旧文档称该菜单"弹参数对话框，可调数量/尺寸/种子"；当前实现**无对话框**，全部使用结构体默认值（100 个、8000 mm²、10 列、25 mm 间距与抖动）。
- 旧文档称"生成图形保证互不重叠"；当前网格步长小于最大图形尺寸 + 抖动幅度，边界情形会重叠，代码无重叠检测。
- 旧文档未记录"随机种子默认为 true、每次结果不同"，也未说明可通过 `seed + randomSeed=false` 复现（目前只能从代码/测试调用，菜单不可用）。
