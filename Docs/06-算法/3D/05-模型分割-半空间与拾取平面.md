# 模型分割：半空间与拾取平面

> 状态说明（2026-11-10）　状态：现行　维护：架构组

分割把单个实体一分为二：`Split Half X/Y/Z` 取包围盒中心平面，`By Picked Plane` 用视口点击处的三角形法线构造平面。两条路径最终都调用 `GmcSplit::splitByPlane`，用“平面片 + 半空间实体”与原始实体做一次求交、一次求差。

> **当前构建的接线状态（2026-11-08 修正）**：`ModelSplit3D::installPickHandler` 已在 `OperationSetup3D::initialize` 接线（`UI/3D/Src/Operation/OperationSetup3D.cpp`），视口拾取回调和取消回调都会挂到 `RenderWidget3D`；工作台 `deactivate` 时由 `ModelSplit3D::clearPickHandler` 解绑。点击 `By Picked Plane` 后进入拾取态，点击所选实体上的面即触发分割；Esc、右键、切换到其它命令（操作总线派发前钩子）都会退出拾取态。详见第 6 节。

## 4. 算法原理与分步流程

### 数据结构

- 输出 `GmcSplitResult`（[GmcSplit.h](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Include/GeoModelCore/GmcSplit.h#L24-L32)）：`success`、`errorMessage[256]`、`positiveSide`、`negativeSide`。
- 输入平面 `GmcSplitPlane`（[GmcSplit.h](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Include/GeoModelCore/GmcSplit.h#L34-L43)）：`origin` 在平面上，`normal` 指向 `positiveSide` 一侧。
- 轴枚举 `GmcSplitAxis`：`X`、`Y`、`Z`，注释明确“正侧 = 沿该轴正方向一侧”（[GmcSplit.h](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Include/GeoModelCore/GmcSplit.h#L13-L21)）。

### 坐标系与命名

- 右手系、Z 轴向上、mm。X 切分：正侧 `Split +X`、负侧 `Split -X`；Y 切分：`Split +Y` / `Split -Y`；Z 切分：`Split Top` / `Split Bottom`（[ModelOperations3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelOperations3D.cpp#L279-L298)）。
- 拾取平面：正侧 `Split +N`、负侧 `Split -N`，实体名按法向而非坐标轴（[ModelSplit3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelSplit3D.cpp#L358-L363)）。

### 半空间构造

`splitByPlane` 由 `buildHalfSpaceSolid`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L99-L158)）完成：

1. `margin = max(dx, dy, dz, 1.0) * 0.25 + 1.0`（`bboxExtent`，[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L63-L69)、L101）。
2. 把包围盒 8 个角点投影到平面局部坐标系的 U/V 方向，取 `[uMin - margin, uMax + margin] × [vMin - margin, vMax + margin]`。
3. `BRepBuilderAPI_MakeFace(plane, uMin, uMax, vMin, vMax)` 造平面片（L141）。
4. 参考点取平面原点沿法线平移 `±margin`：`positiveSide` 取 `+margin`，负侧取 `-margin`（L147-L150）。
5. `BRepPrimAPI_MakeHalfSpace(face, refPoint)` 造半空间实体（L152-L157）。

### 分步流程

1. `validateSplitInput`：空形状报 `null input shape`；`!isValid()` 报 `input shape failed validity check: ... (failed subshapes: N)`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L40-L61)）。
2. Half 路径取包围盒，`min/max` 中心作为平面位置；随后 `splitByAxisPlane` 生成 `origin` 在该轴坐标、`normal` 为该轴 +1 的平面（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L250-L270)）。
3. `splitByPlane` 再校验一次输入与包围盒，包围盒无效报 `shape bounding box is invalid`；法线长度小于 `1e-12` 报 `split plane normal is zero`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L222-L233)、L85-L97）。
4. 构造正半空间；失败（`MakeFace`/`MakeHalfSpace` 未完成）时报 `failed to build positive half-space`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L160-L166)）。
5. 正侧 = `GmcBoolean::common(shape, positiveHalfSpace)`，负侧 = `GmcBoolean::cut(shape, positiveHalfSpace)`；两次布尔各自完成 fuzzy 重试、同域合并与体积校验（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L168-L183)）。
6. 结果守卫：任一侧 `!isValid()` 报 `split produced invalid shape`；任一侧体积 `<= 1e-9` 报 `split plane does not divide the solid into two parts`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L71-L74)、L185-L194）。
7. 异常兜底：`std::exception` 原样取 `what()`，其它异常报 `split internal error`（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L235-L247)）。
8. 每一步都是两次完整布尔：正侧做 `common`、负侧做 `cut`，源码注释标明代价为 2× 全布尔，并列出 `BRepAlgoAPI_Splitter` 等潜在优化方向但当前未采用（[GmcSplit.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/GeoModelCore/GeoModelCore/Source/GmcSplit.cpp#L204-L211)）。

### 拾取平面的具体几何

- 命中信息来自 `RayHit3D`：`point` 为射线与三角形交点，`normal` 为三角形法线（`hit.normal = cross.normalized()`，[BVH3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/3D/Src/SpatialIndex/BVH3D.cpp#L213-L219)）。
- 法线长度小于 `1e-6f` 时回退 `(0, 0, 1)`，否则归一化（[ModelSplit3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelSplit3D.cpp#L336-L344)）。
- 平面原点直接用命中点，因此平面穿过被点击的表面位置；曲面上的“平面”是该点处的切平面近似，不是 B-Rep 面参数平面。

- 分割完成后 `setPickActive(false)` 关闭拾取态（L356）。

## 5. 输出形态与撤销

- 两个结果实体一次 `addEntities(results, 2)` 批量入场景（避免两次场景变更广播），随后分别 `attachBRep(positiveId, positiveSide)`、`attachBRep(negativeId, negativeSide)`（[ModelOperations3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelOperations3D.cpp#L328-L336)）。

- 撤销命令为 `BRepReplaceEntitiesCommand3D`，参数为“1 个操作数移除 + 2 个结果新增”，并同时携带操作数与两个结果的 B-Rep 快照（[ModelOperations3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelOperations3D.cpp#L338-L343)、[ModelSplit3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelSplit3D.cpp#L149-L169)）。

  - 重做：操作数再次离场并 `detachBRep`，两个结果回场并挂回各自 B-Rep。
  - 网格搬运由内层 `Eg::ReplaceEntitiesCommand3D` 负责，B-Rep 快照与网格共享同一 `shared_ptr`（[BRepReplaceEntitiesCommand3D.h](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Edit/BRepReplaceEntitiesCommand3D.h#L54-L64)）。

## 6. 限制与边界行为

- 选择数量：启用条件只要求 `>= 1`，实现要求 `== 1`。选中 2 个及以上时菜单可点，执行会失败并弹 `Split` 提示框。
- 无 B-Rep：Half 路径弹 `Select exactly one B-Rep solid to split.`；拾取路径弹专用提示 `The selected object has no B-Rep geometry. Create a solid or import STEP first.`
- 失败报错文本（原样）：`null input shape`、`input shape failed validity check: ... (failed subshapes: N)`、`shape bounding box is invalid`、`split plane normal is zero`、`failed to build positive half-space`、`positive side boolean failed: ...`、`negative side boolean failed: ...`、`split produced invalid shape`、`split plane does not divide the solid into two parts`（当任一侧体积 `<= 1e-9`）、`split internal error`。
- 平面与包围盒边界重合、切在实体外侧、平面只擦过实体一角时，至少一侧体积不足 `1e-9`，按“没有把实体分成两部分”失败，且**不产生任何实体**。
- 拾取平面精度：法线来自渲染三角形，曲面处得到的是切平面近似；平面位置是点击点，因此同一面两次点击会得到不同结果。
- 面回指缺失：`AprMeshEntity` 不保存 `faceIds`（[GmcMeshBridge3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Adapter/GmcMeshBridge3D.cpp#L29-L48)），拾取只能拿到三角形索引与三角形法线，无法直接映射到 B-Rep 面。
- 世界 B-Rep 对齐限制：`getWorldBRepForEntity` 只按包围盒中心平移，带旋转/缩放的实体分割位置会偏移；该限制对两条路径同样生效。
- `supportsMeshSurfacePick` 恒为 `true`（[RenderWidget3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Render/RenderWidget3D.cpp#L1075-L1078)），`beginPickPlaneOperation` 中“视口拾取未实现”的提示分支（`Picking a split plane in the viewport is not implemented yet.`）在当前代码下不可达。
- 拾取回调安装：`ModelSplit3D::installPickHandler`（[ModelSplit3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/ModelSplit3D.cpp#L235-L261)）由 `OperationSetup3D::initialize` 调用；`clearPickHandler` 在工作台 `deactivate` 中解绑并清空全局主窗口/总线指针，避免视口先于服务销毁时留下悬空捕获。`handleMeshSurfacePick` 在回调返回 `true` 后退出拾取态（[RenderWidget3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Render/RenderWidget3D.cpp#L1099-L1134)）；Esc、右键仍可取消（[RenderWidget3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Render/RenderWidget3D.cpp#L2772-L2790)、L3305-L3313）。
- 拾取态随命令切换退出：`OperationBus3D::run` 在派发前调用 `setPreDispatchHook` 注册的回调（[OperationBus3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/OperationBus3D.cpp#L103-L126)），`ModelSplit3D` 借此在用户点击任何其它命令时立即关闭拾取态，不会留下“永远在等一次点击”的状态。
