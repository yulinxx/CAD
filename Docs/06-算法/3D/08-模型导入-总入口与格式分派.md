# 模型导入 — 总入口与格式分派

> 状态说明（2026-11-10）　状态：现行　维护：架构组

本文描述 3D 工作台所有“导入”菜单项共用的总入口：菜单如何落到命令、命令如何分派到 STEP 与网格两条读取路径、实体如何入场景，以及导入过程中的撤销与失败回滚语义。各格式的解析细节见 [09-STEP装配导入.md](09-STEP装配导入.md) 与 [10-网格导入-OBJ与STL.md](10-网格导入-OBJ与STL.md)。

## 2. 调用链路

总入口是匿名命名空间里的 `importModel`（[FileOperations3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L387-L715)）。

```text
File_ImportModel  → importModel(ctx, replace=false, path)
File_ImportOBJ    → importModelWithFilter(ctx, false, path, "obj")  → importModel(..., stepOnly=false)
File_ImportSTL    → importModelWithFilter(ctx, false, path, "stl")  → importModel(..., stepOnly=false)
File_ImportSTEP   → importModelWithFilter(ctx, false, path, "step") → importModel(..., stepOnly=true)
File_Open         → importModel(ctx, replace=true, path, false, openFilter, [".sy3d", ".syx"])
File_OpenRecent   → importModel(ctx, replace=true, path)
```

`importModelWithFilter` 只负责“弹选择框 + 决定过滤器/标题”，随后把已选路径回传给 `importModel`，见 [L717-L796](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L717-L796)。`importModel` 内部的格式分派与读取：

```text
importModel
├─ SceneDocumentIO3D::cloneAllEntities          快照
├─ .sy3d / .syx  → SceneDocumentIO3D::loadScene  场景文档整替
├─ .step / .stp  → loadModelFile STEP 分支        B-Rep 装配读取
└─ .obj          → loadModelFile OBJ 分支         FileIO 解析 → IR
   └─ 其它扩展名 → loadModelFile STL 分支
```

`loadModelFile` 的 STEP 分支见 [L115-L216](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L115-L216)，OBJ/STL 分支见 [L227-L337](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L227-L337)。

## 3. 输入与参数

- 文件路径：命令可从 `req.params` 的 `filePath` 透传；为空才弹 `QFileDialog::getOpenFileName`（[L432-L477](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L432-L477)）。
- 起始目录取 `documentManager->currentFilePath()`，没有则空串。
- 过滤器构造：
  - 首选 `All Supported Files (*.stl *.obj *.sy3d *.syx)`；启用 `ENABLE_GEOMODELCORE` 时追加 `*.step *.stp`。
  - `customFilter`（仅 Open 语义）只给 `SanYi 3D Scene (*.sy3d *.syx)`。
  - `stepOnlyFilter` 在首选组之后追加 `STEP B-Rep (*.step *.STEP *.stp *.STP)`，标题为 `Open STEP Model` / `Import STEP Model`。
  - 默认组为 `3D Models (*.stl *.STL *.obj *.OBJ *.sy3d *.syx [*.step *.STEP *.stp *.STP])`，标题 `Open 3D Model`。
- 扩展名白名单只对 `allowedExtensions` 生效（Open 专用，[L483-L505](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L483-L505)），失败弹 `Open Error` / `Only 3D scene documents (*.sy3d *.syx) can be opened here.\nUse File ▸ Import for other 3D model formats.`
- 分派只看小写扩展名，不看对话框里用户选的过滤器（[L113-L116](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L113-L116)、[L230-L231](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L230-L231)）。
- 无单位选项、无三角化精度选项：STEP 固定由内核换算到毫米，OBJ/STL 不做单位换算。

## 4. 算法原理与分步流程

1. **重入守卫**：`static std::atomic<int> s_importDepth` 配合 `ImportDepthGuard` 自增/自减；`depth > 1` 只打印 `importModel re-entered!` 告警，不拒绝执行（[L394-L418](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L394-L418)）。
2. **上下文校验**：`mainWindow` / `sceneManager` / `renderWidget` 任一为空直接失败返回，不弹框。
3. **替换前确认**：`replaceScene` 为真时调用 `confirmDiscardModified`，走 `DocumentManager3D::promptSaveIfModified`；用户取消则静默返回 `false`（[L425-L428](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L425-L428)）。
4. **整场景快照**：`before = SceneDocumentIO3D::cloneAllEntities(ctx.sceneManager)`（[L430](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L430)）。快照用于失败回滚与撤销命令，语义见第 5 节。
5. **取得路径**：路径为空才弹框；弹框取消返回 `false`。
6. **白名单校验**：只对 Open 的 `.sy3d/.syx` 生效。
7. **判定替换范围**：`replaceWhole = replaceScene || isSceneDocument`（[L526-L528](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L526-L528)）。选 `.sy3d/.syx` 即使命令语义是追加，也按整文档替换处理。
8. **替换前置清理**：`replaceWhole` 时先 `undoRedoManager()->clear()`（[L530-L535](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L530-L535)），再 `brepService->clearEntityMap()`（[L538-L547](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L538-L547)）。前者避免旧命令持有将被 `clearScene` 释放的裸指针，后者避免新文档复用实体 id 时命中旧 B-Rep。
9. **分支读取**：
   - 场景文档：`replaceScene` 时先 `clearScene`，再 `SceneDocumentIO3D::loadScene`（其内部会整批替换）；失败调用 `restoreBeforeEntities` 恢复快照并弹 `Load Error`（[L549-L568](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L549-L568)）。
   - 网格/STEP：`replaceScene` 时先 `clearScene`；`loadModelFile` 返回零件数组；失败只在替换模式恢复快照，弹 `Load Error` / `Failed to load model:\n%1`（[L569-L599](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L569-L599)）。
10. **批量入场景**：先 `release()` 所有权、把 `EntityId` 提前取出，再一次性 `sceneManager->addEntities(partPtrs...)`，避免逐件触发 UI 全量刷新（[L601-L648](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L601-L648)）。
11. **B-Rep / partInfo 回挂**：场景入库后按队列逐件 `attachBRep`、`attachPartInfo`（[L650-L665](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L650-L665)）。网格导入没有 B-Rep，但 `partInfo` 队列仍有默认条目（`partIndex = -1`、单位矩阵）。
12. **文档状态**：替换语义 `setCurrentFilePath` + `setModified(false)` + `recordRecentFile`；追加语义 `setModified(true)`（[L677-L691](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L677-L691)）。
13. **撤销入栈**：`replaceWhole` 走 `pushSceneUndo`（`SceneReplaceCommand3D`），否则走 `pushReplaceUndo`（`ReplaceEntitiesCommand3D`）（[L693-L707](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L693-L707)）。
14. **收尾**：清选择、`markSceneDirty`、`fitAll`、刷新状态栏（[L709-L712](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L709-L712)）。

坐标与单位口径：STEP 分支的零件几何已在 `GmcAssemblyImpl` 内换算为毫米并应用装配位姿；OBJ/STL 按文件原值读入，不做缩放。渲染坐标系为右手系、Z 轴向上。`partInfo.transform` 只是位姿记录，任何渲染/加工都不得再次应用。

## 5. 输出形态与撤销

- **实体粒度**：STEP 每件一个 `Eg::AprMeshEntity`；OBJ/STL 无论文件内多少 `o/g/usemtl` 分段，都合并为一个实体（合并原因见 [L286-L292](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L286-L292)）。
- **B-Rep 回挂**：`brepQueue` 与 `partInfoQueue` 用 `release()` 之前抓到的 `EntityId` 作为键（[L616-L628](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L616-L628)）。`attachPartInfo` 会校验 `structSize == sizeof(GmcPartInfo)`，不匹配直接拒绝并告警（[BRepModelService3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Service/BRepModelService3D.cpp#L211-L226)）。
- **快照语义**：`cloneAllEntities` 对场景内每个实体调用 `cloneUnique()`（[SceneDocumentIO3D.cpp](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Storage/SceneDocumentIO3D.cpp#L53-L72)）。`AprMeshEntity` 拷贝构造会生成新 id（[AprMeshEntity.h](file:///c:/Users/xx/Documents/Cpp/CAD/Engine/3D/Include/Engine3D/AprEntity/AprMeshEntity.h#L174-L186)），因此快照只保留几何与显示属性，不保留原 id。
- **整场景替换撤销**：`pushSceneUndo` 把 `before` 快照与当前场景的 `after` 快照都 `release()` 成裸指针数组，交给 `SceneReplaceCommand3D`（[L339-L368](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L339-L368)）。撤销/重做时命令从对应快照克隆入场。
- **追加导入撤销**：`pushReplaceUndo` 用 `ReplaceEntitiesCommand3D(scene, nullptr, 0, added, n, "Import Model")`，`added` 已在场景中、命令只记 id（[L370-L385](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L370-L385)）。撤销即把新增实体摘出，重做放回。
- **清撤销栈时机**：在 `replaceWhole` 判定之后、实际读取之前清空（[L530-L535](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L530-L535)）。因此若随后的读取失败，快照虽能恢复场景，但历史已被清空。
- **保存点**：只有 `replaceScene == true` 才 `markSavePoint()`（[L698-L702](file:///c:/Users/xx/Documents/Cpp/CAD/UI/3D/Src/Operation/FileOperations3D.cpp#L698-L702)）。追加导入不建保存点，只把文档置脏。
- **B-Rep 与撤销的错位**：整场景撤销恢复的是新 id 的克隆，而 `entityBRep/entityPartInfo` 以旧 id 为键，且替换前已 `clearEntityMap`，所以 Open/New 撤销后 B-Rep 不会回来。追加导入撤销时映射未清理，重做再摘出后会短暂留下陈旧条目，直到下一次 `pruneStaleEntries`。
