# 2D 图元算法框架

本文描述 2D 图元算法的当前分层方式，重点是把基础几何、通用查询、图元专用和编辑类能力分开。

---

## 1. 为什么需要独立框架

2D 图元后续会持续增加命中、投影、离散、编辑、分析类算法。把这些算法分散到 UI 或图元类中，会带来重复实现、命名混乱和依赖循环。

---

## 2. 总体目标

### 2.1 算法独立于 UI

算法应属于几何/图元层，不依赖菜单、工具栏、视口或鼠标事件。

### 2.2 算法可复用

同一个算法应尽量被选择、编辑、偏移、打断、离散等能力复用。

### 2.3 分层组织

```text
基础数学层 (GeomMath)
→ 基础几何层 (Geo2DPrimitives)
→ 路径分解层 (Geo2DPath)
→ 曲线算法层 (BezierAlgorithms / SplineAlgorithms / CircleAlgorithms / LineAlgorithms)
→ 通用查询层 (Geo2DQuery / Geo2DAnalysis)
→ 编辑层 (Geo2DEdit)
→ 采样层 (Geo2DSampling)
→ 布尔运算层 (Geo2DBoolean)
→ 偏移运算层 (Geo2DOffset)
→ 并行批处理层 (Geo2DParallel)
→ 算法适配器层 (IGeometryAlgorithm)
```

---

## 3. 基础数学层

当前数值和基础向量运算已收口到 `Ut::GeomMath`，包括：

- 容差比较（`nearlyEqual`）
- clamp / lerp
- 角度转换（`DEG_TO_RAD`）
- 近似相等判断

---

## 4. 基础几何层 (Geo2DPrimitives)

**文件**: `Engine/2D/Include/Engine2D/Geometry/Geo2DPrimitives.h` (428行)

这一层只关心点、线、圆、弧、多边形、包围盒等基础几何对象，提供**无状态、纯函数、线程安全**的静态方法。

### 4.1 线段算法
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `segmentLength()` | 线段长度 | O(1) |
| `closestPointOnSegment()` | 点到线段最近点 | O(1) |
| `distancePointToSegment()` | 点到线段距离 | O(1) |
| `intersectSegmentSegment()` | 线段求交 | O(1) |
| `intersectLineLine()` | 直线求交 | O(1) |
| `segmentsCollinear()` | 共线判定 | O(1) |

### 4.2 圆/弧算法
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `intersectSegmentCircle()` | 线段×圆求交 | O(1) |
| `intersectCircleCircle()` | 圆×圆求交 | O(1) |
| `intersectSegmentArc()` | 线段×弧求交 | O(1) |
| `intersectArcArc()` | 弧×弧求交 | O(1) |
| `pointInDisk()` | 点在圆内判定 | O(1) |
| `closestPointOnArc()` | 弧上最近点 | O(1) |

### 4.3 椭圆算法
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `intersectSegmentEllipse()` | 线段×椭圆求交 | O(1) |
| `pointInEllipse()` | 点在椭圆内判定 | O(1) |
| `distancePointToEllipseBoundary()` | 点到椭圆边界距离 | O(1) |

### 4.4 多边形算法
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `signedArea()` | 鞋带公式有向面积 | O(n) |
| `perimeter()` | 周长 | O(n) |
| `getWinding()` | 绕向判定 | O(n) |
| `pointInPolygon()` | 射线法点内含判定 | O(n) |
| `isConvex()` | 凸性判定 | O(n) |
| `isSelfIntersecting()` | 自交检测 | O(n²) |
| `convexHull()` | 凸包（单调链） | O(n log n) |
| `minimumEnclosingCircle()` | 最小外接圆（Welzl） | O(n) |

## 6. 曲线算法层

### 6.1 贝塞尔算法 (BezierAlgorithms)
**文件**: `Engine/2D/Include/Engine2D/Geometry/BezierAlgorithms.h` (212行)

| 功能类别 | 方法 | 复杂度 |
|----------|------|--------|
| 分割 | `splitBezier()` (De Casteljau) | O(n) |
| 合并 | `mergeBeziers()` | O(n) |
| 包围盒 | `getBbox()` | O(n) |
| 极值 | `findExtrema()` | O(n) |
| 自适应离散 | `discretizeAdaptive()` | O(n·k), k=递归深度 |
| 固定段数离散 | `discretizeByCount()` | O(n) |
| 固定弧长离散 | `discretizeByLength()` | O(n·m), m=段数 |
| 弧长 | `length()` | O(n·k), 数值积分 |
| 弧长→参数 | `arcLengthToParam()` | O(n·k), 二分 |

### 6.2 样条算法 (SplineAlgorithms)
**文件**: `Engine/2D/Include/Engine2D/Geometry/SplineAlgorithms.h` (209行)

| 功能类别 | 方法 | 复杂度 |
|----------|------|--------|
| 基函数 | `basisFunction()` (De Boor-Cox) | O(p) |
| 求值 | `evaluate()` | O(p) |
| 自适应离散 | `discretizeAdaptive()` | O(n·k) |
| 导数 | `derivative()` | O(p) |
| 切线/法线 | `tangent()` / `normal()` | O(p) |
| 曲率 | `curvature()` | O(p) |
| 弧长 | `length()` | O(n·k) |
| 最近点 | `closestPoint()` | O(n·k) |

### 6.3 圆/弧离散 (CircleAlgorithms)

| 方法 | 功能 |
|------|------|

| `discretizeArc()` | 弧 → 点集 |
| `discretizeCircle()` | 圆 → 点集 |
| `discretizeEllipse()` | 椭圆 → 点集 |

### 6.4 线段算法 (LineAlgorithms)

| 方法 | 功能 | 复杂度 |
|------|------|--------|

| `segmentPolygonIntersection()` | 线段×多边形 | O(n) |

## 15. 当前维护原则

- 算法只放一处
- UI 不直接写几何逻辑
- 图元类保持轻量
- 新能力优先复用现有几何服务
- 所有公有 API 接受 `GeometryContext` 作为权威容差来源
- 公共方法无状态、纯函数、线程安全
