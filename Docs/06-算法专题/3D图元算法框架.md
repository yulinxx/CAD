# 3D 图元算法框架

本文描述 3D 网格算法的当前分层方式，目标是让拾取、测量、分析、采样和编辑能力保持同构和可收口。

---

## 1. 为什么需要独立框架

`SyMeshEntity` 后续会持续增加命中、测量、拓扑、采样、清理和编辑类算法。如果这些算法散落在 UI、命令类或加载器中，会和 2D 一样导致重复实现和依赖混乱。

---

## 2. 总体目标

### 2.1 算法独立于 UI

算法应位于 `Engine3D`，不依赖菜单、视口或 Qt 事件对象。

### 2.2 算法可复用

例如：
- 点到网格最近点可复用于拾取和测量
- 射线与三角形求交可复用于拾取和遮挡
- 顶点焊接可复用于清理和拓扑分析

### 2.3 分层组织

```text
容差上下文层 (GeometryContext3D)
→ 基础几何原语层 (Geo3DPrimitives)
→ 网格查询层 (Geo3DQuery)
→ 网格分析层 (Geo3DAnalysis)
→ 网格采样层 (Geo3DSampling)
→ 网格编辑层 (Geo3DEdit)
→ 算法门面层 (MeshAlgorithms)
→ 并行批处理层 (Geo3DParallel)
```

## 3. 容差上下文层 (GeometryContext3D)

**文件**: `Engine/3D/Include/Engine3D/Geo/GeometryContext3D.h` (84行)

统一的容差配置，是所有 3D 几何操作的**唯一容差来源**：

| 字段 | 默认值 | 用途 |
|------|--------|------|
| `dModeling` | `1e-6` | 点重合、共线、共面判定 |
| `dTopology` | `1e-5` | 顶点焊接、边去重、水密性检查 |
| `dDiscretize` | `1e-3` | 采样、网格逼近容差 |
| `dPick` | `1e-3` | 屏幕→世界拾取半径 |
| `dArea` | `1e-10` | 零面积/零体积检测 |

提供 `toTolerance()` / `fromTolerance()` 桥接旧版 `Geo3DTolerance`，全局单例 `defaultContext()` 作为默认值。

## 4. 基础几何原语层 (Geo3DPrimitives)

**文件**: `Engine/3D/Include/Engine3D/Geometry/Geo3DPrimitives.h` (135行)

无状态、纯函数、线程安全的静态方法，不依赖网格数据：

### 4.1 三角形算法
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `triangleArea()` | 三角形面积 | O(1) |
| `triangleNormal()` | 三角形法线 | O(1) |
| `signedTetrahedronVolume()` | 四面体有符号体积 | O(1) |
| `closestPointOnTriangle()` | 点到三角形最近点 | O(1) |
| `distancePointToTriangle()` | 点到三角形距离 | O(1) |
| `barycentricCoordinates()` | 重心坐标 | O(1) |
| `pointInTriangle()` | 点在三角形内判定 | O(1) |

### 4.2 射线求交
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `rayTriangle()` | 射线×三角形 (Moller-Trumbore) | O(1) |
| `rayPlane()` | 射线×平面 | O(1) |
| `raySphere()` | 射线×球 | O(1) |
| `segmentTriangle()` | 线段×三角形 | O(1) |
| `trianglesIntersect()` | 三角形×三角形 (边交叉+共面包含) | O(1) |

### 4.3 线段/直线
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `closestPointOnSegment()` | 线段上最近点 | O(1) |
| `distancePointToSegment()` | 点到线段距离 | O(1) |
| `distanceSegmentSegment()` | 线段间距离 (Ericson RTC) | O(1) |
| `projectPointToLine()` | 点投影到直线 | O(1) |

### 4.4 平面
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `planeFromPointNormal()` | 从点+法线构建平面 | O(1) |
| `planeFromTriangle()` | 从三角形构建平面 | O(1) |
| `distancePointToPlane()` | 点到平面距离 | O(1) |
| `projectPointToPlane()` | 点投影到平面 | O(1) |

### 4.5 包围盒 (AABB)

## 5. 网格查询层 (Geo3DQuery)

**文件**: `Engine/3D/Include/Engine3D/Geometry/Geo3DQuery.h` (191行)

无状态、线程安全的只读查询：

### 5.1 度量
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `measure()` | 综合度量（面积/体积/质心/包围盒） | O(n) |
| `surfaceArea()` | 表面积 | O(n) |
| `volume()` | 体积（需水密） | O(n) |
| `surfaceCentroid()` | 表面质心 | O(n) |

### 5.2 射线查询
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `raycastMesh()` | 射线×网格所有交点 | O(n) |
| `raycastMeshFirst()` | 射线×网格最近交点 | O(n) |
| `raycastMeshes()` | 射线×多网格所有交点 | O(m·n) |
| `raycastMeshesFirst()` | 射线×多网格最近交点 | O(m·n) |

**BVH 加速**: `SyMeshEntity::getBVH()` 提供延迟构建的 BVH 加速结构（`BVH3D`），射线查询可降至 O(log n)。

### 5.3 点查询
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `closestPointOnMesh()` | 网格上最近点 | O(n) |
| `distanceToPoint()` | 点到网格距离 | O(n) |
| `hitTest()` | 拾取测试 | O(n) |
| `pointInMesh()` | 点在网格内判定（射线奇偶） | O(n) |

### 5.4 空间关系
| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `bboxIntersects()` | 包围盒相交 | O(1) |
| `spatialRelationBBox()` | 与包围盒的空间关系 | O(1) |
| `bboxIntersectsMesh()` | 包围盒×网格相交 | O(n) |
| `meshIsWatertight()` | 水密性检查 | O(n) |

## 11. 加速结构

### 11.1 BVH (BVH3D)
**文件**: `Engine/3D/Include/Engine3D/SpatialIndex/BVH3D.h` (135行)

中值分割 BVH 构建，用于射线-三角形加速：

| 方法 | 功能 | 复杂度 |
|------|------|--------|
| `build()` | BVH 构建 | O(n log n) |
| `raycast()` | 最近命中射线查询 | O(log n) |
| `raycastAll()` | 所有命中射线查询 | O(log n + k) |
| `queryBBox()` | AABB 重叠查询 | O(log n + k) |

每个 `SyMeshEntity` 延迟构建并缓存自己的 BVH（`getBVH()`），generation 变化时失效。

### 11.2 R-Tree 空间索引 (SpatialIndex3D)
**文件**: `Engine/3D/Include/Engine3D/SpatialIndex/SpatialIndex3D.h` (201行)

基于 Boost.Geometry R-tree (`bgi::quadratic<16>`)，场景级实体空间索引：

| 方法 | 功能 |
|------|------|
| `insert()` / `remove()` / `update()` | 增删改 |
| `raycast()` | 射线查询（实体候选） |
| `raycastFirst()` | 首次命中 |
| `raycastHits()` / `raycastHitFirst()` | 精确三角形级 |
| `rangeQuery()` | 范围查询 |
| `pointQuery()` | 点查询 |

### 11.3 LOD 显示缓存 (DisplayCache3D)
**文件**: `Engine/3D/Include/Engine3D/Render/DisplayCache3D.h` (112行)

世界空间分块 + 距离级 LOD 管理，用于大场景渲染优化。

## 13. 当前维护原则

- 算法只放一处
- UI 不直接写几何逻辑
- 图元类保持轻量
- 新能力优先复用现有几何服务
- 所有公有 API 接受 `GeometryContext3D` 作为权威容差来源
- 公共方法无状态、纯函数、线程安全
