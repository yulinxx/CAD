# 三角剖分算法（PolygonTriangulator）

> 本文档描述 CAD 系统中多边形三角剖分算法的原理、实现细节与使用方式。
>
> 三角剖分是色块填充的核心步骤：将多边形区域分解为三角形集合，
> 供渲染引擎以三角面片方式绘制实心色块。

---

## 1. 算法概述

三角剖分的目标：将任意简单多边形（可能带孔洞）分解为互不重叠的三角形集合。

本模块采用的算法：

| 功能 | 算法 | 复杂度 |
|---|---|---|
| 点内含判定 | 射线法（Ray Casting） | O(n) |
| 有向面积计算 | 鞋带公式（Shoelace） | O(n) |
| 单连通多边形剖分 | 耳切法（Ear Clipping） | O(n²) |
| 带孔洞多边形剖分 | 桥接合并 + 耳切法 | O(n²) |

## 2. 模块接口

```cpp
class PolygonTriangulator {
public:
    // 三角形顶点索引三元组
    struct Tri {
        int a{ 0 };
        int b{ 0 };
        int c{ 0 };
    };

    // 射线法：点是否在多边形内（偶数-奇数规则）
    static bool pointInPolygon(const Vec2d& pt, const std::vector<Vec2d>& contour);

    // 有向面积（鞋带公式），正值=CCW，负值=CW
    static double signedArea(const std::vector<Vec2d>& contour);

    // 绕向判定
    static bool isCCW(const std::vector<Vec2d>& contour);
    static bool isCW(const std::vector<Vec2d>& contour);

    // 单连通多边形三角剖分
    static bool triangulateSimple(const std::vector<Vec2d>& contour, std::vector<Tri>& outTris);

    // 带孔洞多边形三角剖分
    static bool triangulate(const std::vector<Vec2d>& outer,
                            const std::vector<std::vector<Vec2d>>& holes,
                            std::vector<Tri>& outTris,
                            std::vector<Vec2d>& mergedVertices);

    // 便捷重载：输出扁平三角形顶点流
    static bool triangulateToSoup(const std::vector<Vec2d>& outer,
                                  const std::vector<std::vector<Vec2d>>& holes,
                                  std::vector<Vec2d>& outSoup);
};
```

## 3. 点内含判定（射线法）

### 3.1 原理

从待判定点向右发射水平射线，统计与多边形边的交点数：
- 奇数 → 点在内部
- 偶数 → 点在外部

### 3.2 实现

```cpp
bool pointInPolygon(const Vec2d& pt, const std::vector<Vec2d>& contour) {
    bool inside = false;
    for (size_t i = 0, j = n - 1; i < n; j = i++) {
        const Vec2d& a = contour[j];
        const Vec2d& b = contour[i];
        if ((a.y() > pt.y()) != (b.y() > pt.y())) {
            double xInt = a.x() + (pt.y() - a.y()) * (b.x() - a.x()) / (b.y() - a.y());
            if (pt.x() < xInt) {
                inside = !inside;
            }
        }
    }
    return inside;
}
```

### 3.3 注意事项

- 恰在边界上的点结果不定
- 水平边自然跳过（半开区间规则）

## 4. 有向面积计算（鞋带公式）

```cpp
double signedArea(const std::vector<Vec2d>& contour) {
    double area = 0.0;
    for (size_t i = 0; i < n; ++i) {
        const Vec2d& a = contour[i];
        const Vec2d& b = contour[(i + 1) % n];
        area += a.x() * b.y() - b.x() * a.y();
    }
    return 0.5 * area;
}
```

- 正值 → 逆时针（CCW）
- 负值 → 顺时针（CW）
- 零值 → 退化（面积为零）

## 5. 耳切法（Ear Clipping）

### 5.1 基本概念

- **耳（Ear）**：多边形的一个凸顶点，其与相邻顶点构成的三角形内部不含其他顶点
- **耳切**：移除耳顶点，记录三角形，重复直到剩余3个顶点

### 5.2 算法流程

```
输入：CCW 顶点环 pts
输出：三角形索引列表 outTris

1. 构建双向链表（next/prev）
2. 标记所有凹顶点（reflex）
3. while remaining > 3:
   a. 从 cursor 起扫描凸顶点
   b. 对每个凸顶点，测试耳三角形内是否不含其他凹顶点
   c. 如果找到耳：
      - 记录三角形 (prev, ear, next)
      - 摘除耳顶点
      - 更新相邻顶点凸性
   d. 如果找不到耳：
      - 退化多边形，终止
4. 剩余3顶点构成最后一个三角形
```

### 5.3 复杂度

- 最坏情况：O(n²)（每次扫描所有凹顶点）
- 平均情况：O(n log n)（随机多边形）

### 5.4 退化处理

- 面积过滤：移除面积 ≤ `kMinTriArea` 的三角形
- 防死循环：最大迭代次数 `3n² + 64`

## 6. 带孔洞多边形剖分

### 6.1 桥接合并（Eberly 变体）

将孔洞通过"桥接"合并到外轮廓，形成单连通顶点环：

```
1. 取孔洞最右顶点 M（x 最大）
2. 从 M 向右水平射线，求与当前环的最近交点 P
3. 双 P 桥接：
   P → M → 沿孔洞绕行一圈 → M → P
   形成零宽度走廊
4. 耳切沿走廊切出零面积三角形
5. 由 filterDegenerateTris 过滤退化三角形
```

### 6.2 处理流程

```
输入：外轮廓 outerCCW，孔洞列表 holesCW
输出：三角形索引列表 outTris，合并顶点表 mergedVertices

1. 输入清理与绕向归一
   - 去除重复点、共线中间点
   - 外轮廓统一为 CCW
   - 孔洞统一为 CW

2. 如果无孔洞：
   - 直接耳切

3. 如果有孔洞：
   - 对每个孔洞执行桥接合并
   - 清理合并后的环（保留共线点保护桥接缝）
   - 耳切

4. 过滤退化三角形
```

## 9. 使用示例

### 9.1 简单多边形

```cpp
std::vector<Vec2d> square = {{0,0}, {10,0}, {10,10}, {0,10}};
std::vector<PolygonTriangulator::Tri> tris;

PolygonTriangulator::triangulateSimple(square, tris);
// tris 包含2个三角形
```

### 9.2 带孔洞多边形

```cpp
std::vector<Vec2d> outer = {{0,0}, {20,0}, {20,20}, {0,20}};
std::vector<Vec2d> hole = {{5,5}, {15,5}, {15,15}, {5,15}};
std::vector<Vec2d> soup;

PolygonTriangulator::triangulateToSoup(outer, {hole}, soup);
// soup 包含环带区域的三角面片
```

### 9.3 点内含判定

```cpp
std::vector<Vec2d> contour = {{0,0}, {10,0}, {10,10}, {0,10}};
bool inside = PolygonTriangulator::pointInPolygon({5,5}, contour);  // true
bool outside = PolygonTriangulator::pointInPolygon({15,5}, contour); // false
```

## 12. 已知限制

- 耳切法在极度退化多边形（自交、共线）时可能失败
- 桥接合并可能产生零宽度走廊，需过滤退化三角形
- 不支持约束 Delaunay（保证三角形质量均匀）
