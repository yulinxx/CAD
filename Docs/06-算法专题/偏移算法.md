# 偏移算法（Offset/Geo2DOffset）

> 本文档描述 CAD 系统中 2D 路径偏移算法的核心实现、参数配置、调用流程与优化分析。
>
> 偏移（Offset）是 CAD 中的基础几何运算，用于将一条或多条轮廓按指定距离向内（内缩/Inset）
> 或向外（外扩/Outset）偏移，同时正确处理圆角、倒角、岛检测等复杂情况。

---

## 1. 一句话概括

使用 **Clipper2** 库对轮廓进行多边形膨胀/收缩，支持内缩和外扩两种模式，
通过 JoinType 控制拐角处理方式（方形/圆角/斜角），对外轮廓+孔洞结构进行整体偏移。

---

## 2. 核心类型与参数

### 2.1 偏移类型

```cpp
enum class Geo2DJoinType {
    Square,  // 方形连接：拐角处延伸形成方形
    Round,   // 圆角连接：拐角处用圆弧过渡
    Miter    // 斜角连接：拐角处沿角平分线延伸
};

enum class Geo2DOffsetType {
    Inset,   // 内缩：向轮廓内部偏移（缩小）
    Outset   // 外扩：向轮廓外部偏移（扩大）
};
```

### 2.2 偏移参数结构

```cpp
struct Geo2DOffsetParams {
    double dOffset = 10.0;          // 偏移距离（mm）
    bool bInset = false;            // true=内缩, false=外扩
    Geo2DJoinType eJoin = Geo2DJoinType::Round;
    double dMiterLimit = 2.0;       // 斜角限制（仅 Miter 有效）
    double dArcTolerance = 0.5;     // 圆弧逼近精度
};

struct Geo2DChamferParams {
    double dDistance = 5.0;         // 倒角距离
};

struct Geo2DTolerance {
    double dLinear = 1e-6;          // 线性容差
    double dAngular = 1e-6;         // 角度容差
};
```

## 3. 算法实现详解

### 3.1 单轮廓偏移

```cpp
std::vector<std::vector<Ut::Vec2d>> Geo2DOffset::offsetContour(
    const std::vector<Ut::Vec2d>& contour,
    const Geo2DOffsetParams& params,
    const Geo2DTolerance& tol)
{
    // 1. 参数校验
    if (contour.size() < 3 || params.dOffset <= 0.0) {
        return {};
    }

    // 2. 清理轮廓：去重顶点、合并接近点
    Clipper2Lib::PathD subjectPath = toClipperPathOffset(contour, tol);
    if (subjectPath.size() < 3) {
        return {};
    }

    // 3. 预处理：Union 操作统一结构
    Clipper2Lib::PathsD subjectPaths;
    subjectPaths.push_back(subjectPath);
    Clipper2Lib::ClipperD clipper(2);
    clipper.AddSubject(subjectPaths);
    Clipper2Lib::PathsD splitPaths;
    clipper.Execute(Clipper2Lib::ClipType::Union,
                    Clipper2Lib::FillRule::NonZero, splitPaths);
    if (splitPaths.empty()) {
        splitPaths.push_back(subjectPath);
    }

    // 4. 计算偏移方向
    double delta = params.dOffset;
    if (params.bInset) {
        delta = -delta;  // 内缩取负
    }

    // 5. 对每个子轮廓分别偏移
    Clipper2Lib::PathsD allSolution;
    for (const auto& path : splitPaths) {
        if (path.size() < 3) continue;

        Clipper2Lib::PathsD single;
        single.push_back(path);
        Clipper2Lib::PathsD solution = Clipper2Lib::InflatePaths(single,
            delta,
            toClipperJoin(params.eJoin),           // JoinType
            Clipper2Lib::EndType::Polygon,         // 闭合多边形
            params.dMiterLimit,
            2,
            params.dArcTolerance);

        for (const auto& s : solution) {
            allSolution.push_back(s);
        }
    }

    // 6. 外扩时合并重叠部分
    if (!params.bInset && allSolution.size() > 1) {
        Clipper2Lib::ClipperD unionClipper(2);
        unionClipper.AddSubject(allSolution);
        Clipper2Lib::PathsD merged;
        unionClipper.Execute(Clipper2Lib::ClipType::Union,
                            Clipper2Lib::FillRule::NonZero, merged);
        allSolution = merged;
    }

    // 7. 转换回 Vec2d 格式
    std::vector<std::vector<Ut::Vec2d>> result;
    for (const auto& path : allSolution) {
        if (path.size() < 3) continue;
        std::vector<Ut::Vec2d> out;
        for (const auto& p : path) {
            out.emplace_back(p.x, p.y);
        }
        result.push_back(std::move(out));
    }
    return result;
}
```

### 3.2 多轮廓偏移（带岛检测）

```cpp
std::vector<std::vector<Ut::Vec2d>> Geo2DOffset::offsetContours(
    const std::vector<std::vector<Ut::Vec2d>>& contours,
    const Geo2DOffsetParams& params,
    const Geo2DTolerance& tol)
{
    if (contours.empty() || params.dOffset <= 0.0) {
        return {};
    }

    // 1. 归一化轮廓结构：以 EvenOdd 规则对所有轮廓求并
    //    既能消融重叠区域，又能把"外轮廓 + 孔洞"整理成正确的嵌套结构
    const auto structure = Geo2DBoolean::uniteContours(
        contours, EFillRule::EvenOdd, ctx);
    if (structure.empty()) {
        return {};
    }

    // 2. 转换为 Clipper 格式
    Clipper2Lib::PathsD subjectPaths;
    for (const auto& c : structure) {
        auto p = toClipperPathOffset(c, tol);
        if (p.size() >= 3) {
            subjectPaths.push_back(std::move(p));
        }
    }
    if (subjectPaths.empty()) {
        return {};
    }

    // 3. 整体偏移（保留孔洞）
    double delta = params.dOffset;
    if (params.bInset) {
        delta = -delta;
    }

    Clipper2Lib::PathsD solution = Clipper2Lib::InflatePaths(subjectPaths,
        delta,
        toClipperJoin(params.eJoin),
        Clipper2Lib::EndType::Polygon,
        params.dMiterLimit,
        2,
        params.dArcTolerance);

    // 4. 转换结果
    std::vector<std::vector<Ut::Vec2d>> result;
    for (const auto& path : solution) {
        if (path.size() < 3) continue;
        std::vector<Ut::Vec2d> out;
        for (const auto& p : path) {
            out.emplace_back(p.x, p.y);
        }
        result.push_back(std::move(out));
    }
    return result;
}
```

### 3.3 圆角处理（Fillet）

```cpp
bool Geo2DOffset::filletCorner(
    const Ut::Vec2d& prev,      // 前一个顶点
    const Ut::Vec2d& corner,   // 拐角顶点
    const Ut::Vec2d& next,     // 后一个顶点
    double radius,             // 圆角半径
    Ut::Vec2d& outTan1,       // 输出：第一个切点
    Ut::Vec2d& outTan2,       // 输出：第二个切点
    Ut::Vec2d& outCenter,     // 输出：圆心
    const Geo2DTolerance& tol)
{
    if (radius <= tol.dLinear) return false;

    // 1. 计算两边的单位向量
    Ut::Vec2d u1 = prev - corner;
    Ut::Vec2d u2 = next - corner;
    double len1 = u1.length();
    double len2 = u2.length();
    if (len1 <= tol.dLinear || len2 <= tol.dLinear) return false;

    u1 /= len1;
    u2 /= len2;

    // 2. 计算夹角
    double cosAngle = u1.dot(u2);
    cosAngle = std::clamp(cosAngle, -1.0, 1.0);
    double halfAngle = std::acos(cosAngle) * 0.5;
    if (halfAngle < tol.dAngular || halfAngle > M_PI * 0.5 - tol.dAngular) {
        return false;
    }

    // 3. 计算切点距离 d = R * cot(halfAngle)
    double d = radius * std::cos(halfAngle) / std::sin(halfAngle);
    // 限制不超过边长的 1/2
    double maxD = std::min(len1, len2) * 0.5;
    if (d > maxD) {
        d = maxD;
    }

    // 4. 计算切点
    outTan1 = corner + u1 * d;
    outTan2 = corner + u2 * d;

    // 5. 计算圆心（在角平分线上）
    Ut::Vec2d bisector = u1 + u2;
    double bisLen = bisector.length();
    if (bisLen <= tol.dLinear) return false;
    bisector /= bisLen;
    double centerDist = radius / std::sin(halfAngle);
    outCenter = corner + bisector * centerDist;

    return true;
}
```

### 3.4 倒角处理（Chamfer）

```cpp
std::vector<Ut::Vec2d> Geo2DOffset::chamferCorner(
    const Ut::Vec2d& prev,
    const Ut::Vec2d& corner,
    const Ut::Vec2d& next,
    const Geo2DChamferParams& params,
    const Geo2DTolerance& tol)
{
    std::vector<Ut::Vec2d> result;

    if (params.dDistance <= tol.dLinear) {
        result.push_back(corner);
        return result;
    }

    const Ut::Vec2d v1 = corner - prev;
    const Ut::Vec2d v2 = next - corner;
    const double len1 = v1.length();
    const double len2 = v2.length();
    if (len1 <= tol.dLinear || len2 <= tol.dLinear) {
        result.push_back(corner);
        return result;
    }

    // 限制距离不超过边长的 1/2
    const double d = std::min(params.dDistance, std::min(len1, len2) * 0.5);

    // 计算倒角点
    const Ut::Vec2d p1 = corner - v1 * (d / len1);
    const Ut::Vec2d p2 = corner + v2 * (d / len2);
    result.push_back(p1);
    result.push_back(p2);

    return result;
}
```

## 4. 依赖库：Clipper2

### 4.1 Clipper2 简介

[Clipper2](https://github.com/AngusJohnson/Clipper2) 是一个高性能的 2D 多边形裁剪库，
支持：
- 并集（Union）、交集（Intersection）、差集（Difference）、异或（Xor）
- 多边形膨胀/收缩（Inflate/Deflate）
- 多种连接方式（Square、Round、Miter）
- 多种填充规则（NonZero、EvenOdd、Positive、Negative）

### 4.2 核心函数

```cpp
// 多边形膨胀/收缩
PathsD InflatePaths(
    const PathsD& paths,        // 输入路径
    double delta,               // 偏移距离（正=外扩，负=内缩）
    JoinType joinType,          // 连接方式
    EndType endType,           // 端点类型
    double miterLimit = 2.0,   // 斜角限制
    int precision = 2,          // 精度（2 = 0.01）
    double arcTolerance = 0.0   // 圆弧逼近容差
);
```

### 4.3 关键参数说明

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `delta` | 偏移距离 | 根据实际需求 |
| `joinType` | 拐角处理方式 | Round（圆角效果最好） |
| `endType` | 端点类型 | Polygon（闭合多边形） |
| `miterLimit` | 斜角限制 | 2.0（防止尖角过长） |
| `precision` | 计算精度 | 2（0.01 精度） |
| `arcTolerance` | 圆弧容差 | 0.5（圆角过渡精度） |

## 5. 调用链路

### 5.1 单轮廓偏移

```
用户操作（菜单/命令）
  │
  ▼ OffsetCommand
  ▼ OptionBus → OffsetTaskHandler
  │
  └─ Geo2DOffset::offsetContour(contour, params, tol)
        ├─ toClipperPathOffset()     // 清理轮廓
        ├─ Union 预处理              // 统一结构
        ├─ Clipper2Lib::InflatePaths // 核心偏移
        └─ 转换结果
```

### 5.2 图元偏移

```cpp
std::vector<std::unique_ptr<SyPolygon>> Geo2DOffset::offsetEntity(
    const SyEntity* entity,
    const Geo2DOffsetParams& params,
    const Geo2DTolerance& tol)
{
    // 1. 图元 → 轮廓集合
    const auto contours = Geo2DBoolean::entityToContours(entity, ctx);

    // 2. 对每条轮廓偏移
    std::vector<std::unique_ptr<SyPolygon>> result;
    for (const auto& c : contours) {
        const auto offset = offsetContour(c, params, ctx);
        for (const auto& out : offset) {
            // 3. 轮廓 → 多边形图元
            auto poly = Geo2DBoolean::contourToPolygon(out);
            if (poly) {
                result.push_back(std::move(poly));
            }
        }
    }
    return result;
}
```

## 6. 复杂度分析

设输入轮廓顶点数为 N：

| 步骤 | 时间复杂度 | 说明 |
|------|------------|------|
| 轮廓清理 | O(N log N) | 排序去重 |
| Union 预处理 | O(N log N) | Clipper2 内部实现 |
| 偏移计算 | O(N) | Clipper2 线性扫描 |
| 结果合并 | O(M log M) | M = 结果轮廓数 |
| 格式转换 | O(M) | 结果遍历 |

**总时间复杂度**：O(N log N)

## 7. 优化分析

### 7.1 已实现的优化

- ✅ **Clipper2 高性能**：使用成熟的 Clipper2 库，底层经过高度优化
- ✅ **轮廓预处理**：Union 操作统一结构，消融重叠区域
- ✅ **批量偏移**：`offsetContours` 支持多轮廓整体偏移，保留岛结构

### 7.2 潜在优化空间

1. **增量偏移**：对连续多次偏移，可缓存中间结果
2. **GPU 加速**：Clipper2 主要是 CPU 密集型，可考虑 GPU 实现
3. **空间索引**：对大量小轮廓使用 R-Tree 加速空间查询
4. **并行化**：对独立轮廓可并行处理

### 7.3 已知不足与限制

1. **极端偏移**：偏移距离过大时可能导致轮廓坍缩为空
2. **自交轮廓**：对自交轮廓的处理可能产生意外结果
3. **数值精度**：极端情况下可能出现浮点精度问题
4. **圆角质量**：圆角使用圆弧逼近，精度依赖 `arcTolerance` 参数

### 7.4 圆角 vs 倒角选择

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 机械零件 | 倒角 | 更精确，易于加工 |
| 艺术设计 | 圆角 | 更美观，过渡自然 |
| 激光加工 | 圆角 | 减少尖角能量集中 |
| 数控加工 | 倒角 | 刀具路径更简单 |
