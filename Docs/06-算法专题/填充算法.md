# 填充算法（Hatch/Fill）

> 本文档描述 CAD 系统中填充（Fill/Hatch）算法的完整实现，包括线填充（Hatch Fill）和色块填充（Color Fill）两大类。
>
> 填充是 CAD/CAM 系统中的核心功能，用于在闭合轮廓内生成填充线或实心区域。线填充常用于激光雕刻，色块填充常用于可视化渲染。

---

## 1. 填充算法体系概览

```
填充算法
  │
  ├─ 线填充（EntityFiller / EntityFill）
  │    ├─ 扫描线填充（ScanlineFill）
  │    │    ├─ L2R（从左到右）
  │    │    ├─ R2L（从右到左）
  │    │    ├─ Bi（双向交替）
  │    │    └─ 扫描方向：B2T / T2B
  │    │
  │    └─ 弓形填充（BowFill）
  │         └─ 连续折返路径（激光雕刻优化）
  │
  └─ 色块填充（EntityColorFiller）
       └─ 三角剖分实心区域
```

## 2. 线填充算法（Scanline Fill）

### 2.1 一句话概括

把**所有选中图元**的轮廓合成一个统一的边集合，按填充角度反向旋转使扫描线水平，逐行做扫描线求交、按奇偶规则配对成填充段，再正向旋转回去，最后作为一批 `SyLine` 写入场景。

### 2.2 核心参数

```cpp
struct FillParameters {
    double dSpacing{ 1.0 };                    // 填充间距（mm）
    double dAngle{ 0.0 };                      // 填充角度（度）
    FillType fillType{ FillType::L2R };         // 填充类型
    FillDirection fillDirection{ FillDirection::B2T }; // 扫描方向
    unsigned int nPrecision{ 1000 };             // 定点精度
    double dMargin{ 0.0 };                      // 边距（未实现）
    bool bCrossFill{ false };                   // 交叉填充
};

enum class FillType { L2R, R2L, Bi, Bow };
enum class FillDirection { B2T, T2B };
```

### 2.3 算法流程

```cpp
bool EntityFiller::computeFill(
    const std::vector<SyEntity*>& entities,
    const FillParameters& params,
    std::vector<std::vector<Ut::Vec2d>>& outHatchLines)
{
    // 1. 离散化：将所有选中图元转换为轮廓点序列
    EntityDiscretizer discretizer;
    std::vector<Ut::Vec2dVector> vOutLinePts;
    int nCount = discretizer.doDiscretize(entities, vOutLinePts);

    // 2. 填充计算
    VecLines vOutlines = ...;  // 转换为轮廓格式

    EntityFill entityFillAlgo;
    entityFillAlgo.setOutlines(vOutlines);
    entityFillAlgo.setParameters(params);
    entityFillAlgo.doFill();

    VecLines* vResult = entityFillAlgo.getFillLines();

    // 3. 交叉填充（如需要）
    if (params.bCrossFill) {
        FillParameters crossParams = params;
        crossParams.dAngle += 90.0;
        // 再跑一遍...
    }

    return !outHatchLines.empty();
}
```

### 2.4 填充类型详解

#### 2.4.1 L2R（从左到右）

```
─────────────→
─────────────→
─────────────→
```

每行独立生成填充线，方向一致。

#### 2.4.2 R2L（从右到左）

```
←─────────────
←─────────────
←─────────────
```

每行独立生成填充线，方向一致。

#### 2.4.3 Bi（双向交替）

```
─────────────→
←─────────────
─────────────→
```

每行方向交替，减少空程距离。

#### 2.4.4 Bow（弓形填充）

```
─────────────→
              │
←─────────────
              │
─────────────→
```

行间用连接段串起来，**整条路径不断笔**，适合激光连续雕刻。

### 2.5 扫描线算法核心

```cpp
void ScanlineFill::doFillByScanLine(
    int nY,
    const VecEdges& edges,
    const FillData& data,
    const FillGroup& group,
    ScaledSegmentList& outSegments)
{
    // 1. 收集交点
    IntersectionList vX;
    collectIntersections(nY, edges, vX);
    sortAndDedupeIntersections(vX);

    // 2. 配对并校验
    pairIntersections(vX, data, group, dTestY, outSegments);
}
```

#### 2.5.1 交点收集（collectIntersections）

```cpp
void collectIntersections(int nY, const VecEdges& edges, IntersectionList& out) {
    const double dScanY = static_cast<double>(nY) + kSampleOffset; // 0.5偏移

    for (FillEdge* pE : edges) {
        // 普通边：计算与扫描线的交点X
        if (edgeCrossesScanY(dScanY, yMin, yMax)) {
            double dX = pE->ptStart.x() + pE->dDelta * (dScanY - pE->ptStart.y());
            out.emplace_back(dX, pE);
        }

        // 水平边：加入两端点
        if (pE->eType == FillEdge::Type::Horizontal) {
            out.emplace_back(xLo, pE);
            out.emplace_back(xHi, pE);
        }
    }
}
```

关键设计：
- **采样偏移**：`kSampleOffset = 0.5`，避免顶点正好落在扫描线上的退化情况
- **半开区间**：使用 `(yMin, yMax]` 判断跨越，保证共享顶点的两条边只贡献一个交点

#### 2.5.2 交点配对（pairIntersections）

不是简单的"1-2、3-4 配对"，而是带校验的两级策略：

```cpp
void pairIntersections(const IntersectionList& vX, ...) {
    // 策略1：先试相邻配对
    for (size_t i = 0; i < vX.size();) {
        if (i + 1 < vX.size()) {
            const double x0 = vX[i].first;
            const double x1 = vX[i + 1].first;
            if (segmentInside(x0, x1)) {  // 校验段是否在内部
                outSegments.emplace_back(x0, x1);
                i += 2;
                continue;
            }
        }

        // 策略2：回退搜索，找跨度最短且校验通过的
        size_t bestJ = findBestPair(vX, i);
        if (bestJ != vX.size()) {
            outSegments.emplace_back(vX[i].first, vX[bestJ].first);
            i = bestJ + 1;
        }
    }
}
```

#### 2.5.3 内外判定（isPointInsideGroup）

经典射线奇偶算法：

```cpp
bool isPointInsideGroup(const FillData& data, double dX, double dY, const FillGroup& group) {
    int nCrossCount = 0;

    for (size_t nEnt : group) {
        for (FillEdge* pEdge : data.getEntityEdgeAt(nEnt)) {
            // 统一成 y1 < y2 的方向
            if (y1 > y2) { swap(x1, x2); swap(y1, y2); }

            // 半开区间过滤
            if (dY <= y1 + EPSILON || dY > y2 + EPSILON) continue;

            // 计算交点X
            const double t = (dY - y1) / (y2 - y1);
            const double xIntersect = x1 + t * (x2 - x1);

            // 向右计数
            if (xIntersect >= dX - EPSILON) ++nCrossCount;
        }
    }

    return (nCrossCount % 2) == 1;
}
```

### 2.6 填充分组（Fill Groups）

这是算法的核心设计点：**必须整体处理**。

```cpp
void buildFillGroups(const FillData& data, FillGroupList& outGroups) {
    // 1. 对每个图元边集算 BBox
    std::vector<EntityBBox> vBoxes(nEnt);
    for (size_t i = 0; i < nEnt; ++i) {
        vBoxes[i] = computeEntityBBox(data.getEntityEdgeAt(i));
    }

    // 2. 用并查集求连通分量（BBox 重叠 → 同组）
    for (size_t i = 0; i < nEnt; ++i) {
        for (size_t j = i + 1; j < nEnt; ++j) {
            if (bboxesOverlap(vBoxes[i], vBoxes[j])) {
                union(i, j);  // 并查集
            }
        }
    }

    // 3. 按连通分量分组
    outGroups = groupsByRoot;
}
```

**分组语义**：
- **外轮廓 + 孔洞**：BBox 包含 → 重叠 → 同组 → 孔洞不填充
- **两个相交轮廓**：同组 → 相交部分挖空
- **完全分离的轮廓**：不同组 → 互不干扰

## 3. 色块填充算法（Color Fill）

### 3.1 一句话概括

将闭合轮廓分割为三角形网格，生成实心填充区域，常用于渲染可视化。

### 3.2 实现方式

```cpp
class EntityColorFiller {
public:
    int fillEntities(const std::vector<SyEntity*>& entities, const FillParameters& params);

private:
    bool computeColorFill(...);  // 内部调用三角剖分
};
```

色块填充基于三角剖分算法，将多边形分割为三角形，实现实心区域填充。详细算法见 `三角剖分算法.md`。

## 4. 定点数优化

整个算法在**定点整数域**上工作，避免浮点累加误差：

```cpp
// 参数归一
m_nStep = max(1, lround(params.dSpacing * nPrecision));  // 间距 → 定点步长
m_params.dAngle = DEG_TO_RAD(params.dAngle);            // 度 → 弧度

// 边构建
x = lround(x * nPrecision);  // 定点化
y = lround(y * nPrecision);

// 扫描线 Y 坐标用 int 递增
for (int nY = startY; nY != endY; nY += stepDir) { ... }
```

## 6. 性能优化

### 6.1 已实现的优化

1. **批量写回**：填充线一次性提交到场景，避免 N 次撤销命令
2. **定点数运算**：避免浮点累加误差，提升性能
3. **填充分组**：BBox 重叠检测 + 并查集，减少无效计算

### 6.2 潜在优化空间

1. **哈希桶加速**：扫描线路径也可接入哈希桶（目前只有 Bow 用）
2. **活性边表（AET）**：沿 Y 增量维护边集合，把 O(R×E) 降到 O(E log E + 交点数)
3. **并行扫描行**：按扫描行并行，各行结果独立
4. **采样复核优化**：`isSegmentInsideGroup` 可先用一次奇偶快速判定

---

## 7. 已知限制

1. **dMargin 未实现**：`FillParameters::dMargin` 是惰性参数，无效果
2. **BBox 分组局限**：凹形轮廓的 BBox 可能误重叠
3. **自交轮廓**：不支持自交轮廓的正确处理
4. **交叉填充**：完整跑两遍，线段数与耗时翻倍
