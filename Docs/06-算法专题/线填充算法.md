# 线填充算法（Fill2D）

> 本文档描述 CAD 系统中线填充（Hatch Fill）算法的原理、模块划分、参数配置与实现细节。
>
> 线填充是激光雕刻中最常用的填充方式：在闭合轮廓内按指定间距、角度生成平行扫描线，
> 激光沿这些扫描线运动完成区域填充。

---

## 1. 算法概述

线填充的基本思路：

1. **离散化**：将选中的图元（线、圆、弧、多边形等）转换为闭合多段线轮廓
2. **旋转**：将轮廓按填充角度旋转，使扫描线水平
3. **扫描线求交**：用水平扫描线与轮廓边求交，得到交点序列
4. **配对**：将交点按 X 坐标排序配对，确定填充段
5. **内外判定**：验证填充段是否在轮廓内部
6. **反旋转**：将填充线旋转回原始角度
7. **输出**：生成 `SyLine` 实体写入场景

## 2. 模块划分

| 模块 | 文件 | 职责 |
|---|---|---|
| 参数 | `FillParameters.h` | 间距、角度、填充类型、扫描方向、边距、交叉填充开关 |
| 数据结构 | `FillDataDefine.h` | 填充边线 `FillEdge`、扫描线 `ScanLine`、边线点 `EdgePoint`、类型枚举 |
| 核心算法 | `EntityFill.h/cpp` | 边缘构建、哈希桶、扫描线求交、填充计算 |
| 弓形填充 | `PolygonFill/BowFill.h/cpp` | 行间连续折返路径（弓形/Boustrophedon） |
| 扫描线填充 | `PolygonFill/ScanlineFill.h/cpp` | L2R/R2L/Bi 模式，独立扫描线段 |
| 服务层 | `EntityFiller.h/cpp` | 离散化、填充计算、写入场景、交叉填充 |

## 3. 填充类型（FillType）

```cpp
enum class FillType {
    L2R,  // Left to Right：每条扫描线从左到右，线段独立
    Bow,  // Bow/Boustrophedon：行间连续折返，路径不断开
    R2L,  // Right to Left：每条扫描线从右到左，线段独立
    Bi    // Bidirectional：行间方向交替，但每条扫描线单独成段
};
```

### 3.1 L2R（左到右）

```
─────────────→
─────────────→
─────────────→
```

每条扫描线独立从左到右绘制，行间无连接。

### 3.2 Bow（弓形/牛耕式）

```
─────────────→
←─────────────
─────────────→
```

行间连续折返，路径不断开，适合激光连续雕刻。

### 3.3 R2L（右到左）

```
←─────────────
←─────────────
←─────────────
```

每条扫描线独立从右到左绘制。

### 3.4 Bi（双向交替）

```
─────────────→
←─────────────
─────────────→
```

行间方向交替，但每条扫描线独立成段。

```cpp
};
```

## 5. 参数结构体

```cpp
struct FillParameters {
    double dSpacing{ 1.0 };            // 填充间距（mm）
    double dAngle{ 0.0 };             // 填充角度（度）
    FillType fillType{ FillType::L2R };           // 填充类型
    FillDirection fillDirection{ FillDirection::B2T }; // 扫描方向
    unsigned int nPrecision{ 1000 };   // 坐标精度
    double dMargin{ 0.0 };            // 边距（mm）
    bool bCrossFill{ false };          // 是否启用交叉填充

    bool isValid() const {
        return dSpacing > 0 && nPrecision > 0 && dMargin >= 0;
    }
};
```

## 6. 处理流程

```
用户选择图元 → 弹出 FillDialog 配置参数
  │
  ▼ EntityFiller::fillEntities()
  │
  ├─ 1. EntityDiscretizer::doDiscretize()
  │     将图元转换为闭合多段线轮廓 (VecLines)
  │
  ├─ 2. 旋转轮廓 (dAngle → 水平)
  │
  ├─ 3. EntityFill::doFill()
  │     ├─ initAllEdge()         // 构建填充边线
  │     ├─ sortEdge()            // 按 Y 坐标排序
  │     ├─ initHashTable()       // 建立哈希桶加速
  │     └─ doFillAlgo()
  │         ├─ BowFill::fillByEdge()      // 弓形填充
  │         └─ ScanlineFill 相关函数       // L2R/R2L/Bi 填充
  │
  ├─ 4. 反旋转填充线
  │
  ├─ 5. 边距裁剪 (dMargin)
  │
  ├─ 6. 交叉填充 (bCrossFill)
  │     如果启用，以 angle+90° 再执行一次填充
  │
  └─ 7. writeHatchLinesToScene()
        生成 SyLine 实体写入场景
```

## 7. 关键算法细节

### 7.1 边缘构建（initAllEdge）

将离散化后的多段线转换为 `FillEdge` 结构：
- 记录起点、终点
- 计算斜率倒数 `dDelta`（用于快速求 X 值）
- 标记水平线、垂直线
- 过滤退化边

### 7.2 哈希桶加速（initHashTable）

将边线按 Y 坐标范围插入哈希桶，加速扫描线求交：
- 桶大小与填充间距对齐
- 查询时只需检查当前桶及相邻桶

### 7.3 扫描线求交（ScanlineFill::collectIntersections）

对每条扫描线 Y：
- 收集与该 Y 相交的所有边
- 计算交点 X 坐标
- 排序去重

### 7.4 配对与内外判定（pairIntersections）

交点配对规则：
- 按 X 坐标排序
- 奇偶配对（第1-2、3-4...为填充段）
- 验证中点是否在轮廓内（处理退化情况）

### 7.5 弓形填充（BowFill）

弓形填充的特殊处理：
- 行间保持路径连续
- 在行末通过垂直段连接下一行
- 处理桥接点（insertPoint）
- 支持跨边连接

---

## 8. 交叉填充

当 `bCrossFill = true` 时：
1. 以原始角度执行一次填充
2. 以 angle + 90° 再执行一次填充
3. 合并两次填充结果

适用于需要网格状填充的场景。

## 11. 已知限制

- 仅支持凸/凹多边形轮廓，不支持自交轮廓
- 弓形填充在极端退化情况下可能产生断点
- 交叉填充会生成双倍线段数量
