# 色块填充算法（FillColor2D）

> 本文档描述 CAD 系统中色块填充（Color Fill / Solid Fill）算法的原理、模块划分、参数配置与实现细节。
>
> 色块填充将闭合轮廓内的区域三角剖分，生成实心色块（`SyFillRegion`），用于激光切割的区域填充或视觉预览。

---

## 1. 算法概述

色块填充与线填充的本质区别：

| 特性 | 线填充（Fill2D） | 色块填充（FillColor2D） |
|---|---|---|
| 输出实体 | `SyLine`（线段） | `SyFillRegion`（三角面片） |
| 作用范围 | 按选中图元 | 按图层（`bFill=true` 的图层） |
| 算法核心 | 扫描线求交 | 三角剖分（Delaunay/Ear Clipping） |
| 渲染方式 | 线段绘制 | 三角面片实心填充 |

色块填充的基本思路：

1. **收集图元**：获取指定图层上的所有图元（排除已有的 `SyFillRegion`）
2. **连通分量划分**：通过空间索引 + 并查集，将相交图元分组
3. **离散化**：将图元转换为闭合轮廓
4. **布尔并集**：相交轮廓做并集运算（Clipper2）
5. **嵌套解析**：分析轮廓嵌套关系，确定填充区域
6. **三角剖分**：对每个填充区域做三角剖分
7. **写入场景**：生成 `SyFillRegion` 实体

## 2. 模块划分

| 模块 | 文件 | 职责 |
|---|---|---|
| 参数 | `ColorFillParameters.h` | 离散化容差、最小区域面积、嵌套规则 |

| 服务层 | `EntityColorFiller.h/cpp` | 整层填充、连通分量、增量更新、写入场景 |

## 3. 参数结构体

```cpp
namespace Eg {
    struct ColorFillParameters {
        double discretizeTolerance = 0.01;   // 曲线离散化容差（mm）
        double minRegionArea = 1e-6;         // 小于该面积的区域忽略（mm²）
        double minTriangleArea = 1e-9;       // 退化三角形过滤阈值（mm²）
        bool mergeIntersecting = true;       // 相交图元先做布尔并集
        FillNestingRule nestingRule = FillNestingRule::EvenOdd;  // 嵌套规则

        bool isValid() const {
            return discretizeTolerance > 0.0 && minRegionArea >= 0.0 && minTriangleArea >= 0.0;
        }
    };

    enum class FillNestingRule {
        EvenOdd,  // 奇偶规则：偶数深度填充，奇数深度镂空
    };
}
```

## 4. 处理流程

### 4.1 整层填充（fillLayer）

```
用户点击 "Fill..." → 选择 "Color Fill" → 配置参数
  │
  ▼ EntityColorFiller::fillLayer(layerId, params)
  │
  ├─ 1. collectFillableEntities(layerId)
  │     收集图层上所有图元（排除 SyFillRegion）
  │
  ├─ 2. removeFillRegionsOfLayer(layerId)
  │     移除该图层旧的填充图元
  │
  ├─ 3. partitionComponents(entities)
  │     ├─ BBoxSpatialIndex::build()       // 建立空间索引
  │     ├─ UnionFind::unite()              // 并查集合并相交图元
  │     └─ 按根节点分组                     // 输出连通分量列表
  │
  ├─ 4. 对每个连通分量:
  │     └─ computeComponentRegions(component, params)
  │         ├─ entityToContours()          // 图元 → 闭合轮廓
  │         ├─ uniteContours()             // 布尔并集（Clipper2）
  │         ├─ resolveDepths()             // 嵌套深度解析
  │         ├─ buildFillRegions()          // 构建填充区域（外轮廓+孔洞）
  │         └─ triangulateToSoup()         // 三角剖分
  │
  └─ 5. writeRegionsToScene(regions, layerId)
        生成 SyFillRegion 实体写入场景
```

### 4.2 增量更新（updateAfterMove）

当图元移动时，仅重算受影响的连通分量：

```
updateAfterMove(movedEntities, oldBBoxes, params)
  │
  ├─ 1. 建立空间索引（基于当前包围盒）
  │
  ├─ 2. 对移动图元的新、旧包围盒分别查询
  │     得到受影响图元索引集合
  │
  ├─ 3. 划分连通分量，找出含受影响图元的分量
  │
  ├─ 4. 移除受影响分量的旧填充图元
  │
  └─ 5. 重算并写入新填充结果
```

与移动无关的分量完全跳过，保持响应效率。

## 5. 连通分量划分

### 5.1 空间索引（BBoxSpatialIndex）

- 均匀网格空间索引
- 支持增量插入/删除/更新
- 查询：相交查询、包含点查询

### 5.2 并查集（UnionFind）

将包围盒相交的图元合并到同一连通分量：
1. 对每个图元查询空间索引，找到包围盒相交的图元对
2. 用并查集合并
3. 按根节点分组，得到连通分量列表

---

## 6. 嵌套解析（ContainmentResolver）

### 6.1 嵌套深度计算

使用射线法（Ray Casting）计算每个轮廓的嵌套深度：
- 从轮廓内一点向右发射水平射线
- 统计与其他轮廓的交点数
- 偶数深度 → 填充区域（外轮廓）
- 奇数深度 → 镂空区域（孔洞）

### 6.2 填充区域构建（buildFillRegions）

将轮廓配对为填充区域：
- 外轮廓（偶数深度）+ 直接子孔洞（奇数深度）
- 输出 `FillRegion` 结构

## 7. 数据结构

```cpp
// 闭合轮廓点序列（首尾不重复）
using FillContour = std::vector<Ut::Vec2d>;

// 三角剖分输出：扁平三角形顶点流（每3个顶点=1个三角形）
using FillTriangleSoup = std::vector<Ut::Vec2d>;

// 单个填充区域
struct FillRegion {
    FillContour outer;                    // 外轮廓（CCW）
    std::vector<FillContour> holes;       // 直接子孔洞（CW）
    FillTriangleSoup triangles;           // 三角剖分结果
    int sourceEntityCount = 0;            // 来源图元数量
    std::vector<EntityId> sourceEntityIds; // 来源图元 ID

    bool isValid() const {
        return outer.size() >= 3 && !triangles.empty() && triangles.size() % 3 == 0;
    }

    size_t triangleCount() const {
        return triangles.size() / 3;
    }
};
```

## 8. 图层属性

色块填充依赖图层的两个属性：

| 属性 | 类型 | 说明 |
|---|---|---|
| `fill` | bool | 是否填充图层（该图层上图元参与色块填充） |
| `fillColor` | color | 填充色（色块使用的颜色） |

调用链（可撤销）：
```
LayerManagerDialog（"Color Fill" 复选框 + "Fill Color" 拾色器）
  → LayerEditService::setLayerFill / setLayerFillColor
  → LayerManager::setLayerFill / setLayerFillColor
  → LayerPersistenceBridge::syncLayerToDb
```

---

## 9. 渲染

- 新增图元类型 `EType::FILL_REGION`（`SyFillRegion`）
- 存储扁平三角形顶点流与来源图元 ID
- `Tessellator` 输出 `PrimitiveType::Triangles`
- 实时渲染：`EntityGeometryEmitter` → `emitTriangles` → `PrimitiveType::TriangleList`
- 填充色：`overrideColor` 设为图层填充色

---

## 10. DLL 导出

所有核心算法模块均通过 `ENGINE2D_API` 导出：
- `PolygonTriangulator`
- `ContainmentResolver`
- `BBoxSpatialIndex`
- `EntityColorFiller`

跨 DLL 数据传递使用 POD 访问器（指针 + 计数），避免 `std::vector` 跨 DLL 边界。

## 12. 已知限制

- `FileIO` 序列化（proto）尚未支持 `FILL_REGION`：保存文档时色块图元会被丢弃，加载后需重新执行填充命令
- 增量更新与交互工具（SelectTool 移动）的自动联动可作为后续增强
- 三角剖分使用耳切法，对极度复杂的多边形可能退化
