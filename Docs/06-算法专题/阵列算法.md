# 阵列算法（ArrayAlgorithm）

> 本文档描述 CAD 系统中阵列（Array）算法的核心实现、参数配置、调用流程与优化分析。
>
> 阵列是一种常见的图形复制操作，通过指定行/列数或角度/半径，将选中的图元按规则复制并排列成矩阵或环形分布。本算法支持矩形阵列和环形阵列两种模式，并提供多种遍历顺序以优化加工路径。

---

## 1. 一句话概括

对**源图元集合**进行并行克隆 + 几何变换（平移或旋转），按矩形网格或圆周分布生成副本，同时维护副本与源图元的群组关系，支持取消操作和进度回调。

---

## 2. 核心类型与参数

### 2.1 阵列类型

```cpp
enum class ArrayType {
    Rectangular,  // 矩形阵列
    Circular      // 环形阵列
};
```

### 2.2 遍历顺序策略

```cpp
enum class TraversalOrder {
    RowFirst,     // 行优先: (0,0)→(0,1)→...→(0,n)→(1,0)...
    ColumnFirst,  // 列优先: (0,0)→(1,0)→...→(n,0)→(0,1)...
    Zigzag,       // 之字形: (0,0)→(0,1)→...→(0,n)→(1,n)→(1,n-1)...
    Spiral,       // 螺旋扫描: 从外向内/从内向外螺旋访问
    TSPGreedy,    // 贪心TSP（最近邻）
    TSP2Opt       // 2-opt优化TSP
};
```

### 2.3 完整参数结构

```cpp
struct ArrayParams {
    ArrayType type = ArrayType::Rectangular;

    // 矩形阵列参数
    int rows = 3;
    int cols = 3;
    double rowSpacing = 10.0;   // 行间距
    double colSpacing = 10.0;   // 列间距

    // 环形阵列参数
    int count = 6;              // 副本数量
    double angle = 360.0;        // 总角度（度）
    double radius = 50.0;       // 半径

    TraversalOrder traversalOrder = TraversalOrder::RowFirst;

    // 异步支持
    std::function<bool()> cancelRequested;
    std::function<void(double progress, const std::string& stage)> progressCallback;
};
```

## 3. 算法实现详解

### 3.1 核心接口

```cpp
class ArrayAlgorithm : public IGeometryAlgorithm {
```

### 3.2 矩形阵列算法流程

```cpp
ArrayResult ArrayAlgorithm::createRectangularArray(
    const std::vector<const SyEntity*>& sourceEntities,
    const ArrayParams& params, ...)
{
    // 1. 参数校验
    const int totalCopies = params.rows * params.cols;
    if (totalCopies <= 1 || sourceEntities.empty()) {
        return error;
    }

    // 2. 预热图元缓存（并发安全准备）
    for (const auto* e : sourceEntities) {
        e->prewarmCaches();  // 单线程预热惰性缓存
    }

    // 3. 计算源图元包围盒
    Ut::BBox2d sourceBbox = computeSourceBbox(sourceEntities);
    double sourceWidth = sourceBbox.width();
    double sourceHeight = sourceBbox.height();

    // 4. 生成遍历顺序
    std::vector<int> orderIndices = generateTraversalOrder(
        params.rows, params.cols, params.traversalOrder);

    // 5. 并行生成副本
    result.entities = EngineParallel::parallelCollect<std::unique_ptr<SyEntity>>(
        totalPositions, [&](size_t idx, std::vector<std::unique_ptr<SyEntity>>& out) {
            // idx=0 为原位，跳过
            if (r == 0 && c == 0) return;

            // 计算偏移量
            const double offsetX = c * (sourceWidth + params.colSpacing);
            const double offsetY = r * (sourceHeight + params.rowSpacing);

            // 构造变换矩阵
            const Ut::Mat3d translation = Ut::Mat3d::translate(offsetX, offsetY);

            // 克隆并变换每个源图元
            for (const auto* e : sourceEntities) {
                auto cloned = std::unique_ptr<SyEntity>(e->clone());
                cloned->transform(translation);
                cloned->setLayer(e->layer());
                cloned->setGroup(nullptr);
                out.push_back(std::move(cloned));
            }
        });

    return result;
}
```

### 3.3 环形阵列算法流程

```cpp
ArrayResult ArrayAlgorithm::createCircularArray(
    const std::vector<const SyEntity*>& sourceEntities,
    const ArrayParams& params, ...)
{
    // 1. 参数校验
    if (params.count <= 1 || sourceEntities.empty()) {
        return error;
    }

    // 2. 预热图元缓存
    for (const auto* e : sourceEntities) {
        e->prewarmCaches();
    }

    // 3. 计算角度步长
    const double startAngle = 0.0;
    const double angleStep = (params.angle / 180.0 * M_PI) / params.count;

    // 4. 并行生成副本
    result.entities = EngineParallel::parallelCollect<std::unique_ptr<SyEntity>>(
        totalCopies, [&](size_t idx, std::vector<std::unique_ptr<SyEntity>>& out) {
            if (idx == 0) return;  // 原位

            // 计算当前角度和偏移
            const double angle = startAngle + idx * angleStep;
            const double offsetX = params.radius * std::cos(angle);
            const double offsetY = params.radius * std::sin(angle);

            // 构造变换：先旋转后平移（先绕原点旋转，再移到圆周位置）
            const Ut::Mat3d rotation = Ut::Mat3d::rotate(-angle);
            const Ut::Mat3d translation = Ut::Mat3d::translate(offsetX, offsetY);
            const Ut::Mat3d transform = translation * rotation;

            // 克隆并变换
            for (const auto* e : sourceEntities) {
                auto cloned = std::unique_ptr<SyEntity>(e->clone());
                cloned->transform(transform);
                cloned->setLayer(e->layer());
                cloned->setGroup(nullptr);
                out.push_back(std::move(cloned));
            }
        });

    return result;
}
```

### 3.4 遍历顺序生成

```cpp
std::vector<int> ArrayAlgorithm::generateTraversalOrder(
    int rows, int cols, TraversalOrder order)
{
    std::vector<int> result(rows * cols);
    std::iota(result.begin(), result.end(), 0);

    switch (order) {
    case TraversalOrder::RowFirst:
        // 默认顺序，无需处理
        break;

    case TraversalOrder::ColumnFirst:
        // 转置矩阵
        for (int r = 0; r < rows; ++r)
            for (int c = 0; c < cols; ++c)
                transposed[c * rows + r] = result[r * cols + c];
        break;

    case TraversalOrder::Zigzag:
        // 偶数行不变，奇数行反向
        for (int r = 1; r < rows; r += 2)
            for (int c = 0; c < cols / 2; ++c)
                std::swap(result[r * cols + c],
                          result[r * cols + (cols - 1 - c)]);
        break;

    case TraversalOrder::Spiral:
        // 螺旋遍历：上→右→下→左
        while (top <= bottom && left <= right) {
            // 从左到右
            for (int c = left; c <= right; ++c) spiral.push_back(...);
            ++top;
            // 从上到下
            for (int r = top; r <= bottom; ++r) spiral.push_back(...);
            --right;
            // 从右到左
            for (int c = right; c >= left; --c) spiral.push_back(...);
            --bottom;
            // 从下到上
            for (int r = bottom; r >= top; --r) spiral.push_back(...);
            ++left;
        }
        break;
    }
    return result;
}
```

### 3.5 群组关系维护

```cpp
void ArrayAlgorithm::maintainGroupRelations(
    const std::vector<const SyEntity*>& sourceEntities,
    const std::vector<SyGroup*>& sourceGroups,
    const std::vector<SyEntity*>& copyEntities,
    GroupManager* groupManager)
{
    // 每个副本各自成组，镜像源图元的直接群组关系
    // 副本内部保持与源一致的成组关系，副本之间互不相干
    for (size_t copyIdx = 0; copyIdx < numCopies; ++copyIdx) {
        std::unordered_map<SyGroup*, std::vector<SyEntity*>> membersOfCopy;

        for (size_t i = 0; i < entitiesPerCopy; ++i) {
            const SyEntity* srcEntity = sourceEntities[i];
            SyEntity* copyEntity = copyEntities[copyIdx * entitiesPerCopy + i];
            if (srcEntity && srcEntity->group() && copyEntity) {
                membersOfCopy[srcEntity->group()].push_back(copyEntity);
            }
        }

        // 为每个源群组创建新群组
        for (auto& [srcGroup, members] : membersOfCopy) {
            SyGroup* newGroup = groupManager->createGroup(srcGroup->nameStr() + "_copy");
            newGroup->addEntities(members);
        }
    }
}
```

## 4. 并发与线程安全

### 4.1 并行策略

使用 `EngineParallel::parallelCollect` 进行数据并行：

- **任务划分**：每个阵列位置（行×列）作为一个工作项
- **输出顺序保证**：按位置升序收集结果，保证输出顺序与串行一致
- **原子操作**：使用 `std::atomic` 计数器记录完成进度

### 4.2 线程安全要点

1. **缓存预热**：并行前单线程调用 `prewarmCaches()`，之后只读命中
2. **无锁设计**：每个位置独占局部结果容器，无锁竞争
3. **顺序确定性**：输出顺序固定，避免 EntityId 分配、落盘、撤销栈不可复现

### 4.3 取消与进度

```cpp
// 取消检查
if (cancelled.load(std::memory_order_relaxed)) return;
if (params.cancelRequested && params.cancelRequested()) {
    cancelled.store(true);
    return;
}

// 进度汇报
const size_t done = completed.fetch_add(1) + 1;
if (params.progressCallback && workItems > 0) {
    params.progressCallback(done / workItems, "Rectangular array");
}
```

## 6. 复杂度分析

设源图元数为 E，矩形阵列总副本数为 N = rows × cols：

| 步骤 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 缓存预热 | O(E) | O(1) |
| 包围盒计算 | O(E) | O(1) |
| 遍历顺序生成 | O(N) | O(N) |
| 并行克隆+变换 | O(E × N) | O(E × N) |
| 群组关系维护 | O(E × N) | O(E × N) |

**总时间复杂度**：O(E × N)

## 7. 优化分析

### 7.1 已实现的优化

- ✅ **数据并行**：使用 `parallelCollect` 多线程并行生成副本
- ✅ **缓存预热**：预热惰性缓存，避免并发竞争
- ✅ **局部结果无锁**：每个位置独占结果容器
- ✅ **确定性输出**：按位置升序收集，保证可复现性

### 7.2 潜在优化空间

1. **增量克隆**：源图元完全相同时（如多个相同圆），可以复用克隆结果
2. **批量预分配**：`result.entities` 可预先分配 exact size，避免动态扩容
3. **SIMD 加速**：图元变换（矩阵乘法）可使用 SIMD 加速
4. **GPU 加速**：大批量阵列可考虑 GPU 并行
5. **TSP 整合**：`PathOptimizer` 已实现 `greedy()` 和 `twoOpt()`（`PathOptimizer.cpp`），
   但 `ArrayAlgorithm::generateTraversalOrder` 中 `TSPGreedy/TSP2Opt` 分支尚未调用，
   可整合为激光加工优化路径

### 7.3 已知不足

1. **TSP 未接入阵列遍历**：`PathOptimizer` 已有完整实现（贪心最近邻 + 2-opt 优化），
   但 `ArrayAlgorithm::generateTraversalOrder` 对 `TSPGreedy/TSP2Opt` 分支为空 `break`，
   需要将 `PathOptimizer::compute` 接入阵列生成流程
2. **圆形缩放**：环形阵列未考虑源图元自身尺寸对半径的影响
3. **碰撞检测**：未检查阵列副本之间是否重叠
4. **边界处理**：未提供"自动计算间距"功能，需用户手动指定
