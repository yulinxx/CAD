```

   │  → SceneManager::insertEntitiesPreserveId (unique_ptr 接管, 分配 EntityId)
   │  图元默认落当前图层 (SceneEditService.cpp:357)
```

## 2. 环节 1：导入

### 2.1 格式与解析器

| 格式 | 解析器 | 载体 | 结论 |
| --- | --- | --- | --- |
| DXF | `DxfParser` | `Fio::EntityInfo`（polyline/arc/circle…） | 主路径，单位读 `$INSUNITS` |
| SVG | `SvgParser`（NanoSVG） | 同上 | **单位按 1px=1mm 静默落地** |
| PDF | `PdfParser` + `PdfToSvgConverter` | SVG 中间态 | 与 SVG 同一单位缺陷 |
| STEP/IGES(UG) | `StepParser` / `UgParser` | 取"最大面积平面"轮廓 → Polygon | 单向、不可逆、多平面丢弃 |
| STL/OBJ | `StlParser` / `ObjParser` | 三角网格 → Engine3D | 不进 2D 场景 |
| 位图 BMP/PNG | 无解析器，`FileDropHandler` / 位图导入路径 | `Eg::SyImage` | DPI 默认 96（已记录 A19） |
| .sy | `NativeImportReader` / `SySerializer` | `Eg::SyEntity` | 图层表整体丢失（见环节 4） |

格式注册：`FileIO/FileIO/Src/FormatRegistry.cpp:101-113`；解析器未注册时返回 `nullptr` 并告警（`FileParserFactory.cpp:33-49`）。

### 2.3 断链检查

- 解析器产出但下游未消费：`EntityInfo::lineWidth`、`barWidth` 在 2D 转换后无渲染/加工消费者（`Fio2DEntityConverter` 只取几何与颜色）；不影响加工，P2。
- PDF 的 `PdfParser::parse` 不是通用入口，PDF 只能走 `PdfToSvgConverter` 专用路径；两者单位口径不一致时无告警（与 I-1 同源）。

## 4. 环节 3：编辑命令与撤销

### 4.1 机制

| 机制 | 语义 | 证据 |
| --- | --- | --- |

## 5. 环节 4：持久化

### 5.1 真实路径

**保存 `.sy`（生产）**：`FileOperationRegistry::doExport` → `ExportService::exportFile` → 主线程克隆图元、把 `sceneManager` 置空 → `NativeExportWriter::write` → `NativeWriter::write(path, entities)` → `SyDocument::addBorrowedEntity` → `SySerializer::saveToFile`。
证据：`FileOperationRegistry.cpp:193-215`、`ExportService.cpp:167,330`、`NativeExportWriter.cpp:30-61`、`NativeWriter.cpp:92-114`。

**`SceneManagerSerializer`（EnginePersistence）在生产零调用**，只有测试引用；因此"图层表由 `layersToProto` 完整写出"的能力没有接到保存按钮上。
