# 矢量文字编辑模块设计文档

> 版本: 1.0
> 日期: 2026-08-15
> 范围: 文字输入后的**点击编辑 / 插入 / 选择删除 / 光标移动 / 字体样式变换**

---

## 1. 目标与需求

在现有"文字输入工具（TextInputTool）"产出的**矢量文字**基础上，提供类文本编辑器的能力：

1. **进入编辑**：双击文字（或文字编辑工具激活后单击）进入编辑会话。
2. **插入**：在光标处键入字符（含中文、英文等），光标随之后移。
3. **选择**：鼠标按下拖动选择字符区间；`Ctrl+A` 全选。
4. **删除**：`Backspace` 删除光标前字符、`Delete` 删除光标后字符、选中区间一键删除。
5. **光标移动**：`← / →` 按字符移动（可配合 `Ctrl` 按词、`Shift` 扩展选区），`Home / End` 行首行尾。
6. **字体/样式变换**：对选中字符（无选区时作用于全文）设置 字体族 / 字号 / 加粗 / 斜体 / 下划线，支持**同一段文字内混合字体**。
7. **提交与撤销**：编辑会话结束（回车 / 点击空白 / 切换工具）一次性提交，整体支持 `Undo/Redo`。

非目标（后续可扩展）：多行文字、富文本粘贴、拼写检查、文字排版对齐线等。

## 2. 现状分析与关键约束

### 2.1 当前文字的数据结构

`TextProcessor::addTextToScene()` 将文字转为矢量轮廓并组织为嵌套群组：

```
Text 群组 (name = "Text")                      ← 顶层群组
├── Char 群组 (name = "Char", 每个字符一个)     ← 子群组
│   ├── SySmartLine (字形第 1 个轮廓)
│   ├── SySmartLine (字形第 2 个轮廓)
│   └── ...
└── Char 群组 ...
```

- 图元所有权在 `SceneManager`；群组关系在 `GroupManager`；群组 id/name 会随文件持久化。
- **关键缺陷**：当前群组结构只保存了字形几何，**没有保存"原始文字内容 / 字体 / 字号 / 样式"**，无法反推用于编辑。

### 2.2 现有相关组件

| 组件 | 位置 | 作用 |
| --- | --- | --- |
| `TextConverter::doConvertByCharacter` | Engine2D/Text | 按字符生成字形轮廓（`CharSmartLines`） |
| `TextProcessor` | UI2D/Option | 转换 + 建群组 + 入场景 |
| `TextInputDlg` / `TextDlgParameters` | UI2D/UI/Dlg | 收集文字内容与字体参数 |
| `SceneManager` / `GroupManager` | Engine2D | 图元/群组唯一数据源 |
| `SceneEditService` | Engine2D/Edit | 一切场景修改的唯一入口，支持 Undo |
| `ToolManager` / `BaseTool` | UI2D/UI/DrawTools | 工具注册与交互协议 |
| `RenderOverlayUpdate` | UI/Common | 覆盖层渲染（选择框/选区/点标记） |

### 2.3 设计约束

- 群组 name 可随文件持久化，是**唯一天然可用的元数据携带通道**（Entity 无属性袋）。
- `GroupManager::removeEmptyGroups` 会清理空群组：重建文字时**不能依赖旧群组存活**，必须"先抓取元数据 + 记录结构快照，再整体重建"。
- 现有 Undo 命令（`Delete/Add/Snapshot`）只恢复图元，**不恢复群组结构**，因此文字编辑需要一个**群组感知**的专用撤销命令。
- UI2D 源文件按目录显式 glob，新增目录需改 `UI/2D/CMakeLists.txt`。

## 4. 元数据设计

### 4.1 存储载体：群组名

```
Text|SY_TXT:v1:<base64(UTF-8 JSON)>
```

- 前缀 `Text|` 保留可读性、兼容"以 Text 开头的文字群组"识别逻辑；
- `SY_TXT:` 标记为本模块元数据；`v1` 为版本号（便于未来迁移）；
- 群组名随文件持久化，重新打开文件后仍可编辑。

### 4.2 JSON 结构

```json
{
  "c": "Hello",                                  // 文字内容 (QString→UTF-8)
  "x": 100.0, "y": 200.0,                        // 原点(基线笔起始)
  "a": 0,                                        // 对齐: 0左 1中 2右
  "r": 0.0,                                      // 旋转角(弧度, 预留)
  "f": [                                         // 逐字符样式, 长度==字符数
    { "fam": "Arial", "s": 12, "b": false, "i": false, "u": false },
    ...
  ]
}
```

- 兼容性：旧数据群组名为纯 `Text`（无 `SY_TXT:` 前缀）→ 视为**不可编辑**，`loadModel` 返回明确错误信息，不破坏渲染。

## 5. 核心组件设计

### 5.1 `TextMeta`（纯数据模型）

```cpp
struct TextCharStyle {
    QString fontFamily = "Arial";
    double  fontSize  = 12.0;
    bool    bold      = false;
    bool    italic    = false;
    bool    underline = false;
};

struct TextMeta {
    QString text;                      // 文字内容
    QVector<TextCharStyle> styles;     // 逐字符样式
    Ut::Vec2d origin{0,0};             // 基线起点
    int alignment = 0;                 // 0/1/2
    double rotation = 0.0;             // 预留

    // 便捷接口
    const TextCharStyle& styleAt(int i) const;
    void insert(int pos, const QString& s, const TextCharStyle& st);
    void remove(int pos, int count);
    void applyStyle(int start, int end, const TextCharStyle& delta); // 区间样式
    bool isValid() const;
    bool operator==(const TextMeta&) const; // 会话无变更判定
};
```

### 5.2 `TextMetaCodec`

```cpp
QString encodeToGroupName(const TextMeta&);          // → "Text|SY_TXT:v1:<base64>"
bool    decodeFromGroupName(const QString&, TextMeta&);
bool    isEditableTextGroupName(const QString&);     // 含 SY_TXT: 前缀
```

- 内部用 `QJsonObject/QJsonDocument`，base64 使用 `QByteArray::toBase64`。

### 5.3 `TextLayoutCalculator`

- 场景字符包围盒（`Char 群组.getBbox()`）是**渲染真源**，布局优先读取它；
- 提供：
  - `computeCharXs(const QVector<Ut::BBox2d>& boxes)` → 每字符的 x 起始/结束边界（相邻字符取中点）；
  - `hitTestIndex(const QVector<Ut::BBox2d>& boxes, double worldX, bool rightSide)` → 光标字符索引；
  - `charBoundaryX(boxes, index)` → 光标坐标（供覆盖层画竖线）。

### 5.4 `TextEditService`（业务编排）

```cpp
class TextEditService {
public:
    explicit TextEditService(Eg::SceneManager* scene,
                             SceneEditService* edit,         // 可空: 无 undo 时仅直接改场景
                             LayerManager* layers);          // 可空: 锁定图层过滤

    // 识别
    static bool    isTextGroup(const Eg::SyGroup*);
    Eg::SyGroup*   findTextGroupAt(const Ut::Vec2d& pos);    // 点选命中
    Eg::SyGroup*   topLevelTextGroupOf(Eg::SyEntity* e);     // 双击命中

    // 载入
    bool loadModel(Eg::SyGroup*, TextMeta& out, QString& err);

    // 重建（编辑会话内, 非撤销路径）
    bool rebuildTextGroup(const TextMeta&, QString& err);    // 使用当前编辑中的群组

    // 会话
    bool beginSession(Eg::SyGroup* g, QString& err);         // 抓取 before 快照
    bool commitSession(const TextMeta& finalMeta, QString& err); // 重建+压入 undo
    void cancelSession();                                    // 恢复 before

    // 字体操作（纯模型）
    static void applyStyleToRange(TextMeta&, int start, int end,
                                  const TextCharStyle& delta);
    static void scaleFontSize(TextMeta&, int start, int end, double delta);

private:
    Eg::SceneManager* m_scene;
    SceneEditService* m_edit;       // 可空
    Eg::SyGroup*      m_sessionGroup = nullptr;
    TextMeta          m_original;                 // 会话起始模型
    TextGroupSnapshot m_beforeSnap;               // 会话起始场景快照
};
```

**重建流程（`rebuildTextGroup`）**：
1. 用 `TextMetaCodec` 生成新群组名（元数据）；
2. 对每个字符调用 `TextConverter.doConvertByCharacter`（单字符、携带该字符样式、`pos.x=penX`）；
3. 收集字形轮廓，逐字符创建 `Char` 群组；
4. 清空旧文字群组（抓取 id/name 后删除其全部叶子图元，空群组会被自动清理）；
5. 用 `createGroupWithId(旧id, 新群组名)` 重建顶层 `Text` 群组，挂接全部 `Char` 子群组；
6. 新叶子图元经 `addEntities`（保 ID）入场景。

**提交流程（`commitSession`）**：
1. 若 `TextMeta == 原始` 则直接结束（无变更不压撤销）；
2. 抓取 `after` 快照（当前群组结构 + 叶子图元克隆）；
3. 通过 `IUndoRedoManager::pushExecutedCommand(new ReplaceTextGroupCommand(before, after))` 压栈一次。

### 5.5 引擎层 `TextGroupSnapshot`（Engine2D/Text）

```cpp
struct TextGroupSnapshot {
    EntityId  groupId = 0;
    std::string name;                                  // 群组名(元数据)
    std::vector<std::vector<std::unique_ptr<SyEntity>>> charGroups; // 有序字符组, 叶子为克隆(保ID)
};

ENGINE2D_API bool captureTextGroup(Eg::SceneManager*, Eg::SyGroup*, TextGroupSnapshot& out);
ENGINE2D_API bool restoreTextGroup(Eg::SceneManager*, const TextGroupSnapshot& snap);
```

**恢复流程（`restoreTextGroup`）**：
1. 若已存在同 id 群组：删除其全部叶子图元 → `destroyGroup`；
2. `createGroupWithId(snap.groupId, snap.name)` 重建顶层群组；
3. 逐字符组：克隆叶子入场景（保 ID）→ `createGroup(..., "Char")` → 挂接为子群组。

### 5.6 引擎层 `ReplaceTextGroupCommand`

- 继承 `UndoRedoManager::Command`；
- `execute()` → `restoreTextGroup(after)`；`undo()` → `restoreTextGroup(before)`；
- 工厂 `createReplaceTextGroupCommand(scene, before, after, desc)` 在 Engine2D DLL 内构造（避免 STL 跨 DLL）。

## 6. 交互工具 `TextEditTool`

### 6.1 状态机

```
Idle ──(单击命中文字)──► Editing
Idle ──(激活时选中集含文字)──► Editing
Editing ──(回车/点击空白/切换工具)──► 提交 ──► Idle
Editing ──(取消)──► 恢复 before ──► Idle
```

### 6.2 事件处理

| 事件 | 行为 |
| --- | --- |
| 左键按下（编辑态） | 命中测试 → 设置光标；记录拖选起点 |
| 左键拖动 | 实时扩展选区 |
| 左键释放 | 结束选区 |
| 左键按下（空闲态） | 命中文字→进入编辑；否则忽略 |
| 可打印字符 | `text()` 插入光标处 |
| Backspace / Delete | 删除字符（无选区删 1 个，有选区删区间） |
| ←/→ | 移动光标（Shift 扩展选区；Ctrl 按词） |
| ↑/↓ | 上下行移动光标（Shift 扩展选区） |
| Home / End | 当前行首 / 行尾 |
| Ctrl+A | 全选 |
| Ctrl+C / V / X | 复制 / 粘贴 / 剪切（系统剪贴板） |
| Ctrl+B / I / U | 选区加粗 / 斜体 / 下划线切换 |
| Ctrl+= / Ctrl+- | 选区字号 ±1 |
| Esc | 提交并退出编辑 |
| 回车 / 点击空白 | 提交并退出编辑 |

### 6.3 覆盖层渲染

| 内容 | 通道 | 说明 |
| --- | --- | --- |
| 光标竖线 | `selectionBox`（SelectionBox 组） | 细矩形，宽≈2px，蓝色 |
| 选区高亮 | `selectionRect`（Preview 组） | 选中字符包围盒并集，半透明蓝色 |

- 退出会话时 `clearOverlay()` 清空。

### 6.4 与 SelectTool 的协作

- 在 `SelectTool::tryEnterEntityEdit` 中，若双击命中的实体属于文字群组：
  1. 先 `selectEntityWithGroup(e)`（选中整段文字，作为交接数据）；
  2. `switchTool("TextEditTool")`；
- `TextEditTool::onActivate` 读取当前选择集，取顶层文字群组进入编辑会话。

## 8. 数据流示例

**场景：用户双击文字 "Hello" 输入 "A"，再改选中 "llo" 字号为 16。**

```
1. SelectTool 双击命中 "Hello"
     └─► selectEntityWithGroup(e)  →  switchTool("TextEditTool")
2. TextEditTool::onActivate
     └─► 读选中集 → 顶层文字群组 → TextEditService.beginSession
           ├─ TextMetaCodec.decodeFromGroupName → meta{text:"Hello", styles:[H,e,l,l,o]}
           └─ captureTextGroup → before 快照
3. 键入 'A' (光标在 1)
     └─ meta.insert(1,"A",style) → rebuildTextGroup(meta) → 场景实时更新 + 光标右移
4. Shift+← 选中 "llo"
5. Ctrl+=  字号+1
     └─ meta.applyStyleToRange(2,5,{s:16}) → rebuildTextGroup(meta)
6. 回车
     └─ TextEditService.commitSession
           ├─ captureTextGroup → after 快照
           ├─ undo.pushExecutedCommand(new ReplaceTextGroupCommand(before,after))
           └─ clearOverlay → 回 SelectTool
```

## 9. 可扩展性设计

- **新字体属性**（字距、基线偏移、字重）：仅需扩展 `TextCharStyle` + `TextMetaCodec` 版本升级（`v1→v2`），兼容读取旧版本。
- **多行文字**：`TextMeta` 增加行高字段，布局器按行拆分，重建逐行放置。
- **富文本粘贴**：`TextEditTool` 剪贴板分支解析 `text/html` → 生成样式 runs。
- **框选编辑区域**：在 `TextEditTool` 增加 `EditArea` 概念（矩形），命中测试先落在编辑区域内。
- **渲染侧边框/基线辅助线**：复用覆盖层通道即可，不改引擎。

## 10. 风险与取舍

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 旧文字无元数据 | 无法编辑 | 识别为不可编辑并提示；新文字自动携带元数据 |
| 每字符重建开销 | 长文本逐键重建慢 | 本次实现先全量重建；后续可做增量（仅重排受影响字符） |
| 字符定位用包围盒 | 光标精确度依赖字形 | 相邻字符取中点边界；后续接入 glyph advance |
| 撤销仅一个命令粒度 | 无法逐键撤销 | 符合 CAD 惯例（一次编辑会话一次撤销） |

### 12.2 变换保持（关键设计）

1. **检测**：进入编辑会话时，以"基准字符基点 ↔ 场景字符基点"的最小二乘求解
   文字块整体仿射变换（≥3 字符）或相似变换（2 字符）。基准几何由
   `TextConverter.doConvertByCharacter(..., &outAdvance)` 重新生成，
   其水平推进与原始布局完全一致，保证检测精确。
2. **复现**：重建几何时对每个字形应用该变换；布局（光标/命中）保持在基空间，
   世界坐标先经逆变换回基空间再命中，光标线段经变换后按旋转方向绘制。
3. **持久化**：变换随几何保存（图元顶点携带），重新打开文件/重新进入会话时
   自动重新检测，无需额外元数据。

### 12.3 输入法（IME）链路（跨平台）

```
RenderWidget (Qt::StrongFocus + WA_InputMethodEnabled)
  → inputMethodEvent() 覆写：将 QInputMethodEvent 转交注入的处理器
  → inputMethodQuery()：ImEnabled / ImCursorRectangle / ImFont /
                        ImSurroundingText / ImCursorPosition / ImAnchorPosition
  → ViewportInputRouter（查询处理器 + 事件处理器，均委托活动工具）
  → TextEditTool::onInputMethodEvent：preedit 临时插入 → commit 替换上屏
    光标世界矩形经相机换算为屏幕矩形（ImCursorRectangle），光标移动后
    调用 QGuiApplication::inputMethod()->update() 刷新候选窗口
```

关键点：

1. **事件入口**：`QOpenGLWidget` 默认不把 `QInputMethodEvent` 派发给业务逻辑，
   必须覆写 `RenderWidget::inputMethodEvent()` 并转交上层处理器，否则中文
   组字/上屏被 Qt 直接丢弃（此前中文无法输入的根本原因）。
2. **焦点**：`RenderWidget` 需 `Qt::StrongFocus`，否则输入法上下文不与控件绑定。
3. **查询完整**：Windows（IM）、macOS（NSTextInputClient）、Linux（IBus/Fcitx）
   依赖的查询需全部应答，缺失会导致候选窗口无法定位/渲染。
4. **防重复输入**：IME 组合期间（`m_imeActive`）屏蔽按键路径，组字由
   `QInputMethodEvent` 单一驱动；上屏后平台若再派发携带相同 `text()` 的
   按键事件，通过前缀匹配 `m_imeCommitRemaining` 逐字符消耗，避免多字符
   commit 部分重复输入（如 commit "你好" 后平台分别派发 '你'、'好' 两次按键）。

### 12.4 性能设计：字形缓存 + 增量重建

1. **字形缓存**：`TextEditService` 维护 `字符+样式 → 轮廓+推进宽` 缓存
   （`m_glyphCache`）。逐键重建只对首次出现的组合运行字体管线，其余命中缓存克隆。
   缓存设上限 4096 条，超过时整体清空并按需重建，防止超大文档/反复切换字体时内存无限增长。
2. **增量重建**：`rebuild` 对"有字形槽位"做公共前缀/后缀匹配（按字形键），
   中间区域才销毁重建；未变字符（含其它行）复用场景图元、仅平移
   （`transform` + `scene->updateEntityBounds`），并整体批量通知一次。
3. **快照恢复批量**：`restoreTextGroup` 将全部字符叶子合并为单次
   `scene->addEntities` 调用，把逐字符通知从 O(n) 降为 O(1)。
4. **结构兜底**：字符群组结构异常（旧版本/手工构造）时自动回退全量重建，
   保证正确性；`benchmark` 显示 1860 字符多行文本逐键追加重建约 <10ms。
5. **选区包围盒**：`charBoxes()` 改为基于布局逐槽位计算并映射到世界空间，
   与光标/命中完全同源，避免空格/换行槽位缺失导致的选区错位。

### 12.5 已知限制（后续可扩展）

1. **工具栏入口**：TextEditTool 暂未加入左侧绘图工具栏，进入方式为双击文字。
   后续可注册 `OperationId::Tool_EditText` 与工具栏按钮。
2. **旧文字不可编辑**：无 `SY_TXT:` 元数据的旧文字仅保留渲染能力。
3. **单字符旋转检测**：单字符文字无法从单个基点确定旋转角（仅恢复位置与缩放）。

### 12.8 已修复的关键缺陷

- **全选改字号崩溃（高危，2026-08-27）**：编辑态下 Ctrl+A 全选再改字号/字体族，
  必崩。`applyIncrementalRebuild` 第 1 步销毁旧字符群组时会调
  `deleteEntitiesBatch`，它连带跑 `GroupManager::removeEmptyGroups`；
  而顶层文字群组只挂子群组、不直接持图元，全选时 `prefix=suffix=0`，
  所有 Char 群组一次性解链，顶层群组随即满足 `isEmpty()` 被一并销毁，
  后续 `group->replaceSubGroups()` / `setNameStr()` 就在写已释放的内存
  （SEH 0xC0000005）。已修复：旧叶子的删除推迟到 `replaceSubGroups` 之后，
  顶层群组在整个过程中始终非空。回归由 `FontStyleToolbarOperationsApplyToSelection` 覆盖
  —— 该用例此前一直"超时"，掩盖了这个崩溃。
- **每次重建重复读几百 MB 字体文件（2026-08-27）**：Windows 分支的
  `Eg::loadFontFace` 用 `FT_New_Memory_Face`（`FT_New_Face` 只吃本地代码页路径），
  每次调用都把整个字体文件读进内存；而 `findFaceIndex` 会对同一文件按
  `num_faces+1` 次反复加载，`doConvertByCharacter` 又无条件把 13 个族名的
  回退链整条加载一遍 —— 哪怕正文是纯 ASCII、主字体完全够用。
  单次字形转换因此要读掉 3~4 亿字节，Debug 下一次 rebuild ~5s。已修复三处：
  1. `FontUtil.cpp` 加进程级字体文件字节缓存（不淘汰：`FT_New_Memory_Face`
     只借用缓冲，淘汰会让在用的 `FT_Face` 悬垂）；`FontData` 增
     `bOwnsBuffer` 区分自有/借用；
  2. `TextConverter.cpp` 给 `findFaceIndex` 加 `(路径, 族名) → face 索引` 缓存；
  3. 回退链改为**延迟加载** —— 只有主字体缺该字形时才向链表后方取下一个字体。
  效果：`TextEditServiceTests` 整套从 >600s（超时）降到 8s，
  单次多行重建从 ~5s 降到 93ms（Debug）。
- **撤销崩溃（高危）**：`SyEntity::clone()` 会拷贝 `pGroup` 群组引用。编辑会话的
  before 快照克隆若携带该引用，旧群组被重建销毁后克隆仍指向悬垂内存，
  执行 Undo 恢复 before 快照时 `createGroup` → `addEntity` 会解引用崩溃。
  已修复：`TextGroupSnapshot::clonePreserveId` 克隆后清空 `pGroup`，
  并新增 `UndoRestoreBeforeSnapshot` 回归测试。
- **中文无法输入（IME 失效）**：`QOpenGLWidget` 未覆写 `inputMethodEvent()`，
  `QInputMethodEvent` 被 Qt 丢弃。已修复：覆写并注入事件处理器 + `Qt::StrongFocus`，
  补齐 `ImFont/ImSurroundingText/ImCursorPosition/ImAnchorPosition` 查询，
  增加 IME 组合期间按键防重与上屏后"一次性按键"防重复。
- **选区无高亮框**：文字选区原本用细边框（22% 透明度）几乎不可见，且
  `charBoxes()` 按场景子群组取值会因空格/换行槽位缺失导致跨行选区错位。
  已修复：新增 `setFilledSelectionBox`（半透明填充 + 边框），选区包围盒改为
  布局逐槽位计算并与变换对齐。
- **多行文字响应慢**：逐键全量重建（删除+重建全部字形 + 逐字符通知 + 重复跑
  字体管线）。已修复：字形缓存 + 增量重建（前缀/后缀复用）+ 快照恢复批量提交，
  1860 字符多行文本逐键重建降至 ~10ms 以内。
- **多行光标导航缺失**：缺少 ↑/↓ 方向键支持，Home/End 移动到全文首尾而非
  行首行尾。已修复：新增 `moveCursorVertical` 实现行间导航，`lineStartSlot`/`lineEndSlot`
  支持行首行尾定位，`slotAtXOnLine` 按 X 坐标在目标行找最近槽位。
- **Utility 工作区编辑损坏**：`Vec.hpp` 本地改动引用了不存在的 `Vec::zero()`，
  在新增的模板实例化路径（`Mat3d` 运算）下编译失败。已改为默认构造
  `Vec()`（全 0 向量），保持"零向量归一化返回零向量"的意图。
- **beginSession 空会话（高危）**：布局计算失败时 `m_sessionGroupId` 已被设置，
  导致 `isSessionActive()=true` 但布局为空，后续操作在空布局上无定义行为。
  已修复：将 `m_sessionGroupId` 赋值移至布局计算成功之后，失败时返回 false 并
  设置错误信息。
- **IME 多字符 commit 部分重复**：旧实现用全串比较 `m_imeCommitText`，
  commit "你好" 后平台逐字符派发 '你'、'好' 两次按键时，第一个 '你' 不等于
  "你好" 不会被吞掉，导致部分重复输入。已修复：改用前缀匹配
  `m_imeCommitRemaining`，逐字符消耗，正确处理多字符 commit。
- **字形缓存内存无限增长**：字形缓存只增不减，超大文档或反复切换字体时
  内存持续膨胀。已修复：设上限 4096 条，超过时整体清空并按需重建
  （代价为一次字体管线全量重跑，仅触发一次）。
- **词边界 Ctrl+Left/Right 不支持 CJK**：旧实现用 `!isSpace()` 判断词边界，
  CJK 字符间无空格，导致 Ctrl+Left/Right 跳过整个 CJK 段而非逐字移动。
  已修复：改用 `QChar::isLetterOrNumber()`，CJK 字符逐字回退/前进。
