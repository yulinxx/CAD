## 1. P0 — 必须立即处理(✅ 已核实)

### P0-1 许可校验在发货版默认关闭,且没有任何构建目标启用它 ✅
- `Licensing/License/Src/LicenseInternal.cpp:12-16`:`g_checkEnabled` 默认值由 `#ifdef SANYI_ENABLE_LICENSE` 决定,未定义即 `false`。
- 全仓 CMake 无 `option()` 也无 `target_compile_definitions` 定义该宏;`Main/CMakeLists.txt:119` 只是把未定义变量写进 `BuildConfig.h`,恒为 `false`。
- 后果:`UiFeatureGate` 进入 unrestricted,试用期整体被跳过,付费控制失效。

### P0-2 单位变换读取悬垂指针(确定性 UAF)✅
- `FileIO/FileIO/Src/Internal/IrProjector.cpp:225`:`publish()` 返回的 `extensionBlob.data` 借用 `m_blob`(`std::vector<uint8_t>`)。
- `FileIO/FileIO/Src/UnitTransform.cpp:135`:保存 `srcBlob` 指针后进入循环;`FileIO/FileIO/Src/Internal/IrTransform.cpp:452` 等在循环内调 `pub.appendBlob()`,`IrProjector.cpp:132` 对同一 vector `resize`,全链路无 `reserve`。
- 任何带扩展数据、追加后超出既有容量的文件,重分配即令 `srcBlob` 悬空,后续读写为 UAF。

## 4. ❌ 不成立 / 已剔除的原指控

1. **"de/fr 环境 G-code 写成 X10,5"不成立**:全仓无 `std::locale::global`/`imbue`,`std::ostringstream` 默认即 "C" locale,现状不受系统 locale 影响。降级为防御性编码建议(仍顺手补 `imbue(classic)`)。另:ToolpathExporter.cpp 实际在 Engraving 模块,非 FileIO。
2. **"UiEngineAccess 门面 0/102 引用"与事实相反**:UI/2D 下 30+ 文件实际引用门面(SelectTool、FillDialog、OperationRouting 等)。
3. **"EntityOffset 并行 lambda 缺空指针检查"不成立**:EntityOffset.cpp:134 已有 `if (!entity) return;`。
4. **"EngineParallel push/pop 异常不平衡"不成立**:`ParallelRegion` 是 RAII(析构 pop),异常/提前 return 均安全。
5. **"DXF 嵌套阵列不计入预算"不准确**:存在 `kMaxBlockDepth` 深度限制与 `kMaxExpandedEntities=2M` 预算且嵌套路径有检查;真实问题只是预算上限偏大。
6. **第三份"框架体检"报告的量化结论**("RAII 使用率 ~85%"、"B+ 评分"等)无行号证据,不予采信;其两条"立即修复"(上文 3、4)已证伪。

## 6. 本轮修复记录(2026-10-29,已完成并通过测试)

### P0
- **P0-1 许可宏**:`Config.cmake:242` 新增 `option(SANYI_ENABLE_LICENSE ... OFF)`;`Licensing/License/CMakeLists.txt:67` 将宏 `target_compile_definitions` 进 License 库本身(此前全仓无人定义)。开发构建默认 OFF、发货构建 `-D SANYI_ENABLE_LICENSE=ON` 即生效;`BuildConfig.h` 的 `kLicense` 随之为真实值。CI 加了注释性说明,Release 断言待 CI 结构调整时补。
- **P0-2 UnitTransform UAF**:`UnitTransform.cpp` 循环前将源 extensionBlob 深拷贝到局部 vector,读取一律走拷贝,追加不再影响源指针。

### P1
- **writeBuffer/mapBuffer 回绕(6 处)**:gl/metal/null 三后端统一改为 `offset > size || sizeBytes > size - offset`;mapBuffer 的 `sizeBytes==0` 分支拆成两段校验,消除减法自身回绕。
- **坏样条中止整段**:`libdxfrw.cpp processSpline` 校验失败改为记录 secondary 诊断后跳过该实体继续解析;`DxfParser` 将诊断转为 warning 透出。测试 `DegenerateSplineIsSkippedButRestOfFileSurvives` 由失败转通过。
- **登录 token**:LoginManager 登录/刷新成功写入 `ConfigManager::setAccessToken/setRefreshToken`(刷新响应带新 refresh token 时同步轮换);NetworkManager 订阅 `loginSucceeded` 并分发到 httpRequest/UploadManager/WebSocketClient。
- **UploadManager 悬垂引用**:三处 `[=, &task]` 改为按值捕获 taskId + 回调内重查。
- **DownloadManager 路径穿越**:`QFileInfo(saveName).fileName()` 净化 + 落盘目录校验。
- **CacheManager 双重前缀**:写入改传裸 url 与读取一致;`DiskCache::put` 覆盖写按 `written - oldSize` 修正体积。
- **PythonHost 数据竞争**:`isCancelled` 纳入 `m_mutex` 保护(线程模型重构仍列为 §5 暂缓)。
- **TrialManager**:`trial_days` 读档 clamp 到 [0,365];静态缓存提为文件级并由 `Trial_Reset` 清除(新增 `TrialManager::resetState()`),Reset 后重新读档生效。
- **FileImporter 裸转型**:`dynamic_cast` 守卫,非 2D 实体不再误读 `bClosed/bCCW`。

### P2
- **HTTP 超时**:`HttpRequest::buildRequest` 与 UploadManager 三处 request 接入 `setTransferTimeout`(Qt 6.11 该 API 在 QNetworkRequest 上)。
- **WebSocket**:重连计数清零前保存旧值再判断 `reconnected()`;文本/二进制离线队列加 1000 条上限,超限丢最旧并告警。
- **SVGZ**:解压上限 64MB,超限中止;输入按 `<=UINT_MAX` 分块喂入消除 >4GB 截断。
- **SySerializer**:容量不足返回 fail 并报告所需字节数(`written` 仍回填完整大小,不破坏"先查大小"调用模式)。
- **BUILD_ALL_TESTS**:去掉 `Config.cmake:261` 的 FORCE 写回,`-D` 传参实测生效。
- **版本串**:`RENDERX_VERSION_STRING` 第三段改用 `RENDERX_VERSION_PATCH`。
- **classic locale 防御**(§4-1 已降级为建议,顺手补齐):ToolpathExporter(成员流+2 局部流)、SvgWriter、UgWriter、DxfFileWriter 共 4 文件 7 处 `imbue(std::locale::classic())`。
- **根目录游离测试文件**:确认与 Engraving/Test 正式版本为旧草稿(用例为超集覆盖、无任何目标引用)后已删除。
